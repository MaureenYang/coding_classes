## 1. 本章定位

接下來兩章（ch11 Diffie-Hellman、ch12 RSA）介紹公鑰系統，需要一些數學基礎。

> 作者的強烈主張：**不能只給公式。** 要用工具就得了解工具的性質。雜湊函式有「理想模型」可以對照；**公鑰系統沒有理想模型**——實務上你必須處理它們的數學性質，而要安全地處理，就必須**理解**這些性質。沒有捷徑。幸好只需要高中數學。

## 2. 整除與質數

- **a | b**（a 整除 b）：b 除以 a 沒有餘數，例如 7 | 35。
- **質數**：恰有兩個正因數 1 和自己。2, 3, 5, 7, 11, 13, …
- 大於 1 的非質數稱為**合數**；**1 既非質數也非合數**。

**引理 1**：若 a | b 且 b | c，則 a | c。

> 證：存在 s 使 as = b，存在 t 使 bt = c ⇒ c = bt = (as)t = a(st)。∎

**引理 2**：n > 1，令 d 為 n 大於 1 的最小因數，則 d 是質數。

> 證（反證法 *reductio ad absurdum*）：先確認 d 有定義（n 本身就是大於 1 的因數，故最小者存在）。假設 d 不是質數，則有 1 < e < d 且 e | d；由引理 1，e | n，與 d 最小矛盾。∎

**定理 3（歐幾里得）**：質數有無限多個。⭐

> 證：假設質數只有 p1, …, pk。令 n = p1·p2·…·pk + 1。由引理 2，n 的最小因數 d 是質數；但每個 pi 除 n 都餘 1，所以 d 不在清單中——矛盾。∎

其他背景：

- 質數的分佈看起來相當隨機，沒有簡單公式算出區間內的確切個數。
- **哥德巴赫猜想**（每個大於 2 的偶數都是兩質數之和）至今未證明。
- **算術基本定理**：大於 1 的整數**唯一**地分解為質數乘積（不計順序）。例：60 = 2·2·3·5。
- 小故事：埃拉托斯特尼（阿基米德的朋友）是第一個準確量出地球直徑的人；1700 年後哥倫布用了一個小得多（而且錯誤）的估計往西航向印度。

## 3. 產生小質數：埃拉托斯特尼篩法

兩千多年前的演算法，至今仍是產生小質數（例如一百萬以下）的最佳方法。

```
function SmallPrimeList(n) → P
    assert 2 ≤ n ≤ 2^20                 限制大小，避免記憶體耗盡
    (b2, b3, …, bn) ← (1, 1, …, 1)
    i ← 2
    while i² ≤ n do
        for j ∈ 2i, 3i, 4i, …, ⌊n/i⌋·i do  bj ← 0  od     標記 i 的倍數為合數
        repeat i ← i + 1 until bi = 1                     下一個質數
    od
    P ← 所有 bk = 1 的 k
```

**為何到 i² > n 就可以停？** 設 k 是合數，p 為其最小質因數，q = k/p，則 p ≤ q（否則 q 是更小的因數）。若 p > √k，則 k = p·q ≥ p·p > k，矛盾。故**每個合數 k 都有 ≤ √k 的質因數**；i > √n 時，所有 ≤ n 的合數都已被標記。

小質數的用途：產生大質數時先用它們快速過濾（§6）。

## 4. 模質數的運算 ⭐

密碼學喜歡質數的主要原因：**可以模質數運算**。

- 只使用 0, 1, …, p−1；每算出一個結果就取模 p。
- (25 mod 7) = 4。
- ⚠️ **取模結果永遠在 0 … p−1，即使原數是負的。** 有些程式語言（C、Java 的 `%`）會給負數結果——對數學家來說非常惱人。−1 mod p = p − 1。

> 實作提醒：在 C 中 `-1 % 7 == -1`；在 Python 中 `-1 % 7 == 6`。寫密碼程式時要特別注意。

### 4.1 加減法

- 加：相加，若 ≥ p 就減 p（最多減一次，因為和 ≤ 2p − 2）。
- 減：相減，若為負就加 p。
- 只在輸入已在範圍內時成立；否則要完整取模。
- 例：5 + 3 = 1 (mod 7)。日常例子：時鐘（mod 12 / 24）、公車 55 分出發、行駛 15 分 → 55 + 15 = 10 (mod 60)。
- 長算式中**任何時候取模都可以**：(5+2+5+4+6) mod 7 = 22 mod 7 = 1，也可以逐步取模。

### 4.2 乘法

- 先算整數乘積 ab（最大可到 (p−1)²），再做長除法取餘數。
- 例：3·4 = 12 = 2 (mod 5)；3·4·2·3 = 72 = 2 (mod 5)，逐步取模結果相同。

### 4.3 群與有限體

- 模 p 的數字集合稱為**有限體**，記作 **Zp**（其他書寫作 GF(p) 或 Z/pZ）。
  - 可以加減 p 的任意倍數而不改變結果；
  - 結果總在 0 … p−1；
  - 可以想成全程用整數計算、最後才取模——所以**整數的代數規則都成立**（如分配律）。
- **群**：一個集合加上一種運算（還有幾個附加條件，這裡討論的群都滿足）。
  - (Zp, +) 是群。
  - 乘法不能用 0 → {1, …, p−1} 與模 p 乘法構成**乘法群 Zp\***。
  - 有限體 = 加法群 + 乘法群。
- **子群**：部分元素，運算後仍在其中。
  - 模 8 加法：{0, 2, 4, 6} 是子群。
  - 模 7 乘法：{1, 6} 與 {1, 2, 4} 都是子群。

> 子群可以**加速**某些密碼運算，也可以被用來**攻擊**系統——所以必須了解（ch11 的小子群攻擊）。

- **除法**：a/b (mod p) 是滿足 c·b = a (mod p) 的 c；只要 b ≠ 0 就有定義。怎麼算？要回到歐幾里得。

### 4.4 GCD 演算法

```
function GCD(a, b) → k
    assert a ≥ 0 ∧ b ≥ 0
    while a ≠ 0 do
        (a, b) ← (b mod a, a)
    od
    return b
```

- 正確性：(b mod a) = b − sa，賦值不改變公因數的集合；a = 0 時 b 就是最大公因數。a、b 一直變小，必定終止。
- 例：(21, 30) → (9, 21) → (3, 9) → (0, 3) ⇒ gcd = 3。
- **LCM**：lcm(a, b) = ab / gcd(a, b)，例 lcm(6, 8) = 24。

### 4.5 擴展歐幾里得演算法 ⭐⭐

同時求出 u、v 使 **ua + vb = gcd(a, b)**。

```
function extendedGCD(a, b) → k, (u, v)
    assert a ≥ 0 ∧ b ≥ 0
    (c, d) ← (a, b)
    (uc, vc, ud, vd) ← (1, 0, 0, 1)
    while c ≠ 0 do
        不變量：uc·a + vc·b = c  ∧  ud·a + vd·b = d
        q ← ⌊d / c⌋
        (c, d) ← (d − qc, c)
        (uc, vc, ud, vd) ← (ud − q·uc, vd − q·vc, uc, vc)
    od
    return d, (ud, vd)
```

**求模反元素**：要算 1/b mod p（1 ≤ b < p），呼叫 extendedGCD(b, p)。因 p 是質數，gcd = 1：

```
u·b + v·p = 1   ⇒   u·b ≡ 1 (mod p)   ⇒   u = 1/b (mod p)
a/b = a·u (mod p)
```

- u 可能是負數，使用前先**取模 p**。
- 只需要 u 時，可省略 vc、vd 的計算。

> 對照第一本書：這裡的「不變量」註解，正是 Hanson 在 `XP`、`AP`、`MP`（任意精度算術，ch17–19）實作中大量使用的論證方式。Hanson 的 `MP` 介面也提供了模運算所需的大整數基礎。

### 4.6 模 2 運算

2 也是質數：

```
  +  | 0  1          ×  | 0  1
  ---+------        ---+------
  0  | 0  1          0  | 0  0
  1  | 1  0          1  | 0  1
```

- 模 2 加法 = **xor**；模 2 乘法 = **and**；唯一的反元素 1/1 = 1，所以除法 = 乘法。
- Z2 是分析電腦演算法的重要工具（例如 AES 的 GF(2^8)、GCM 的 GF(2^128) 都建立在其上）。

## 5. 大質數

公鑰密碼需要 **2000–4000 bits**（數百位數）的質數。

- 需要**多精度函式庫**：浮點數精度不夠，一般整數只有十幾位。
- 自己寫多精度函式庫遠比想像中費工：不只要正確，還要快，還有許多特殊情況。**下載免費函式庫，或用內建大整數的語言（如 Python）**。

> 對照第一本書：Hanson 的 ch17–19（`XP`、`AP`、`MP`）正好示範了「寫多精度函式庫有多費工」——光是除法就要處理許多邊界情況。

### 5.1 產生方法：隨機挑選 + 測試

- 在 n 附近，約每 **ln n** 個數就有一個質數（ln 2^k ≈ 0.7k）。
- 2000-bit 範圍內約每 **1386** 個數有一個質數——其中還包括許多一看就是合數的（例如偶數）。

```
function generateLargePrime(l, u) → p
    assert 2 < l ≤ u
    r ← 100 · (⌊log2 u⌋ + 1)            最多嘗試次數
    repeat
        r ← r − 1
        assert r > 0
        n ∈R l, …, u                    均勻隨機
    until isPrime(n)
    return n
```

- **l = 2 不允許**：Rabin-Miller 不適用 2（反正我們知道 2 是質數）。
- **限制嘗試次數**：有些區間沒有質數（例如 90 … 96）。**好的程式不論輸入為何都不該當住**。因子 100 讓大區間因運氣差而失敗的機率 < 2^-128。（作者承認用 assert 回報失敗有點偷懶，正式實作應給出說明清楚的錯誤。）
- n 必須在 l … u 中**均勻隨機**；若要保密質數，區間不能太小——區間內質數少於 2^128 個，攻擊者可能全部試一遍。
- 可以把最低位元設為 1 只挑奇數（嘗試次數減半）——但只在 u 為奇數時安全（否則可能超出範圍），且 l 為奇數時會稍微偏離 l。

### 5.2 isPrime：兩階段過濾

```
function isPrime(n) → b
    assert n ≥ 3
    for p ∈ 所有 ≤ 1000 的質數 do
        if p | n then return p = n
    od
    return Rabin-Miller(n)
```

- 先用小質數試除，快速淘汰大部分合數，再用重量級的 Rabin-Miller。
- 偷懶版：試 2 和所有奇數 3, 5, …, 999（**依序**，以確保 9 這種小合數被正確判斷）。上限 1000 可調整以求最佳效能。

### 5.3 Rabin-Miller 質數測試 ⭐⭐

所有簡單的質數測試都是**機率性**的，但可以重複執行把錯誤率壓到可接受的程度。

**Fermat 小定理**：p 為質數，對所有 1 ≤ a < p，a^(p−1) ≡ 1 (mod p)。
**Fermat 測試**直接檢查這個式子——但有些討厭的 **Carmichael 數**（如 561 = 3·11·17）是合數，卻對（幾乎）所有底數通過 Fermat 測試。

**Rabin-Miller 的想法**：

```
寫 n − 1 = 2^t · s（s 為奇數）
計算 a^s, a^(2s), a^(4s), …, a^(2^t·s) = a^(n−1)   （全部 mod n）

若 n 是質數：
  · 最後一項必為 1（Fermat）
  · x² ≡ 1 (mod n) 的解只有 1 和 n−1
  ⇒ 序列要嘛一開始就是 1，要嘛在變成 1 之前的那一項是 n−1
```

```
function Rabin-Miller(n) → b
    assert n ≥ 3 ∧ n mod 2 = 1
    (s, t) ← (n − 1, 0)
    while s mod 2 = 0 do (s, t) ← (s/2, t + 1) od
    k ← 0                               錯誤機率至多 2^-k
    while k < 128 do
        a ∈R 2, …, n − 1
        v ← a^s mod n                   昂貴的模冪運算
        if v ≠ 1 then
            i ← 0
            while v ≠ n − 1 do
                if i = t − 1 then return false
                else (v, i) ← (v² mod n, i + 1)
            od
        fi
        k ← k + 2                       通過一個底數：錯誤機率 × 1/4
    od
    return true
```

- 若 n 是質數，**一定**通過；若 n 是合數，**至少 75%** 的底數會揭穿它。
- 錯誤機率上限 2^-128 → **64 個底數**。
- 即使 isPrime 只會用合法參數呼叫它，仍要檢查輸入——**每個函式負責檢查自己的輸入與輸出**，你永遠不知道軟體將來會怎麼被修改。

**為何要做滿 64 輪？**

- 對**隨機**數，失敗機率遠小於上限；很多函式庫只測 5–10 個底數。
- 但之後會遇到**別人給的數**（ch11 驗證 DH 參數）——可能是**惡意挑選**的，所以 isPrime 必須**自己**達到 2^-128。
- 產生質數時，大部分時間花在淘汰合數（幾乎所有合數第一輪就被淘汰），可能要試幾百個數才找到一個質數 → 最後做 64 輪只比 10 輪稍慢。

**刪掉不必要的選項**：本章較早的版本中，Rabin-Miller 有第二個參數可以選錯誤機率——一個完美的**不必要選項**範例，於是被移除。永遠做到 2^-128 更簡單，也更不容易被誤用。（呼應 ch8「簡單為王」。）

> 2^-128 有多小？你在讀這句話時被隕石砸死的機率都大得多。還活著嗎？那就別擔心了。

### 5.4 模冪運算

a^s mod n 中 a、s 都是數千位元——不可能先算 a^s 再取模（全世界沒有電腦存得下），但可以**每一步都取模**。

**二進位法**（遞迴定義）：

```
s = 0          → 1
s > 0 且偶數   → y = a^(s/2) mod n，答案 = y² mod n
s > 0 且奇數   → y = a^((s−1)/2) mod n，答案 = a·y² mod n
```

- 從指數的**最高位**往**最低位**逐位元建構。
- s 有 k bits → 最多 **2k 次**模乘法。2000-bit 數的測試約 4000 次乘法，桌機可以應付。
- 優化：**Montgomery 乘法**、更少乘法的冪次演算法，各省 10%–30%，組合起來很重要。
- ⚠️ 直接的實作常受**時序攻擊**（ch15.3）——依指數位元決定是否多乘一次，時間洩漏指數。

## 6. 參考實作（Python）

依書中虛擬碼寫成，並用來計算習題答案（Python 內建大整數；`secrets` 提供密碼學亂數）。

```python
import secrets

def small_prime_list(n: int) -> list[int]:
    """Eratosthenes 篩法：回傳所有 ≤ n 的質數"""
    assert 2 <= n <= 2**20
    b = [True] * (n + 1)
    i = 2
    while i * i <= n:
        for j in range(2 * i, n + 1, i):
            b[j] = False
        i += 1
        while not b[i]:
            i += 1
    return [k for k in range(2, n + 1) if b[k]]

def extended_gcd(a: int, b: int):
    """回傳 (k, u, v) 使 u·a + v·b = k = gcd(a, b)"""
    assert a >= 0 and b >= 0
    c, d = a, b
    uc, vc, ud, vd = 1, 0, 0, 1
    while c != 0:
        # 不變量：uc·a + vc·b = c  且  ud·a + vd·b = d
        q = d // c
        c, d = d - q * c, c
        uc, vc, ud, vd = ud - q * uc, vd - q * vc, uc, vc
    return d, ud, vd

def mod_pow(a: int, s: int, n: int):
    """由高位到低位的二進位冪次（迴圈版），回傳 (結果, 乘法次數)"""
    r, mults = 1, 0
    for bit in bin(s)[2:]:
        r = r * r % n; mults += 1          # 平方
        if bit == "1":
            r = r * a % n; mults += 1      # 乘上 a
    return r, mults

SMALL = small_prime_list(1000)

def rabin_miller(n: int) -> bool:
    assert n >= 3 and n % 2 == 1
    s, t = n - 1, 0
    while s % 2 == 0:
        s, t = s // 2, t + 1
    k = 0
    while k < 128:                          # 每通過一個底數，錯誤機率 ×1/4
        a = 2 + secrets.randbelow(n - 2)    # a ∈R {2, …, n−1}
        v = pow(a, s, n)
        if v != 1:
            i = 0
            while v != n - 1:
                if i == t - 1:
                    return False
                v, i = v * v % n, i + 1
        k += 2
    return True

def is_prime(n: int) -> bool:
    assert n >= 3
    for p in SMALL:
        if n % p == 0:
            return p == n
    return rabin_miller(n)

def generate_large_prime(l: int, u: int) -> int:
    assert 2 < l <= u
    r = 100 * u.bit_length()
    while True:
        r -= 1
        assert r > 0, "no prime found"
        n = l + secrets.randbelow(u - l + 1)
        if is_prime(n):
            return n

if __name__ == "__main__":
    print(small_prime_list(50))
    print("10.2:", (13635 + 16060 + 8190 + 21363) % 29101,
          (((13635 + 16060) % 29101 + 8190) % 29101 + 21363) % 29101)
    print("10.3:", 12358 * 1854 * 14303 % 29101, (12358 * 1854 % 29101) * 14303 % 29101)
    print("10.4:", sorted({a * b % 7 for a in (1, 3, 4) for b in (1, 3, 4)}))
    print("10.5:", extended_gcd(91261, 117035)[0])
    k, u, v = extended_gcd(74, 167)
    print("10.6:", u % 167, 74 * (u % 167) % 167)
    p = generate_large_prime(2**255, 2**256 - 1)
    print("10.7:", hex(p))
    print("10.9:", mod_pow(2, 735, 569))
    print("Carmichael 561 =", [q for q in SMALL if 561 % q == 0], "is_prime:", is_prime(561))
```

## 7. 設計觀念整理

| 觀念 | 說明 |
|---|---|
| 理解數學 | 公鑰系統沒有理想模型，只能靠理解其性質 |
| 用現成的大整數函式庫 | 自己寫又慢又容易錯 |
| 程式永遠不該當住 | generateLargePrime 限制嘗試次數 |
| 每個函式檢查自己的輸入 | Rabin-Miller 即使只被 isPrime 呼叫也要 assert |
| 對惡意輸入要自足 | isPrime 必須獨自達到 2^-128，不能假設輸入是隨機的 |
| 刪除不必要的選項 | 錯誤機率參數被移除 |
| 負數取模 | 數學定義永遠非負；小心程式語言的 `%` |
| 均勻隨機 + 足夠大的區間 | 否則質數可被列舉 |

## 10. 本章重點整理

1. 公鑰系統沒有理想模型 → **必須理解數學**。
2. 整除、質數、歐幾里得的無限質數證明、算術基本定理。
3. 小質數用**埃拉托斯特尼篩法**，只需篩到 √n。
4. **Zp** 是有限體：加減乘都可隨時取模；**Zp\*** 是乘法群；子群可加速也可被用來攻擊。
5. **擴展歐幾里得**求 ua + vb = gcd → 模反元素 → 模除法。
6. 大質數：均勻隨機挑選 + **小質數試除** + **Rabin-Miller 64 輪**（錯誤率 2^-128）；限制嘗試次數。
7. 模冪用**二進位法**（≤ 2k 次乘法），但要注意時序攻擊。

> **一句話**：產生大質數其實很簡單——隨機挑、先用小質數篩、再用 Rabin-Miller 做滿 64 輪；真正要小心的是均勻性、惡意輸入和時序。
