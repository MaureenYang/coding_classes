@@@ 01 | 替換密碼

??? 預測輸出
```python
def shift(s, k):
    return "".join(chr((ord(c) - 65 + k) % 26 + 65) if c.isalpha() else c for c in s)

c = shift("ATTACK AT DAWN", 3)
print(c)
print(shift(c, -3))
print(shift("XYZ", 3))
print(len({shift("HELLO", k) for k in range(26)}))
```
!!!
```output
DWWDFN DW GDZQ
ATTACK AT DAWN
ABC
26
```

- 凱撒密碼每個字母往後移 3 格，Z 之後接回 A（所以 XYZ → ABC）。
- 解密就是往回移。
- 金鑰只有 26 種，同一個明文的 26 種位移各不相同——**暴力試完 26 種** 就能破解，所以凱撒密碼毫無安全性。

??? 觀念
一般的 **單字母替換密碼** 有 26! ≈ 4 × 10²⁶ 種金鑰，暴力破解不可能。為什麼它還是很容易被破解？描述破解的方法。
!!!
金鑰空間大 **不代表安全**。替換密碼把每個明文字母 **固定** 換成同一個密文字母，所以 **字母的出現頻率被完整保留**：密文中最常見的字母多半是 E，接著是 T、A、O……再配合常見的雙字母（TH、HE、IN）、三字母（THE、AND）和單字（A、I、THE）的模式，就能一步一步猜出整張替換表。這叫 **頻率分析**。文字越長，統計越可靠。

??? 觀念
用 **卡方統計量** 自動破解凱撒密碼時，要怎麼計算？為什麼文字太短時可能判錯？
!!!
對每個位移 k，把密文往回移 k 格，數出 26 個字母的次數 `cnt[i]`（共 n 個），計算 `χ² = Σ (cnt[i] − n·Fᵢ)² / (n·Fᵢ)`，其中 Fᵢ 是英文中第 i 個字母的頻率。χ² 越小代表越像英文，取最小的 k。

文字太短時，統計量的隨機誤差很大：幾十個字母的樣本可能剛好缺少 E，或某些罕見字母偏多，使得錯誤的位移反而更「像英文」。所以這類方法需要足夠長的密文（MC01 的測資會保證）。

@@@ 02 | 整除與最大公因數

??? 預測輸出
```python
def ext_gcd(a, b):
    u0, v0, u1, v1 = 1, 0, 0, 1
    while b:
        q, r = divmod(a, b)
        a, b = b, r
        u0, u1 = u1, u0 - q * u1
        v0, v1 = v1, v0 - q * v1
    return a, u0, v0

g, u, v = ext_gcd(2024, 748)
print(g, u, v, 2024 * u + 748 * v)
print(ext_gcd(17, 5))
```
!!!
```output
44 -7 19 44
(1, -2, 7)
```

`2024 · (−7) + 748 · 19 = 44`，所以 gcd = 44。`17 · (−2) + 5 · 7 = 1` 表示 17、5 互質，而且兩邊模 17 得到 `5 · 7 ≡ 1`：**5 模 17 的反元素是 7**。擴展歐幾里得求出的係數不唯一（加減 b/g、a/g 的倍數仍成立），但這個迴圈版本的結果是固定的。

??? 計算
用歐幾里得演算法手算 `gcd(2024, 748)`，寫出每一步的除法。最多需要幾步？
!!!
```
2024 = 2 · 748 + 528
 748 = 1 · 528 + 220
 528 = 2 · 220 +  88
 220 = 2 ·  88 +  44
  88 = 2 ·  44 +   0
```

所以 gcd = 44。

步數的上界：每 **兩步**，餘數至少減半（命題 1.7：`r_{i+2} < r_i / 2`），所以最多大約 `2 log₂ b + 2` 步。對 b = 748 來說不超過約 21 步；實際只用了 5 步。這就是歐幾里得演算法能處理幾千位數字的原因。

??? 觀念
「a、b 互質 ⇔ 存在整數 u、v 使 au + bv = 1」。說明 ⇐ 方向為什麼成立，以及擴展歐幾里得演算法在密碼學中最常見的用途。
!!!
⇐：如果 d 同時整除 a 和 b，就整除 au + bv = 1，所以 d = ±1，gcd(a, b) = 1。

（⇒ 方向就是擴展歐幾里得演算法給出的結果。）

最常見的用途是 **求模反元素**：`au + mv = 1` 兩邊模 m，得到 `au ≡ 1 (mod m)`，所以 u 就是 a 模 m 的反元素。RSA 的解密指數 `d ≡ e⁻¹ (mod (p−1)(q−1))`、ElGamal / DSA 簽章中的 `e⁻¹`、中國剩餘定理的組合，全都靠它。

@@@ 03 | 模運算

??? 預測輸出
```python
def power_mod(a, e, m):
    r = 1
    a %= m
    steps = 0
    while e:
        if e & 1:
            r = r * a % m
            steps += 1
        a = a * a % m
        steps += 1
        e >>= 1
    return r, steps

print(power_mod(3, 218, 1000))
print(power_mod(2, 2**20, 1000003))
print(pow(3, 218, 1000))
```
!!!
```output
(489, 13)
(512410, 22)
489
```

- `3²¹⁸ mod 1000 = 489`（課本例 1.19），218 的二進位是 11011010，8 次平方 + 5 次乘法 = 13 次。
- 指數 2²⁰ 只有一個 1 的位元，21 次平方 + 1 次乘法 = 22 次——直接乘要一百萬次。
- Python 內建的 `pow(a, e, m)` 就是快速冪。

??? 觀念
1. 為什麼「快速冪」對密碼學那麼重要？算 `a^e mod m` 大約需要幾次乘法？
2. 為什麼每一步都要模 m，而不是先算出 `a^e` 再取模？
!!!
1. 幾乎所有公鑰密碼（Diffie–Hellman、ElGamal、RSA、DSA）的核心運算都是 **模冪**，指數有幾百到幾千位元。一次一次乘要 e 次，完全不可能；平方乘法只要看 e 的二進位，最多 `2 log₂ e` 次乘法（每個位元一次平方，加上 1 的位元再乘一次）。2048 位元的指數大約 4000 次乘法。
2. `a^e` 本身大得無法儲存（例如 2048 位元的數自乘 2²⁰⁴⁸ 次，位數比宇宙中的原子還多）。因為 `(xy) mod m = ((x mod m)(y mod m)) mod m`，每一步取模不影響結果，又讓數字保持在 m 以下。

??? 判斷
下面哪些敘述正確？
1. 在 Z/12Z 中，5 有反元素。
2. 在 Z/12Z 中，4 有反元素。
3. `(Z/pZ)*` 有 p − 1 個元素（p 是質數）。
4. 若 `ac ≡ bc (mod m)`，則 `a ≡ b (mod m)`。
!!!
1. **對**。gcd(5, 12) = 1，`5 · 5 = 25 ≡ 1`，反元素是 5。
2. **錯**。gcd(4, 12) = 4 ≠ 1，沒有反元素。
3. **對**。1, 2, …, p − 1 都和 p 互質。
4. **錯**。只有 c 和 m 互質時才能約分。反例：`2 · 6 ≡ 4 · 6 ≡ 0 (mod 12)`，但 `2 ≢ 4`。

@@@ 04 | 質數與有限體

??? 預測輸出
```python
p = 13
for g in (2, 3, 12):
    powers = [pow(g, k, p) for k in range(1, p)]
    order = powers.index(1) + 1
    print(g, order, order == p - 1)
print([pow(a, p - 1, p) for a in range(1, 6)])
print(pow(5, -1, 13), pow(5, 11, 13))
```
!!!
```output
2 12 True
3 3 False
12 2 False
[1, 1, 1, 1, 1]
8 8
```

- 模 13：2 的階是 12 = p − 1，**2 是原根**；3 的階是 3（`3³ = 27 ≡ 1`）；`12 ≡ −1`，階是 2。三個階都整除 12。
- 費馬小定理：`a¹² ≡ 1`。
- `5⁻¹ ≡ 5¹¹ = 5^(p−2) ≡ 8 (mod 13)`（`5 · 8 = 40 = 3 · 13 + 1`），和 `pow(5, -1, 13)` 一樣。

??? 觀念
1. 寫出 **費馬小定理**，並說明怎麼用它求模反元素。
2. 什麼是 **原根**？為什麼 g 的階一定整除 p − 1？
!!!
1. p 是質數、`p ∤ a` 時，`a^(p−1) ≡ 1 (mod p)`。所以 `a · a^(p−2) ≡ 1`，`a⁻¹ ≡ a^(p−2) (mod p)`——只要一次快速冪，不需要擴展歐幾里得。
2. **原根** 是階等於 p − 1 的元素 g：`g, g², …, g^(p−1)` 跑遍 F_p* 的所有元素。原根定理保證每個質數 p 都有原根（而且有 φ(p − 1) 個）。

   g 的階 k 整除 p − 1：把 p − 1 寫成 `qk + r`（0 ≤ r < k），`1 = g^(p−1) = (g^k)^q · g^r = g^r`。k 是最小的正指數，所以 r 只能是 0。

??? 觀念
一個有限體 F_p 和整數模 n（n 是合數）的環 Z/nZ 最大的差別是什麼？為什麼密碼學很多系統都選在 F_p 中運算？
!!!
F_p 中 **每個非零元素都有乘法反元素**，所以可以自由地做除法；Z/nZ（n 合數）中，和 n 不互質的元素沒有反元素（例如 Z/12Z 中的 4），除法不一定能做。

F_p 的乘法群 F_p* 是 **循環群**（有原根），結構清楚：群的大小是 p − 1，可以用原根的冪表示每個元素，離散對數問題也因此有明確的定義。Diffie–Hellman、ElGamal、DSA、橢圓曲線（定義在 F_p 上）都建立在這個基礎上。

@@@ 05 | 對稱與非對稱密碼

??? 預測輸出
```python
import random

def xor(a, b):
    return bytes(x ^ y for x, y in zip(a, b))

key = bytes(random.Random(5).randrange(256) for _ in range(5))
m1, m2 = b"HELLO", b"WORLD"
c1, c2 = xor(m1, key), xor(m2, key)
print(xor(c1, key))
print(xor(c1, c2) == xor(m1, m2))
print(xor(xor(c1, c2), m1))
```
!!!
```output
b'HELLO'
True
b'WORLD'
```

- 用金鑰 XOR 兩次就還原明文（`m ⊕ k ⊕ k = m`）。
- 同一把金鑰加密兩則訊息時，`c₁ ⊕ c₂ = m₁ ⊕ m₂`——**金鑰完全消失**。
- 只要知道（或猜到）其中一則明文，另一則就直接算出來；即使都不知道，`m₁ ⊕ m₂` 也有很多統計規律可以利用（歷史上的 VENONA 計畫就是這樣破解蘇聯重複使用的密碼本）。一次性密碼本的完美保密只在金鑰 **只用一次** 時成立。

說明為什麼一次性密碼本的金鑰 **絕對不能重複使用**。

??? 觀念
比較對稱密碼和公鑰密碼：各自的優缺點是什麼？實務上怎麼結合？
!!!
- **對稱密碼**（AES 等）：速度快、金鑰短；但雙方必須 **事先共享金鑰**，n 個人兩兩通訊要 n(n − 1)/2 把金鑰。
- **公鑰密碼**（RSA、ElGamal、ECC）：不需要事先共享秘密，任何人都能用公鑰加密；但慢上百到上千倍，密文也比較大。

實務上用 **混合加密**：用公鑰密碼（或 Diffie–Hellman 金鑰交換）傳送一把隨機的 **對稱金鑰**，再用對稱密碼加密真正的資料。TLS、PGP 都是這樣做。

??? 觀念
什麼是 **陷門單向函數**？公鑰密碼為什麼需要它？舉一個例子。
!!!
**單向函數**：正向容易算，反向極難算。**陷門單向函數**：反向很難，但知道某個秘密資訊（陷門）的人可以輕易反向計算。

公鑰密碼需要它：加密（正向）任何人都能做，解密（反向）必須只有持有私鑰（陷門）的人能做。

例子：RSA 的 `m ↦ m^e mod N`。不知道 N 的分解時，從 c 求 m 被認為很難；知道 p、q 就能算出 `d = e⁻¹ mod (p−1)(q−1)`，`c^d = m`。

??? 觀念
1. 寫出 **離散對數問題**（DLP）和 **Diffie–Hellman 問題**（DHP）。兩者的關係是什麼？
2. 在 Diffie–Hellman 金鑰交換中，Eve 看到了 p、g、A、B，為什麼算不出共同金鑰？
!!!
1. **DLP**：給 g、h，找 x 使 `g^x = h`。**DHP**：給 `g^a`、`g^b`，求 `g^(ab)`。能解 DLP 就能解 DHP（從 A 求出 a，再算 `B^a`）；反方向是否成立 **未知**——也許有不用解 DLP 就能解 DHP 的方法，只是目前沒人找到。
2. Eve 需要從 A = g^a 求出 a（或從 B 求出 b），也就是解 DLP；p 夠大（2048 位元以上）時，已知最好的演算法（指標演算法）也需要次指數時間，實際上做不到。

??? 找錯
Bob 為了節省時間，用 **同一個臨時金鑰 k** 加密了兩則 ElGamal 訊息 m 和 m'，得到 (c₁, c₂) 和 (c₁, c₂')。Eve 事先知道 m 的內容。她能得到什麼？
!!!
兩則密文的 c₁ = g^k 一樣，而且 `c₂ = m·A^k`、`c₂' = m'·A^k`，所以

```
c₂' / c₂ = m' / m   ⇒   m' = c₂' · c₂⁻¹ · m (mod p)
```

Eve 知道 m 就能直接算出 m'（不需要解任何 DLP）；即使不知道 m，也能得到 m'/m 的關係。臨時金鑰 **每次都要重新隨機產生**。

@@@ 07 | 群與嬰兒步巨人步

??? 預測輸出
```python
from math import isqrt

def bsgs(g, h, p, N):
    n = isqrt(N) + 1
    baby = {}
    cur = 1
    for j in range(n):
        baby.setdefault(cur, j)
        cur = cur * g % p
    u = pow(g, -n, p)
    y = h
    for i in range(n + 1):
        if y in baby:
            return i * n + baby[y], n
        y = y * u % p

print(bsgs(9704, 13896, 17389, 1242))
print(bsgs(2, 9, 11, 10))
```
!!!
```output
(1159, 36)
(6, 4)
```

- 課本例 2.23：9704 的階是 1242，`n = 36`，解是 x = 1159，只要約 2 × 36 步，而不是 1242 步。
- `2⁶ = 64 ≡ 9 (mod 11)`。

??? 觀念
嬰兒步巨人步解一個階為 N 的 DLP 需要多少時間和空間？為什麼它能保證找到解？
!!!
令 `n = ⌊√N⌋ + 1`。嬰兒步存 n 個值（空間 O(√N)），巨人步最多 n + 1 次查表，所以時間和空間都是 **O(√N · log N)**（雜湊表查詢視為常數時間的話就是 O(√N)）。

保證找到：解 x < N < n²，可以寫成 `x = i·n + j`，`0 ≤ i, j < n`。這時 `g^j = h · g^(−in)`，所以第 i 次巨人步一定會在嬰兒步的表中找到 g^j。

這是 **碰撞演算法**：任何群都適用，不需要群的特殊結構——這也是橢圓曲線 DLP 至今最好的通用攻擊方式之一。

??? 觀念
一個群 G 的元素 g 的 **階** 是什麼？拉格朗日定理說什麼？它對選擇 DLP 的參數有什麼影響？
!!!
g 的 **階** 是最小的正整數 k 使 `g^k = e`（單位元素）。**拉格朗日定理**：有限群 G 中，每個元素的階都整除 |G|。

影響：DLP `g^x = h` 的難度取決於 g 的 **階** N（x 只要算到模 N），而不是整個群的大小。所以要選 **階很大的 g**；而且（下一課的 Pohlig–Hellman）N 必須有 **很大的質因數**，最好 N 本身就是大質數。

@@@ 08 | 中國剩餘定理與 Pohlig–Hellman

??? 預測輸出
```python
def crt(residues, moduli):
    x, M = 0, 1
    for a, m in zip(residues, moduli):
        x += M * ((a - x) * pow(M, -1, m) % m)
        M *= m
    return x % M, M

print(crt([2, 3], [3, 7]))
print(crt([2, 3, 4], [3, 7, 16]))
print(crt([1, 9], [5, 11]))
```
!!!
```output
(17, 21)
(164, 336)
(31, 55)
```

- `x ≡ 2 (mod 3)`、`x ≡ 3 (mod 7)` ⇒ `x ≡ 17 (mod 21)`。
- 再加上 `x ≡ 4 (mod 16)` ⇒ `x ≡ 164 (mod 336)`（課本例 2.26）。
- 課本例 2.24：`x ≡ 31 (mod 55)`。

??? 觀念
**Pohlig–Hellman** 演算法的想法是什麼？它告訴我們 Diffie–Hellman 的質數 p 要怎麼選？
!!!
設 g 的階 `N = q₁^e₁ ⋯ q_t^e_t`。對每個 `qᵢ^eᵢ`，把 g、h 都升到 `N/qᵢ^eᵢ` 次方，得到一個階為 `qᵢ^eᵢ` 的小 DLP，解出 `x mod qᵢ^eᵢ`；再把每個質數次方拆成 eᵢ 個階為 qᵢ 的 DLP（一次解 qᵢ 進位的一位數）；最後用 **中國剩餘定理** 合併。

花費大約是 `Σ eᵢ · √qᵢ`，所以 **DLP 的難度由 N 最大的質因數決定**。選 p 時要讓 p − 1 有很大的質因數，常見的做法是用 **安全質數** `p = 2q + 1`（q 也是質數），並在階為 q 的子群中運算。

??? 預測輸出
解 `x² ≡ 197 (mod 437)`，`437 = 19 · 23`。先分別看模 19 和模 23：
```python
print(197 % 19, [x for x in range(19) if x * x % 19 == 197 % 19])
print(197 % 23, [x for x in range(23) if x * x % 23 == 197 % 23])
print(sorted(x for x in range(437) if x * x % 437 == 197))
```
共有幾個解？它們和前兩行有什麼關係？
!!!
```output
7 [8, 11]
13 [6, 17]
[144, 201, 236, 293]
```

模 19 有兩個解、模 23 有兩個解，用中國剩餘定理兩兩組合得到 **四個** 解（每個解模 19 和模 23 的餘數，正好是前兩行的某一組）。這說明：**知道 N = pq 的分解，就能求模 N 的平方根**；反過來，能求模 N 平方根的人也能分解 N（兩個「本質不同」的平方根相減，和 N 的 gcd 就是因數）。

@@@ 09 | 環、多項式與有限體

??? 預測輸出

??? 觀念
1. 為什麼 RSA 解密 `c^d ≡ m (mod N)` 會成立？
2. 為什麼 Eve 知道 N 和 e 卻算不出 d？
!!!
1. `ed ≡ 1 (mod (p−1)(q−1))`，寫成 `ed = 1 + k(p−1)(q−1)`。由 **歐拉公式**，gcd(m, N) = 1 時 `m^((p−1)(q−1)) ≡ 1 (mod N)`，所以 `c^d = m^(ed) = m · (m^((p−1)(q−1)))^k ≡ m`。（gcd(m, N) ≠ 1 的情況可以分別模 p、q 驗證，結論相同。）

??? 觀念
什麼是 **指標演算法**？為什麼它讓 F_p* 中的 DLP 比橢圓曲線上的 DLP 容易？
!!!
指標演算法解 F_p* 中的 `g^x = h`：
1. 選一組小質數（因子基底）。找很多個 k 使 `g^k mod p` 是 B-光滑數，每個都給出一條關於小質數離散對數的 **線性方程**（模 p − 1）；解方程組得到每個小質數的離散對數。
2. 找一個 k 使 `h · g^(−k) mod p` 是 B-光滑數，就能用小質數的離散對數組出 log h。

它是 **次指數時間** `L(p)^c`。它依賴「整數可以分解成小質數」這種額外結構；橢圓曲線上的點沒有類似的「小點」分解，所以 ECDLP 只有通用的 O(√N) 碰撞演算法。這就是 256 位元的橢圓曲線能和 3072 位元的 F_p 有相同安全度的原因。

??? 觀念
次指數函數 `L(X) = e^(√(ln X · ln ln X))` 為什麼叫「次指數」？
!!!
寫成 X 的冪：`L(X) = X^(√(ln ln X / ln X))`。指數 `√(ln ln X / ln X)` 隨 X 變大而趨近 0，所以 L(X) 比任何 `X^ε`（ε > 0 固定）都慢——**比指數時間慢**（以位數 n = log X 來看，比 2^(εn) 慢）。但它又比任何多項式 `(ln X)^k` 快——**比多項式時間快**。介於兩者之間，所以叫次指數。

1. **完美保密**：看到密文完全不改變對明文的猜測，`P(M = m | C = c) = P(M = m)`。一次性密碼本的金鑰均勻隨機，任何密文都可以由任何明文配上某個金鑰得到，而且機率相同，所以密文不透露任何資訊。代價（夏農定理）：**金鑰至少要和明文一樣長**，而且只能用一次。
2. H(X) 是 X 的 **平均不確定性**，也就是描述 X 平均需要多少位元。公平硬幣 1 位元；確定的事件 0 位元；四種等可能結果 2 位元；偏向一邊的硬幣不到 1 位元。密碼學中金鑰的熵就是暴力搜尋的難度。

??? 觀念
P 和 NP 是什麼？如果 P = NP，公鑰密碼會怎樣？為什麼「NP-complete 問題」不一定適合當密碼系統的基礎？
!!!
- **P**：能在多項式時間內 **解出** 的問題。**NP**：答案能在多項式時間內 **驗證** 的問題。
- 公鑰密碼的「私鑰」就是一個容易驗證的答案（例如 N 的因數），所以破解公鑰密碼的問題都在 NP 中。如果 P = NP，這些問題都有多項式時間解法，現有的公鑰密碼全部失效。
- NP-complete 只保證 **最壞情況** 很難；密碼學需要的是 **隨機挑選的實例** 也很難（平均情況困難）。背包密碼系統就是例子：一般的子集和問題是 NP-complete，但背包密碼用的「超遞增 + 偽裝」實例被格約化攻破了。

??? 找錯
2010 年，有人發現某遊戲主機的 ECDSA 簽章實作中，每次簽章用的臨時金鑰 e 都是 **同一個常數**。為什麼這會讓私鑰外洩？
!!!
兩個簽章 `S₂ ≡ (D + sS₁)e⁻¹`、`S₂' ≡ (D' + sS₁)e⁻¹`（e 相同，所以 S₁ 也相同）。相減：

```
(S₂ − S₂') e ≡ D − D'   ⇒   e ≡ (D − D')(S₂ − S₂')⁻¹ (mod q)
```

求出 e 之後，`s ≡ (S₂e − D) S₁⁻¹ (mod q)`——**私鑰直接算出來**。只要兩個簽章就夠了。臨時金鑰必須每次都不同而且不可預測；現代實作常用 RFC 6979，由私鑰和訊息雜湊 **確定性地** 產生 e。

??? 觀念
1. 為什麼簽章前要先對文件做雜湊？
2. 為什麼 DSA 的簽章比 ElGamal 簽章短？
3. 什麼是 GGH 簽章的 **謄本攻擊**？
!!!
1. 效率：簽章演算法一次只能處理幾百位元，雜湊把任意長度的文件壓成固定長度。安全：沒有雜湊時，教科書 RSA 簽章可以被存在性偽造（先選 S，再令 D = S^e），也可以把兩個簽章相乘得到乘積文件的簽章；雜湊破壞了這些代數結構。
2. DSA 在階為質數 q 的子群中運算，簽章是兩個 mod q 的數（q 約 160～320 位元），而不是 mod p（2048 位元以上）。指標演算法攻擊的是整個 F_p，所以 p 仍要大；但碰撞演算法只看 q，`√q` 夠大就安全。
3. 每個 GGH 簽章 s 和文件 d 的差 `d − s` 都落在私鑰基底的 **基本平行多面體** 中。收集大量簽章後，Eve 用統計方法還原這個平行多面體的形狀，也就是私鑰的好基底（Nguyen–Regev 2006）。現代格簽章（Dilithium、Falcon）用拒絕取樣或高斯取樣讓簽章分布和私鑰無關。

```python
p = 101
coeffs = [11, 34, 7]                          # f(x) = 11 + 34x + 7x²，門檻 t = 3
shares = [(x, sum(c * x**k for k, c in enumerate(coeffs)) % p) for x in range(1, 6)]
print(shares)

def recover(pts):
    S = 0
    for i, (xi, yi) in enumerate(pts):
        num = den = 1
        for j, (xj, _) in enumerate(pts):
            if i != j:
                num, den = num * xj % p, den * (xj - xi) % p
        S = (S + yi * num * pow(den, -1, p)) % p
    return S

print(recover(shares[:3]), recover(shares[2:]), recover(shares[:2]))
```

??? 觀念
在「證明 y 是模 N 的平方」的零知識證明中：
1. 如果 Victor 每回合都選 β = 1，不知道平方根的 Peggy 能不能騙過他？
2. 為什麼說 Victor 得到的紀錄「零知識」？
!!!
1. **可以**。Peggy 先選隨機 z，送出 `s ≡ z²·y⁻¹`；Victor 送 β = 1 時，她回 z，就有 `z² ≡ ys`。所以 Victor 的挑戰必須 **隨機**，而且要在 Peggy 送出 s **之後** 才決定；每回合騙子只有 1/2 的機會猜中，n 回合是 2⁻ⁿ。
2. Victor 自己就能產生和真實對話 **分布完全相同** 的紀錄：先隨機選 z 和 β，再令 `s ≡ z²·y^(−β)`。既然不跟 Peggy 說話也能做出一樣的紀錄，真實的紀錄就不可能給他任何新資訊，也無法拿去說服第三人。

??? 觀念
1. Shor 演算法對現有的公鑰密碼有什麼威脅？量子電腦用在演算法的哪一部分？
2. 為什麼格密碼被認為能抵抗量子電腦？
!!!
1. Shor 演算法能在 **多項式時間** 內分解整數、解 DLP 和 ECDLP，所以 RSA、Diffie–Hellman、DSA、ECC 在大型量子電腦面前全部失效。量子電腦只負責 **找階**：用量子傅立葉轉換找出 a 模 n 的階 r；其餘（用連分數從測量值還原 r、算 `gcd(a^(r/2) ± 1, n)`）都是古典計算。
2. 目前 **沒有** 解 SVP / CVP 的有效量子演算法；Grover 搜尋只帶來平方根加速，把參數加大就能彌補。所以 NIST 的後量子標準主要是格密碼：ML-KEM（Kyber）、ML-DSA（Dilithium）、FN-DSA（Falcon，NTRU 格）。

??? 觀念
1. Feistel 網路的輪函數 F 為什麼不需要可逆？
2. AES 的 S-box 是怎麼構造的？為什麼這樣設計？
!!!
1. 每一輪 `(L, R) → (R, L ⊕ F(R))`。拿到輸出 (R, L ⊕ F(R)) 時，R 直接就有，再算一次 F(R) 和第二半 XOR 就還原 L。解密只需要 **計算** F，不需要反轉 F；整個網路把輪金鑰倒過來用同一套程序就能解密。DES 就是 16 輪 Feistel。
2. AES 的 S-box：把 byte 看成 F₂₅₆ 的元素，**求乘法反元素**（0 對應 0），再做一個 F₂ 上的 **仿射轉換**（加上常數 0x63）。求反元素的映射和任何線性函數都「相差很遠」，讓差分和線性密碼分析很難找到有用的統計偏差；仿射轉換則消除不動點等簡單的代數結構。
