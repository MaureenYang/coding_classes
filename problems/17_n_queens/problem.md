# 17. N 皇后 (N-Queens)

> 主題：遞迴 / 回溯法 Backtracking　難度：★★☆　時間限制：2 秒　相關教學：`lessons/02_recursion.md`

## 題目

在 `n × n` 的西洋棋盤上放 `n` 個皇后，使得任兩個皇后都 **不在同一列、同一行、同一條斜線** 上。

給定 `n`，輸出解的總數；並輸出 **字典序最小** 的一組解。

解的表示法：`n` 個整數 `c1 c2 ... cn`，`ci` 代表第 `i` 列的皇后放在第幾行（1-based）。
「字典序最小」就是：第 1 列盡量放左邊，相同時第 2 列盡量放左邊，依此類推。

## 輸入

一個整數 `n`。

## 輸出

第一行：解的數量。
第二行：字典序最小的解；若無解輸出 `none`。

## 限制

- `1 ≤ n ≤ 13`

## 範例

輸入
```
4
```
輸出
```
2
2 4 1 3
```

## 提示

- 一列一列放，每一列試每一行，檢查是否衝突；不行就 **回溯**（拿掉皇后，試下一個位置）。
- 用三個 bool 陣列 `col[c]`、`diag1[r + c]`、`diag2[r - c + n - 1]` 做到 `O(1)` 檢查。
- 照「行由小到大」的順序搜尋，**第一個** 找到的解就是字典序最小。
- corner case：`n = 1`（1 種），`n = 2`、`n = 3`（無解）。
- `n = 13` 有 73712 組解，暴力試所有排列 `13!` 會 TLE，必須剪枝。
