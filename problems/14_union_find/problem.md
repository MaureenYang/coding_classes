# 14. 併查集 (Union-Find / Disjoint Set)

> 主題：併查集　難度：★★☆　時間限制：1 秒　相關教學：`lessons/10_union_find.md`

## 題目

有 `n` 個人，編號 `1 ~ n`，一開始每個人自己一組。處理 `q` 個操作：

| 指令 | 說明 | 輸出 |
|---|---|---|
| `union a b` | 把 `a`、`b` 所在的兩組合併（已經同組就不做事） | 無 |
| `same a b` | `a`、`b` 是否同組 | `YES` / `NO` |
| `size a` | `a` 所在組的人數 | 整數 |
| `count` | 目前一共有幾組 | 整數 |

## 輸入

第一行 `n q`，接下來 `q` 行指令。

## 輸出

依照上表。

## 限制

- `1 ≤ n, q ≤ 3×10^5`
- `a` 可能等於 `b`

## 範例

輸入
```
5 7
union 1 2
union 3 4
same 1 3
union 2 4
same 1 3
size 4
count
```
輸出
```
NO
YES
4
2
```

## 提示

- `parent[x]`：`x` 的老大；`find(x)` 一路往上找到根。
- **路徑壓縮**：`find` 時把路上每個點直接接到根。
- **按大小合併**：小的組接到大的組底下。
- 兩個優化都沒做的話，測資會讓你的樹變成一條長鏈 → TLE；若 `find` 用遞迴，還可能 **stack overflow**。
- `union a a` 不可以讓組數減少！
