# 16. 拓撲排序 (Topological Sort)

> 主題：圖 / 有向無環圖　難度：★★★　時間限制：1 秒　相關教學：`lessons/09_graph.md`

## 題目

有 `n` 門課（編號 `1 ~ n`）和 `m` 條先修關係 `a b`，代表「要先修 `a` 才能修 `b`」。

請輸出一個修課順序。若有多種順序，輸出 **字典序最小** 的那一個（也就是每一步都挑「現在能修的課裡編號最小的」）。
如果不可能修完所有課（有環），輸出 `IMPOSSIBLE`。

## 輸入

第一行 `n m`，接下來 `m` 行，每行 `a b`。

## 輸出

一行 `n` 個整數，或 `IMPOSSIBLE`。

## 限制

- `1 ≤ n ≤ 2×10^5`，`0 ≤ m ≤ 2×10^5`
- 可能有 **重複的邊**，也可能有 **自環** `a a`

## 範例

輸入
```
5 4
3 1
1 2
3 2
5 4
```
輸出
```
3 1 2 5 4
```

## 提示

- Kahn 演算法：記錄每個點的入度 (in-degree)，入度為 0 的點可以修。
- 想要字典序最小 → 把 `queue` 換成 **最小堆積** `priority_queue<int, vector<int>, greater<int>>`。
- 怎麼判斷有環？如果最後輸出的點不到 `n` 個。
- 重複的邊會讓入度被算兩次 —— 只要扣的時候也扣兩次就沒問題。
