# 08. 下一個更大的元素 (Next Greater Element)

> 主題：單調堆疊 Monotonic Stack　難度：★★☆　時間限制：1 秒　相關教學：`lessons/05_stack_queue.md`

## 題目

給一個長度 `n` 的陣列 `a`。對每個位置 `i`，找出它 **右邊第一個嚴格大於** `a[i]` 的元素值；
如果不存在，輸出 `-1`。

## 輸入

第一行 `n`，第二行 `n` 個整數。

## 輸出

一行 `n` 個整數，空白分隔。

## 限制

- `1 ≤ n ≤ 3×10^5`
- `-10^9 ≤ a[i] ≤ 10^9`
- `O(n^2)` 的暴力法會 **TLE**，需要 `O(n)`

## 範例

輸入
```
6
2 7 3 5 4 6
```
輸出
```
7 -1 5 6 6 -1
```

## 提示

- 從左往右掃，stack 裡放「還沒找到答案」的 **索引**。
- 每來一個新元素 `a[i]`，就把 stack 頂端所有 `< a[i]` 的元素彈出，它們的答案就是 `a[i]`。
- 為什麼這樣是 `O(n)`？每個索引最多被 push 一次、pop 一次。
- 陣列裡本來就可能有 `-1`。如果你的程式用「值等於 -1」來判斷「還沒找到答案」，會出錯 —— 改用索引或另外的標記。
- 相等的元素不算更大。
