# 01. 河內塔 (Tower of Hanoi)

> 主題：遞迴　難度：★☆☆　時間限制：2 秒　相關教學：`lessons/02_recursion.md`

## 題目

有三根柱子 `A`、`B`、`C`。一開始 `A` 上由下往上疊著 `n` 個圓盤，
大小分別是 `n, n-1, ..., 2, 1`（編號越大越大）。

規則：
1. 每次只能移動一個圓盤（某根柱子最上面那個）。
2. 大的圓盤不能放在小的圓盤上面。

請用 **最少的步數** 把所有圓盤從 `A` 移到 `C`，並輸出每一步。

## 輸入

一個整數 `n`。

## 輸出

第一行輸出最少步數。接下來每一行輸出一步，格式為：

```
move disk d from X to Y
```

## 限制

- `1 ≤ n ≤ 18`

## 範例

輸入
```
2
```
輸出
```
3
move disk 1 from A to B
move disk 2 from A to C
move disk 1 from B to C
```

## 提示

- 想把 `n` 個盤子從 `A` 搬到 `C`：先把上面 `n-1` 個搬到 `B`，再把第 `n` 個搬到 `C`，最後把 `n-1` 個從 `B` 搬到 `C`。
- 步數是 `2^n - 1`。`n = 18` 時要輸出 26 萬行，注意輸出速度（用 `'\n'` 不要用 `endl`）。
