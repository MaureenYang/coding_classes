# 09. 滑動視窗最大值 (Sliding Window Maximum)

> 主題：雙端佇列 Deque　難度：★★★　時間限制：1 秒　相關教學：`lessons/05_stack_queue.md`

## 題目

給長度 `n` 的陣列 `a` 和整數 `k`。一個長度 `k` 的視窗從最左邊滑到最右邊，
請輸出每個視窗內的最大值（共 `n - k + 1` 個）。

## 輸入

第一行 `n k`，第二行 `n` 個整數。

## 輸出

一行 `n - k + 1` 個整數，空白分隔。

## 限制

- `1 ≤ k ≤ n ≤ 10^6`
- `-10^9 ≤ a[i] ≤ 10^9`
- `O(nk)` 會 **TLE**；目標 `O(n)`

## 範例

輸入
```
8 3
1 3 -1 -3 5 3 6 7
```
輸出
```
3 3 5 5 6 7
```

## 提示

- `deque` 裡放 **索引**，並維持對應的值 **由前到後遞減**。
- 新元素進來時，從後面把比它小（或等於）的都丟掉 —— 它們不可能再當最大值了。
- 前端的索引如果已經 `≤ i - k`，代表滑出視窗了，要丟掉。
- corner case：`k = 1`、`k = n`。
- 輸入有 `10^6` 個數字，記得 `ios::sync_with_stdio(false); cin.tie(nullptr);`。
