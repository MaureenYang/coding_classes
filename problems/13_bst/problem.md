# 13. 二元搜尋樹 (Binary Search Tree)

> 主題：樹 / BST　難度：★★★　時間限制：2 秒　相關教學：`lessons/08_bst.md`

## 題目

自己用指標實作一棵（不平衡的）二元搜尋樹，**不要用 `std::set`**：

| 指令 | 說明 | 輸出 |
|---|---|---|
| `insert x` | 插入 `x`；已存在就忽略 | 無 |
| `find x` | 是否存在 | `yes` / `no` |
| `delete x` | 刪除 `x` | 不存在時輸出 `not found` |
| `inorder` | 中序走訪 | 空白分隔；空樹輸出 `empty` |
| `preorder` | 前序走訪 | 空白分隔；空樹輸出 `empty` |
| `height` | 樹高（空樹 0，只有根是 1） | 整數 |

**刪除規則（必須照做，否則前序結果會不同）：**

1. 葉節點：直接刪掉。
2. 只有一個小孩：用那個小孩取代自己。
3. 有兩個小孩：把自己的值換成 **右子樹中最小的值**（中序後繼 inorder successor），再到右子樹把那個值刪掉。

## 輸入

第一行 `Q`，接下來 `Q` 行指令。

## 輸出

依照上表。

## 限制

- `1 ≤ Q ≤ 5000`
- `-10^9 ≤ x ≤ 10^9`

## 範例

輸入
```
10
insert 5
insert 3
insert 8
insert 7
insert 9
preorder
delete 5
preorder
inorder
height
```
輸出
```
5 3 8 7 9
7 3 8 9
3 7 8 9
3
```

## 想一想

- 依序插入 `1, 2, 3, ..., n` 會長成什麼形狀？樹高是多少？各操作的複雜度變成多少？
  （這就是為什麼需要 AVL、紅黑樹等「平衡樹」，`std::set` 就是紅黑樹。）
- 刪除 **根節點** 時，你的程式有正確更新 `root` 嗎？
- 用 `Node*&`（指標的參考）寫遞迴刪除，會簡單很多。
