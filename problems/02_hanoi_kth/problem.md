# 02. 河內塔的第 k 步

> 主題：遞迴 / 分治　難度：★★☆　時間限制：1 秒　相關教學：`lessons/02_recursion.md`

## 題目

同第 01 題的河內塔：`n` 個圓盤要用最少步數從 `A` 搬到 `C`（`B` 當暫存）。
最少步數的走法是唯一的。

現在 `n` 可能很大（最多 60），總步數 `2^60 - 1` 根本不可能模擬。
請直接算出 **第 `k` 步** 是哪一步。

## 輸入

第一行一個整數 `T`，代表有 `T` 筆詢問。
接下來 `T` 行，每行兩個整數 `n k`。

## 輸出

對每筆詢問輸出一行：

```
disk d: X -> Y
```

表示第 `k` 步把圓盤 `d` 從柱子 `X` 移到柱子 `Y`。

## 限制

- `1 ≤ T ≤ 10^5`
- `1 ≤ n ≤ 60`
- `1 ≤ k ≤ 2^n - 1`（需要 `long long` 或 `unsigned long long`）

## 範例

輸入
```
3
2 1
2 2
3 4
```
輸出
```
disk 1: A -> B
disk 2: A -> C
disk 3: A -> C
```

## 提示

- `hanoi(n, from, via, to)` 的步驟分三段：前 `2^(n-1) - 1` 步、正中間那 1 步、後 `2^(n-1) - 1` 步。
- `k` 落在哪一段，就只要往那一段遞迴。每次 `n` 減 1，所以只需要 `O(n)`。
- 小心 `1 << 59` 會溢位，要寫 `1LL << 59`。
