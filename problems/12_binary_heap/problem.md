# 12. 二元堆積 (Binary Heap)

> 主題：堆積 / 優先佇列　難度：★★☆　時間限制：1 秒　相關教學：`lessons/07_heap.md`

## 題目

請 **不要使用 `std::priority_queue`、`std::set`、`std::make_heap` 等**，
用陣列自己實作一個 **最小堆積 (min-heap)**：

| 指令 | 輸出 |
|---|---|
| `push x` | 無 |
| `pop` | 輸出被移除的最小值；空的輸出 `empty` |
| `top` | 輸出最小值；空的輸出 `empty` |
| `size` | 輸出元素個數 |

## 輸入

第一行 `Q`，接下來 `Q` 行指令。

## 輸出

依照上表。

## 限制

- `1 ≤ Q ≤ 5×10^5`
- `-10^18 ≤ x ≤ 10^18`（用 `long long`）
- 每個操作 `O(log n)`；每次 `pop` 都掃一遍找最小值會 **TLE**

## 範例

輸入
```
7
push 5
push 2
push 8
top
pop
pop
size
```
輸出
```
2
2
5
1
```

## 提示

- 用 0-based 陣列時：節點 `i` 的父親是 `(i-1)/2`，左右小孩是 `2i+1`、`2i+2`。
- `push`：放到最後，往上 **sift up**。
- `pop`：最後一個搬到根，往下 **sift down**（要和 **比較小的那個小孩** 交換）。
- corner case：只有一個小孩的節點（左小孩存在、右小孩不存在）。
