# 03. 自己做一個 vector（動態陣列）

> 主題：動態陣列　難度：★☆☆　時間限制：2 秒　相關教學：`lessons/03_dynamic_array.md`

## 題目

請 **不要使用 `std::vector`**，用 `new[] / delete[]` 自己實作一個動態陣列 `MyVector`，支援以下操作：

| 指令 | 說明 | 輸出 |
|---|---|---|
| `push x` | 在尾端加入 `x` | 無 |
| `pop` | 刪除尾端元素 | 若是空的輸出 `error` |
| `get i` | 輸出第 `i` 個元素（從 0 開始） | 元素值；越界輸出 `error` |
| `set i x` | 把第 `i` 個元素改成 `x` | 越界輸出 `error`，否則無 |
| `size` | 輸出元素個數 | 整數 |
| `capacity` | 輸出目前容量 | 整數 |

**容量規則（必須完全照做）：**
- 一開始容量是 `0`。
- `push` 時如果 `size == capacity`，容量變成 `max(1, capacity * 2)`，並把舊資料搬到新空間。
- `pop` **不會** 縮小容量。

## 輸入

第一行一個整數 `Q`，接下來 `Q` 行每行一個指令。

## 輸出

依照上表輸出，每個輸出佔一行。

## 限制

- `1 ≤ Q ≤ 2×10^5`
- `-10^9 ≤ x ≤ 10^9`，`i` 可能是任意 `int`（**包含負數**）

## 範例

輸入
```
9
capacity
push 5
push 7
push 9
capacity
get 2
get 3
pop
size
```
輸出
```
0
4
9
error
2
```

## 想一想

- 為什麼容量要 **加倍** 而不是每次 +1？`Q` 次 push 的總搬移次數分別是多少？（攤銷分析 amortized analysis）
- `get -1` 會發生什麼事？用 `size_t` 存索引的話要特別小心。
