# 05. 括號配對 (Valid Brackets)

> 主題：堆疊 Stack　難度：★☆☆　時間限制：1 秒　相關教學：`lessons/05_stack_queue.md`

## 題目

給你一個只由 `()[]{}` 組成的字串，判斷括號是否 **正確配對**：

1. 每個左括號都要有同種類的右括號關閉。
2. 關閉的順序要正確：`([)]` 是錯的，`([])` 是對的。

## 輸入

第一行整數 `T`，接下來 `T` 行，每行一個字串 `s`。

## 輸出

每個字串輸出 `YES` 或 `NO`。

## 限制

- `1 ≤ T ≤ 1000`
- `1 ≤ |s| ≤ 10^5`，所有字串總長度 `≤ 10^6`

## 範例

輸入
```
5
()
([]{})
([)]
((
)(
```
輸出
```
YES
YES
NO
NO
NO
```
