# 15. 迷宮最短路徑 (BFS)

> 主題：圖 / 廣度優先搜尋　難度：★★☆　時間限制：2 秒　相關教學：`lessons/09_graph.md`

## 題目

給一個 `R × C` 的迷宮：

- `.` 是空地，`#` 是牆
- `S` 是起點，`T` 是終點（都恰好出現一次，而且是空地）

每一步可以往 **上下左右** 走一格，不能走出邊界、不能穿牆。
請輸出從 `S` 到 `T` 的 **最少步數**；走不到就輸出 `-1`。

## 輸入

第一行 `R C`，接下來 `R` 行，每行一個長度 `C` 的字串。

## 輸出

一個整數。

## 限制

- `1 ≤ R, C ≤ 1000`，`R × C ≥ 2`

## 範例

輸入
```
3 4
S.#.
.##T
....
```
輸出
```
6
```

## 提示

- BFS 第一次走到某個格子時的步數，就是到它的最短距離（每一步代價都是 1）。
- 用 `dist[r][c] = -1` 表示還沒走過。
- **為什麼不用 DFS？** DFS 找到的不一定最短；而且在 `1000×1000` 的蛇形迷宮裡，遞迴深度可達 `5×10^5`，
  會 **stack overflow（RE）**。
- corner case：起點被牆包圍、`1 × 2` 的迷宮、走不到。
