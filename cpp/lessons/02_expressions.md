# 第一部分：運算式是什麼

## 1.1 運算式 (Expression)

**是什麼**：由 **運算元 (operand)** 和 **運算子 (operator)** 組成、**會算出一個值** 的程式片段。

- **運算元**：被運算的東西 —— 變數、字面值、函式呼叫的結果。
- **運算子**：運算的符號 —— `+`、`*`、`=`、`<<`、`&&`、`[]`、`()`……

| 運算式 | 運算元 | 運算子 | 算出的值 |
|---|---|---|---|
| `3 + 4` | `3`、`4` | `+` | `7` |
| `x * 2` | `x`、`2` | `*` | `x` 的兩倍 |
| `max(a, b)` | `a`、`b` | 函式呼叫 `()` | `max` 的回傳值 |
| `v[2]` | `v`、`2` | 下標 `[]` | `v` 的第 3 個元素 |
| `x = 5` | `x`、`5` | `=` | **`x` 本身**（賦值也是運算式！） |
| `cout << "hi"` | `cout`、`"hi"` | `<<` | **`cout` 本身** |

最後兩列很重要：

```cpp
int a, b, c;
a = b = c = 7;              // c = 7 的值是 c，再 b = c，再 a = b
cout << a << b << c << '\n';   // 輸出：777

cout << "x" << "y" << '\n'; // (cout << "x") 的值是 cout，所以可以繼續 << "y"
                            // 輸出：xy

int x;
if ((x = 3) > 2) cout << "yes\n";   // 賦值的值是 x（也就是 3），再和 2 比較
                                    // 輸出：yes
```

運算式加上分號 `;` 就變成 **運算式敘述**（第 03 課）。

## 1.2 副作用 (Side Effect)

**是什麼**：運算式除了算出一個值以外，**還改變了外面的狀態** —— 修改變數、輸出到螢幕、讀檔……

| 運算式 | 算出的值 | 有副作用嗎？ |
|---|---|---|
| `x + 1` | `x + 1` | ❌ 沒有：`x` 沒變 |
| `x++` | `x` 的舊值 | ✅ `x` 被加 1 |
| `x = 5` | `x` | ✅ `x` 被改成 5 |
| `cout << x` | `cout` | ✅ 螢幕上多了東西 |
| `v.push_back(1)` | 無（`void`） | ✅ `v` 多了一個元素 |
| `v.size()` | 元素個數 | ❌ 沒有 |

```cpp
int x = 10;
x + 1;                   // 算出 11，然後丟掉了。什麼都沒改變（-Wall 會警告：statement has no effect）
cout << x << '\n';       // 輸出：10
x++;                     // 副作用：x 變成 11
cout << x << '\n';       // 輸出：11
```

**比喻**：問路是「沒有副作用」的（對方告訴你答案，世界沒有任何改變）；請人幫你搬家是「有副作用」的（東西的位置真的變了）。

**為什麼要分辨？** 第三部分會看到：**同一個運算式裡有好幾個副作用時，結果可能無法預測**。

## 1.3 左值與右值 (Lvalue / Rvalue)

**是什麼**：每個運算式除了「型別」之外，還有一個「**值類別 (value category)**」：

- **左值 (lvalue)**：代表一個 **有固定位置、會持續存在** 的物件。可以取位址 `&`，可以放在 `=` 的左邊（除非是 const）。
- **右值 (rvalue)**：**暫時的值**，用完就消失。不能取位址，不能被賦值。

名稱的由來：左值「可以出現在 `=` 左邊」，右值「只能出現在 `=` 右邊」。

**比喻**：左值是「有門牌號碼的房子」，你可以去那裡放東西、改裝；右值是「計算紙上的中間結果」，算完就丟掉了，你沒辦法「把東西存進計算紙上的一個數字裡」。

每一種運算式的範例：

| 運算式 | 類別 | 原因 |
|---|---|---|
| 變數名稱 `x` | 左值 | 有名字、有固定位置 |
| `++x`（前置） | **左值** | 回傳 `x` 本身 |
| `x++`（後置） | **右值** | 回傳「舊值的複製品」 |
| `*p` | 左值 | 就是 `p` 指向的那個物件 |
| `a[i]`、`v[i]` | 左值 | 就是那個元素 |
| `x = 5` | 左值 | 回傳 `x` 本身 |
| `x + 1`、`x * 2` | 右值 | 計算出來的暫時值 |
| `42`、`3.14`、`true` | 右值 | 字面值 |
| `f()`（回傳 `int`） | 右值 | 回傳值的暫時複製品 |
| `g()`（回傳 `int&`） | 左值 | 回傳的是參考 |
| `"hello"` | 左值（特例） | 字串字面值存在靜態區，有固定位置 |

```cpp
int x = 5;
int arr[3] = {0, 0, 0};
int* p = &x;

x = 10;                // ✅ x 是左值
++x = 20;              // ✅ ++x 是左值（就是 x），x 變成 20
*p = 30;               // ✅ *p 是左值，x 變成 30
arr[1] = 40;           // ✅
cout << x << ' ' << arr[1] << '\n';   // 輸出：30 40

// 10 = x;             // ❌ error: lvalue required as left operand of assignment
// (x + 1) = 3;        // ❌ x + 1 是暫時的值
// x++ = 5;            // ❌ x++ 是右值
// int* q = &(x + 1);  // ❌ error: lvalue required as unary '&' operand
int* r = &(++x);       // ✅ ++x 是左值，可以取位址
```

函式回傳參考時是左值：

```cpp
int value = 1;
int  get_copy() { return value; }       // 回傳 int：右值
int& get_ref()  { return value; }       // 回傳 int&：左值

// get_copy() = 5;     // ❌ 不能賦值給暫時的值
get_ref() = 5;         // ✅ 直接修改 value
cout << value << '\n'; // 輸出：5
```

`vector` 的 `v[i] = 5` 能成立，就是因為 `operator[]` 回傳的是 **參考**（左值）。

🔍 C++11 之後更細分成 lvalue、xvalue、prvalue 三類，這是 **移動語意** 的基礎（第 06 課）。目前記住「**有名字、能取位址的是左值**」就夠了。

## 1.4 前置 vs 後置遞增 (Prefix vs Postfix)

**是什麼**：
- **前置 `++i`**：先把 `i` 加 1，**再** 使用 `i`（新值）。
- **後置 `i++`**：先使用 `i` 的 **舊值**，然後才把 `i` 加 1。

單獨一行時兩者效果一樣；**放在更大的運算式裡時才有差別**：

```cpp
int i = 5;
int a = ++i;       // i 先變成 6，a 拿到 6
cout << i << ' ' << a << '\n';   // 輸出：6 6

int j = 5;
int b = j++;       // b 拿到舊值 5，然後 j 變成 6
cout << j << ' ' << b << '\n';   // 輸出：6 5

int k = 5;
k++;               // 單獨一行：和 ++k 效果一樣
++k;
cout << k << '\n';               // 輸出：7

int arr[] = {10, 20, 30};
int idx = 0;
cout << arr[idx++] << '\n';      // 用 idx = 0 取值，之後 idx 變成 1  → 輸出：10
cout << arr[++idx] << '\n';      // idx 先變成 2，再取值            → 輸出：30
```

`--` 的規則完全一樣。

**比喻**：`++i` 是「先吃藥再上班」—— 上班時已經吃了藥；`i++` 是「先上班，下班後再吃藥」—— 上班時的狀態是吃藥前的。

🔍 **效能**：`i++` 必須先 **複製一份舊值** 才能回傳。對 `int` 編譯器會最佳化掉，沒有差別；但對迭代器或大型物件，`++it` 比 `it++` 有效率。**沒有特別理由時，習慣寫 `++i`**。

# 第二部分：優先順序與結合性

## 2.1 優先順序 (Precedence)

**是什麼**：一個運算式有好幾個運算子時，**哪個運算子先和旁邊的運算元綁在一起**。優先順序高的先綁。

**比喻**：數學的「先乘除後加減」。編譯器看到 `1 + 2 * 3`，會在心裡自動加上括號變成 `1 + (2 * 3)`。

```cpp
cout << 1 + 2 * 3 << '\n';       // * 比 + 優先 → 1 + (2 * 3) → 輸出：7
cout << (1 + 2) * 3 << '\n';     // 括號強制先算加法 → 輸出：9
cout << 10 - 2 * 3 + 1 << '\n';  // (10 - (2 * 3)) + 1 → 輸出：5
cout << 2 + 3 > 4 << '\n';       // ❌ 編譯錯誤！<< 比 > 優先，變成 (cout << 2 + 3) > (4 << '\n')
cout << (2 + 3 > 4) << '\n';     // ✅ 輸出：1
```

## 2.2 結合性 (Associativity)

**是什麼**：**優先順序相同** 的運算子連在一起時，從哪一邊開始綁。

- **左結合**：從左邊開始。大部分的二元運算子（`+ - * / % << >> < == & && ||`）都是。
- **右結合**：從右邊開始。賦值（`= += -=` ……）、一元運算子（`- ! ~ * &` ……）、條件運算子 `?:` 是右結合。

**左結合的例子**：

```cpp
cout << 10 - 4 - 3 << '\n';      // (10 - 4) - 3 = 3，不是 10 - (4 - 3) = 9 → 輸出：3
cout << 100 / 10 / 5 << '\n';    // (100 / 10) / 5 = 2，不是 100 / (10 / 5) = 50 → 輸出：2
cout << 2 * 3 % 4 << '\n';       // * 和 % 同等級：(2 * 3) % 4 = 2 → 輸出：2
cout << 7 % 4 * 3 << '\n';       // (7 % 4) * 3 = 9 → 輸出：9
```

**右結合的例子**：

```cpp
int a, b, c;
a = b = c = 1;                   // a = (b = (c = 1))：先 c = 1，再 b = c，再 a = b
cout << a + b + c << '\n';       // 輸出：3

int x = 5;
cout << - -x << '\n';            // -(-x)：輸出：5
cout << !!x << '\n';             // !(!x)：把任何非 0 值變成 1 → 輸出：1

int score = 85;
const char* g = score >= 90 ? "A" : score >= 80 ? "B" : "C";   // score >= 90 ? "A" : (score >= 80 ? "B" : "C")
cout << g << '\n';               // 輸出：B
```

## 2.3 優先順序表（由高到低）

| 等級 | 運算子 | 名稱 | 結合性 | 範例 → 編譯器的理解 |
|---|---|---|---|---|
| 1 | `a++` `a--` `f()` `a[i]` `.` `->` | 後置、呼叫、下標、成員 | 左 | `*p++` 的 `++` 先綁 → `*(p++)` |
| 2 | `++a` `--a` `+a` `-a` `!` `~` `*p` `&x` `(type)` `sizeof` `new` `delete` | 一元運算子 | **右** | `-x * y` → `(-x) * y` |
| 3 | `*` `/` `%` | 乘除 | 左 | `a + b * c` → `a + (b * c)` |
| 4 | `+` `-` | 加減 | 左 | `a << b + c` → `a << (b + c)` |
| 5 | `<<` `>>` | 移位 | 左 | `a < b << 1` → `a < (b << 1)` |
| 6 | `<` `<=` `>` `>=` | 比較 | 左 | `a == b < c` → `a == (b < c)` |
| 7 | `==` `!=` | 相等 | 左 | `a & b == c` → `a & (b == c)` |
| 8 | `&` | 位元 AND | 左 | `a ^ b & c` → `a ^ (b & c)` |
| 9 | `^` | 位元 XOR | 左 | `a | b ^ c` → `a | (b ^ c)` |
| 10 | `|` | 位元 OR | 左 | `a && b | c` → `a && (b | c)` |
| 11 | `&&` | 邏輯 AND | 左 | `a || b && c` → `a || (b && c)` |
| 12 | `||` | 邏輯 OR | 左 | |
| 13 | `?:` `=` `+=` `-=` `*=` …… `throw` | 條件、賦值 | **右** | `x = a > b ? a : b` → `x = ((a > b) ? a : b)` |
| 14 | `,` | 逗號 | 左 | |

**記憶口訣**：**一元 > 乘除 > 加減 > 移位 > 比較 > 相等 > 位元（& ^ |）> 邏輯（&& ||）> 賦值 > 逗號**。

用程式驗證表格中的幾列：

```cpp
int a = 2, b = 3, c = 4;
cout << (-a * b) << '\n';           // (-2) * 3 → 輸出：-6
cout << (a + b * c) << '\n';        // 2 + 12 → 輸出：14
cout << (1 << a + b) << '\n';       // 1 << 5 → 輸出：32
cout << (a == b < c) << '\n';       // 2 == (3 < 4) → 2 == 1 → 輸出：0
cout << (6 & 3 == 3) << '\n';       // 6 & (3 == 3) → 6 & 1 → 輸出：0
cout << (1 || 0 && 0) << '\n';      // 1 || (0 && 0) → 輸出：1
```

## 2.4 經典的優先順序陷阱

**每一個陷阱都是「位元運算 / 移位 / 比較」和其他運算子混用時發生的**。逐一示範：

**陷阱 1：`x & 1 == 0`（想判斷偶數）**

```cpp
int x = 4;
cout << (x & 1 == 0) << '\n';      // 實際：x & (1 == 0) = 4 & 0 = 0 → 輸出：0（4 明明是偶數！）
cout << ((x & 1) == 0) << '\n';    // 正確 → 輸出：1
```

**陷阱 2：`1 << 2 + 3`（想算 4 + 3）**

```cpp
cout << (1 << 2 + 3) << '\n';      // 實際：1 << (2 + 3) = 32 → 輸出：32
cout << ((1 << 2) + 3) << '\n';    // 正確 → 輸出：7
```

**陷阱 3：`*p++`（想把 p 指向的值加 1）**

```cpp
int arr[] = {10, 20};
int* p = arr;
*p++;                              // 實際：*(p++)：p 往後移一格，值沒變（-Wall 會警告 value computed is not used）
cout << arr[0] << ' ' << *p << '\n';   // 輸出：10 20（arr[0] 沒變，p 指向 arr[1]）

p = arr;
(*p)++;                            // 正確：值加 1
cout << arr[0] << '\n';            // 輸出：11
```

**陷阱 4：`!a == b`（想判斷 a 不等於 b）**

```cpp
int a = 5, b = 3;
cout << (!a == b) << '\n';         // 實際：(!a) == b = 0 == 3 → 輸出：0（a 明明不等於 b）
cout << (a != b) << '\n';          // 正確 → 輸出：1
```

**陷阱 5：`cout << a & b`（想印出 a & b）**

```cpp
// cout << 6 & 3;                  // ❌ 編譯錯誤：(cout << 6) & 3，ostream 不能和 int 做 &
cout << (6 & 3) << '\n';           // 正確 → 輸出：2
```

**陷阱 6：`cout << x > 0 ? ... : ...`（想印出正負號）**

```cpp
int x = -5;
// cout << x > 0 ? "+" : "-";      // ❌ 編譯錯誤：(cout << x) > 0 ? ...
cout << (x > 0 ? "+" : "-") << '\n';   // 正確 → 輸出：-
```

**陷阱 7：`a < b < c`（想判斷 b 在 a 和 c 之間）**

```cpp
int a = 5, b = 1, c = 3;
cout << (a < b < c) << '\n';       // 實際：(5 < 1) < 3 = 0 < 3 = 1 → 輸出：1（錯！b 不在 5 和 3 之間）
cout << (a < b && b < c) << '\n';  // 正確 → 輸出：0
```

**陷阱 8：`a | b == c`、`a ^ b > 0`**

```cpp
int flags = 4, mask = 4;
cout << (flags & mask != 0) << '\n';     // 實際：flags & (mask != 0) = 4 & 1 = 0 → 輸出：0
cout << ((flags & mask) != 0) << '\n';   // 正確 → 輸出：1
```

**黃金規則**：**位元運算、移位、條件運算子，和其他運算子混用時，一律加括號**。括號不會讓程式變慢，只會讓程式更清楚。

### 🔍 C01 題的遞迴下降法

`C01` 要你自己寫一個運算式計算器。遞迴下降法的結構，剛好 **對應優先順序表**：

```
expr   = term   { ('+' | '-') term }           ← 優先順序低
term   = unary  { ('*' | '/' | '%') unary }
unary  = '-' unary | primary                   ← 右結合：自己呼叫自己
primary = 數字 | '(' expr ')'                   ← 優先順序最高
```

- 優先順序低的函式呼叫優先順序高的函式 → 高的先被算出來（先綁定）。
- `while` 迴圈一直往右吃同等級的運算子，每吃一個就馬上合併 → 左結合。
- `unary` 呼叫自己 → 右結合。

以 `2 + 3 * 4` 為例：`expr` 先呼叫 `term` 拿到 `2`；看到 `+`，再呼叫 `term`，這個 `term` 拿到 `3`、看到 `*`、再拿到 `4`，算出 `12` 才回傳；最後 `expr` 算出 `2 + 12 = 14`。

# 第三部分：求值順序

## 3.1 優先順序 ≠ 求值順序 (Evaluation Order)

**是什麼**：
- **優先順序** 決定「**怎麼加括號**」（結構）。
- **求值順序** 決定「**哪個運算元先被計算**」（時間）。

這是兩件 **完全不同** 的事。C++ 對很多運算子 **沒有規定** 求值順序。

```cpp
int f() { cout << "f "; return 1; }
int g() { cout << "g "; return 2; }
int h() { cout << "h "; return 3; }

int r = f() + g() * h();
// 優先順序（結構）是確定的：f() + (g() * h())，結果一定是 1 + 6 = 7
// 但 f、g、h 被呼叫的順序沒有規定：可能印出 "f g h"、"g h f"、"h g f" ……
```

GCC 在這台電腦上印出 `f g h`，但 **換一個編譯器、換一個最佳化選項，就可能不一樣**。這叫 **未指定行為 (unspecified behavior)**：結果是幾種可能之一，但標準不規定是哪一種，編譯器也不用告訴你。

**比喻**：食譜寫「蛋糕 = 麵粉 + 蛋 × 2」，規定了配方的 **結構**，但沒有規定你要先去拿麵粉還是先去拿蛋。只要拿的東西沒有互相影響，順序就不重要；但如果「拿蛋」這個動作會改變「麵粉」的量（副作用），結果就會因順序而不同。

**實務規則**：**不要寫「結果取決於求值順序」的程式碼**。如果 `f`、`g` 有副作用而且互相影響，拆成好幾行：

```cpp
int a = f();
int b = g();
int r = a + b;     // 順序明確
```

## 3.2 未定義行為：同一個變數在同一個運算式裡被改兩次

**規則**：如果一個運算式裡，**同一個變數被修改兩次**，或是 **一邊修改、一邊在另一個沒有先後關係的地方讀取**，就是 **未定義行為 (Undefined Behavior, UB)**。

| 寫法 | 問題 | 結果 |
|---|---|---|
| `i++ + i++` | `i` 被改兩次 | ❌ UB |
| `i + i++` | 左邊讀 `i`、右邊改 `i`，沒有先後 | ❌ UB |
| `a[i] = i++`（C++17 前） | 一邊用 `i` 當索引、一邊改 `i` | ❌ UB（C++17 起有定義） |
| `f(i++, i++)` | 兩個參數都改 `i` | C++17 前 UB；C++17 起是未指定順序 |
| `i = i + 1` | 讀了再寫，有明確的先後 | ✅ 安全 |
| `j = i++ + 1` | `i` 只被改一次 | ✅ 安全 |

```cpp
int i = 1;
int a = i++ + i++;      // ❌ UB：GCC 可能算出 3，Clang 可能算出 3 或其他值，而且會警告
int b = i + i++;        // ❌ UB
```

**未定義行為 (UB)** 比「未指定」更嚴重：
- 未指定：結果是幾種 **合理的可能** 之一。
- 未定義：標準 **完全不管**，編譯器可以假設它 **永遠不會發生**，於是產生的程式 **可能做出任何事** —— 算出奇怪的值、跳過某些程式碼、當掉，或者「看起來正常」。

GCC 加上 `-Wall` 會對這類寫法警告：`operation on 'i' may be undefined`。

**規則**：**在一個運算式裡，同一個變數最多修改一次；如果修改了，就不要在同一個運算式的其他地方再讀它。**

## 3.3 C++17 新增的順序保證

C++17 規定了一些常見寫法的求值順序，讓它們變成安全的：

| 寫法 | C++17 的保證 |
|---|---|
| `a << b << c`（包括 `cout` 串接） | 由左到右 |
| `a >> b >> c`（包括 `cin` 串接） | 由左到右 |
| `a = b`（包括 `+=` `-=` 等） | **右邊** 先算完（包括副作用），再處理左邊 |
| `a[b]` | `a` 先算，再算 `b` |
| `a.b`、`a->b` | `a` 先算 |
| `a && b`、`a || b`、`a , b` | `a` 先算（這個一直都有保證） |
| `a ? b : c` | `a` 先算（一直都有保證） |

每一列的範例：

```cpp
int i = 0;
cout << i++ << ' ' << i++ << ' ' << i++ << '\n';   // C++17：由左到右 → 輸出：0 1 2
                                                   // （C++14 以前：未指定，可能印出 2 1 0）

int arr[5] = {0};
int k = 1;
arr[k] = k++;            // C++17：右邊先算（k++ 回傳 1，k 變成 2），再算左邊 arr[2]
cout << arr[1] << arr[2] << '\n';   // 輸出：01（arr[2] 被設成 1）

int x = 5;
x += x++;                // C++17：右邊先算（得到 5，x 變成 6），再算 x += 5 → x = 11
cout << x << '\n';       // 輸出：11（C++14 以前：UB）
```

> 雖然 C++17 讓這些寫法有了定義，**實務上還是不要這樣寫** —— 讀程式的人很難一眼看出結果，而且舊的編譯器結果不同。

**仍然沒有規定順序的**：`f() + g()`、`f() * g()`、函式的多個參數 `h(f(), g())` 之間。

## 3.4 什麼時候「一定已經完成」

這些位置之前的所有副作用，保證已經完成：

- 每個 **完整運算式** 的結尾（例如分號 `;`）。
- `&&`、`||`、`?:`、逗號運算子 `,` 的 **左邊** 算完之後，才開始算右邊。
- 呼叫函式 **之前**，所有參數都已經算好（但參數之間的順序不確定）。

```cpp
int i = 0;
bool ok = (i++ > 0) || (i > 0);   // 左邊算完（i 變成 1）才算右邊 → 右邊 i > 0 是 true
cout << ok << ' ' << i << '\n';   // 輸出：1 1
```

# 第四部分：算術的細節

## 4.1 整數除法與取餘數

**規則**（C++11 起）：
- `/`：整數除法 **向 0 取整**（直接丟掉小數部分）。
- `%`：餘數的 **正負號跟被除數（左邊）一樣**。
- 永遠成立：`(a / b) * b + a % b == a`。

| 運算 | 結果 | 驗證 `(a/b)*b + a%b` |
|---|---|---|
| `7 / 2`、`7 % 2` | `3`、`1` | `3*2 + 1 = 7` ✓ |
| `-7 / 2`、`-7 % 2` | `-3`、`-1` | `-3*2 + -1 = -7` ✓ |
| `7 / -2`、`7 % -2` | `-3`、`1` | `-3*-2 + 1 = 7` ✓ |
| `-7 / -2`、`-7 % -2` | `3`、`-1` | `3*-2 + -1 = -7` ✓ |

```cpp
cout << 7 / 2 << ' ' << 7 % 2 << '\n';       // 輸出：3 1
cout << -7 / 2 << ' ' << -7 % 2 << '\n';     // 輸出：-3 -1
cout << 7 / -2 << ' ' << 7 % -2 << '\n';     // 輸出：-3 1
cout << -7 / -2 << ' ' << -7 % -2 << '\n';   // 輸出：3 -1
```

**和其他語言比較**：

| 語言 | `-7 / 2` | `-7 % 2` |
|---|---|---|
| C++、Java、C#、JavaScript | `-3`（向 0） | `-1` |
| Python | `-4`（向下取整） | `1` |

**常見需求：一定要非負的餘數**（例如雜湊的桶子編號、星期幾的計算）：

```cpp
int a = -7, m = 3;
cout << a % m << '\n';                 // 輸出：-1（C++ 的結果）
cout << ((a % m) + m) % m << '\n';     // 輸出：2（數學上的餘數）
```

**判斷奇數的陷阱**：

```cpp
int n = -3;
if (n % 2 == 1) cout << "odd\n";       // ❌ -3 % 2 是 -1，不是 1，所以不會印
if (n % 2 != 0) cout << "odd\n";       // ✅ 輸出：odd
```

**除以 0**：整數除以 0、`% 0` 都是 **未定義行為**。在 x86 電腦上通常程式直接當掉（訊號 SIGFPE，評測結果是 RE）。

## 4.2 整數溢位 (Integer Overflow)

**是什麼**：運算結果超出型別能表示的範圍。

| | 有號 (`int`、`long long`) | 無號 (`unsigned`、`size_t`) |
|---|---|---|
| 超出範圍時 | **未定義行為** | **有定義**：自動對 `2ⁿ` 取模（繞回） |

**無號數：繞回（有定義）**

```cpp
unsigned int u = 0;
u = u - 1;
cout << u << '\n';                  // 輸出：4294967295（2³² − 1）
unsigned int big = 4294967295u;
big = big + 1;
cout << big << '\n';                // 輸出：0
```

**比喻**：汽車的里程表只有 6 位數，999999 再走 1 公里就變回 000000 —— 這是無號數的行為，規則很清楚。

**有號數：未定義行為**

```cpp
int x = INT_MAX;                    // 2147483647
// x = x + 1;                       // ❌ UB！不保證會變成 INT_MIN（-2147483648）
long long y = 2000000000LL * 5;     // ✅ 用 long long 計算就不會溢位
```

🔍 **為什麼有號溢位是 UB 這麼重要？** 編譯器會 **假設它永遠不會發生**，然後依此做最佳化：

```cpp
bool check(int x) { return x + 1 > x; }
// 數學上 x + 1 永遠 > x，而且編譯器假設不會溢位
// → GCC -O2 會直接把整個函式最佳化成 return true;
// 就算你傳入 INT_MAX，結果也是 true（不是你以為的「溢位變成負數所以 false」）
```

所以「**先算，再檢查有沒有溢位**」的寫法是錯的（`C13` 題的陷阱）。要在算之前檢查：

```cpp
long long a = LLONG_MAX - 5, b = 10;
// 方法 1：數學判斷
if ((b > 0 && a > LLONG_MAX - b) || (b < 0 && a < LLONG_MIN - b)) cout << "會溢位\n";
// 方法 2：GCC / Clang 的內建函式
long long r;
if (__builtin_add_overflow(a, b, &r)) cout << "會溢位\n";
else cout << r << '\n';
// 輸出：
// 會溢位
// 會溢位
```

**特殊情況**：`LLONG_MIN / -1` 的結果是 `2⁶³`，超出範圍 → 溢位。`LLONG_MIN % -1` 在數學上是 0，但在 x86 上計算時 CPU 會當掉。

## 4.3 浮點數誤差 (Floating-point Error)

**是什麼**：`double` 用 **二進位** 存小數，很多十進位小數（0.1、0.2、0.3……）**無法精確表示**，只能存一個非常接近的值。

**比喻**：用十進位寫 1/3 = 0.3333...，永遠寫不完，只能寫到某一位就停下來。二進位寫 0.1 也是同樣的情況：0.0001100110011...

```cpp
cout << (0.1 + 0.2 == 0.3) << '\n';                      // 輸出：0（false！）
cout << setprecision(17) << 0.1 + 0.2 << '\n';            // 輸出：0.30000000000000004
cout << setprecision(17) << 0.3 << '\n';                  // 輸出：0.29999999999999999
```

**比較浮點數要用誤差範圍 (epsilon)**：

```cpp
double a = 0.1 + 0.2, b = 0.3;
const double EPS = 1e-9;
cout << (fabs(a - b) < EPS) << '\n';                     // 輸出：1
```

**誤差會累積**：

```cpp
double sum = 0;
for (int i = 0; i < 10; i++) sum += 0.1;
cout << (sum == 1.0) << ' ' << setprecision(17) << sum << '\n';
// 輸出：0 0.99999999999999989
```

**其他規則**：

| 情況 | 結果 | 範例 |
|---|---|---|
| `double` 的精度 | 約 15~16 位有效數字 | `123456789.123456789` 後面幾位會不準 |
| `float` 的精度 | 約 **7 位**，盡量用 `double` | `float f = 16777217;` → 存成 `16777216` |
| 正數 / 0.0 | `inf`（無限大） | `1.0 / 0` → `inf` |
| 0.0 / 0.0 | `nan`（不是數字） | `0.0 / 0` → `nan` |
| `nan` 的比較 | **永遠是 false**，連自己都不等於自己 | `nan == nan` → `false` |
| 大整數轉 `double` | 超過 2⁵³ 會失去精度 | `(double)(1LL << 53) + 1 == (double)(1LL << 53)` |

```cpp
double inf = 1.0 / 0, nan_v = 0.0 / 0;
cout << inf << ' ' << nan_v << ' ' << (nan_v == nan_v) << '\n';   // 輸出：inf -nan 0（Linux 的 glibc 印 -nan，有的系統印 nan）
float f = 16777217;
cout << fixed << setprecision(0) << f << '\n';                    // 輸出：16777216
```

**實務建議**：
- 能用整數就用整數（例如金額用「分」存成 `long long`）。
- 比較浮點數用 `fabs(a - b) < EPS`。
- 輸出時用 `fixed << setprecision(k)` 固定小數位數（第 12 課）。

# 第五部分：邏輯運算與短路

## 5.1 三個邏輯運算子

| 運算子 | 名稱 | 結果為 true 的條件 |
|---|---|---|
| `a && b` | AND（且） | 兩個 **都** 是 true |
| `a || b` | OR（或） | **至少一個** 是 true |
| `!a` | NOT（非） | `a` 是 false |

```cpp
int age = 20;
bool has_id = true;
cout << (age >= 18 && has_id) << '\n';    // 輸出：1
cout << (age < 12 || age > 65) << '\n';   // 輸出：0
cout << !has_id << '\n';                  // 輸出：0
```

## 5.2 短路求值 (Short-circuit Evaluation)

**是什麼**：
- `a && b`：如果 `a` 是 **false**，結果一定是 false → **`b` 根本不會被計算**。
- `a || b`：如果 `a` 是 **true**，結果一定是 true → **`b` 不會被計算**。

**比喻**：「有駕照 **而且** 有車，才能開車出門」—— 如果沒駕照，就不用去車庫看有沒有車了。

用有副作用的函式觀察：

```cpp
bool A() { cout << "A "; return false; }
bool B() { cout << "B "; return true; }

A() && B();  cout << '\n';    // 輸出：A        （A 是 false，B 沒被呼叫）
B() && A();  cout << '\n';    // 輸出：B A
B() || A();  cout << '\n';    // 輸出：B        （B 是 true，A 沒被呼叫）
A() || B();  cout << '\n';    // 輸出：A B
```

**短路不只是效率問題，更是安全問題**。把「保護條件」放在左邊，右邊危險的操作就只會在安全時才執行：

```cpp
// 1. 空指標保護
Node* p = nullptr;
if (p != nullptr && p->val > 0) { }       // p 是空的 → 不會執行 p->val，不會當掉

// 2. 陣列越界保護
vector<int> v = {1, 2, 3};
int i = 5;
if (i < (int)v.size() && v[i] == 2) { }   // i 越界 → 不會讀 v[i]

// 3. 空容器保護
stack<char> st;
if (!st.empty() && st.top() == '(') { }   // 空的 → 不會呼叫 top()

// 4. 除以 0 保護
int n = 0, total = 10;
if (n != 0 && total / n > 2) { }          // n 是 0 → 不會除以 0
```

**順序很重要**：

```cpp
if (v[i] == 2 && i < (int)v.size()) { }   // ❌ 先讀 v[i]，越界時已經出事了，保護條件放錯邊
```

> ⚠️ 位元運算子 `&`、`|` **沒有短路**，兩邊都一定會計算。`if (p != nullptr & p->val > 0)` 一樣會當掉。邏輯判斷一律用 `&&`、`||`。

## 5.3 轉成 bool

在需要 `bool` 的地方（`if`、`while`、`&&`、`||`、`!`），值會自動轉成 bool：**0、0.0、空指標是 false，其他都是 true**。

| 運算式 | 轉成 bool | 意思 |
|---|---|---|
| `if (n)` | `n != 0` | 整數非 0 |
| `if (x)` | `x != 0.0` | 浮點數非 0 |
| `if (p)` | `p != nullptr` | 指標不是空的 |
| `if (cin >> x)` | 讀取是否成功 | 串流狀態正常（第 12 課） |
| `if (!s.empty())` | `empty()` 本身就是 bool | |

```cpp
int n = 5;
int* p = nullptr;
if (n) cout << "n 不是 0\n";              // 輸出：n 不是 0
if (!p) cout << "p 是空的\n";             // 輸出：p 是空的
while (n) n--;                            // 等同於 while (n != 0)
cout << n << '\n';                        // 輸出：0
cout << (bool)-3 << (bool)0 << '\n';      // 輸出：10（負數也是 true）
```

## 5.4 條件運算子 (Conditional / Ternary Operator)

**是什麼**：`條件 ? 甲 : 乙` —— 條件成立時值是「甲」，否則是「乙」。是 C++ **唯一** 的三元運算子（有三個運算元）。

```cpp
int a = 7, b = 3;
int mx = (a > b) ? a : b;                     // 輸出：7
cout << mx << '\n';
cout << (a % 2 == 0 ? "even" : "odd") << '\n'; // 輸出：odd
int abs_v = (b - a >= 0) ? b - a : a - b;     // 4
```

**型別規則**：兩個結果的型別會被轉成 **同一種**：

```cpp
auto r = true ? 1 : 2.5;      // 型別是 double，就算選到 1，r 也是 1.0
cout << r << ' ' << sizeof(r) << '\n';   // 輸出：1 8
```

**可讀性**：只用在簡單的二選一。巢狀太多層（`a ? b : c ? d : e ? ...`）時改用 `if-else`。

# 第六部分：位元運算 (Bitwise Operations)

## 6.1 二進位複習

整數在電腦裡是用 **二進位** 存的。以 8 位元為例：

```
十進位 12 = 0000 1100₂ = 8 + 4
十進位 10 = 0000 1010₂ = 8 + 2
位元編號：   7654 3210   （第 0 位是最右邊、最低位）
```

## 6.2 六個位元運算子

**比喻**：一整排電燈開關，位元運算就是「**一個一個開關分別處理**」的規則。

以 `a = 12 = 1100₂`、`b = 10 = 1010₂` 為例：

| 運算子 | 名稱 | 規則（每一位分別算） | 計算過程 | 結果 |
|---|---|---|---|---|
| `a & b` | AND | 兩個都是 1 才是 1 | `1100 & 1010` | `1000₂` = **8** |
| `a | b` | OR | 有一個是 1 就是 1 | `1100 | 1010` | `1110₂` = **14** |
| `a ^ b` | XOR | 不一樣才是 1 | `1100 ^ 1010` | `0110₂` = **6** |
| `~a` | NOT | 0 變 1、1 變 0 | `~0000…1100` | `1111…0011` = **-13**（有號 int） |
| `a << 2` | 左移 | 全部往左移 2 格，右邊補 0 | `1100 → 110000` | **48** = 12 × 4 |
| `a >> 2` | 右移 | 全部往右移 2 格 | `1100 → 11` | **3** = 12 / 4 |

```cpp
#include <bitset>
int a = 12, b = 10;
cout << (a & b) << ' ' << (a | b) << ' ' << (a ^ b) << '\n';   // 輸出：8 14 6
cout << ~a << '\n';                                             // 輸出：-13
cout << (a << 2) << ' ' << (a >> 2) << '\n';                    // 輸出：48 3
cout << bitset<8>(a & b) << '\n';                               // 輸出：00001000
cout << bitset<8>(a | b) << '\n';                               // 輸出：00001110
cout << bitset<8>(a ^ b) << '\n';                               // 輸出：00000110
```

`bitset<N>(x)` 可以把數字印成二進位，學位元運算時非常好用。

**移位和乘除的關係**：
- `x << k` 等於 `x × 2ᵏ`（不溢位時）。
- 非負數 `x >> k` 等於 `x / 2ᵏ`（向下取整）。

```cpp
cout << (5 << 3) << ' ' << (100 >> 3) << '\n';   // 5 × 8 = 40，100 / 8 = 12 → 輸出：40 12
```

**為什麼 `~12` 是 `-13`？** 有號整數用「二補數」表示，`~x` 永遠等於 `-x - 1`。對無號數做 `~` 比較直觀：`~12u` = `4294967283`。

### XOR 的三個特性

```cpp
int x = 37, k = 99;
cout << (x ^ x) << '\n';          // 自己 XOR 自己是 0         → 輸出：0
cout << (x ^ 0) << '\n';          // XOR 0 不變               → 輸出：37
cout << ((x ^ k) ^ k) << '\n';    // XOR 兩次同一個數會還原     → 輸出：37
```

應用：在一堆數字中，只有一個數出現奇數次，其他都出現偶數次 → 全部 XOR 起來就是答案。

```cpp
vector<int> nums = {4, 7, 4, 9, 7};
int ans = 0;
for (int n : nums) ans ^= n;      // 4 ^ 4 和 7 ^ 7 都消掉了
cout << ans << '\n';              // 輸出：9
```

## 6.3 常用技巧

以 `x = 44 = 101100₂` 為例，每一個技巧的計算過程：

| 目的 | 寫法 | 計算過程 | 結果 |
|---|---|---|---|
| 判斷奇偶 | `x & 1` | `101100 & 000001` | `0` → 偶數 |
| 第 `k` 位是不是 1（k=3） | `(x >> 3) & 1` | `101100 >> 3 = 101`，`& 1` | `1` |
| 把第 `k` 位設成 1（k=0） | `x | (1 << 0)` | `101100 | 000001` | `101101` = 45 |
| 把第 `k` 位設成 0（k=2） | `x & ~(1 << 2)` | `101100 & 111011` | `101000` = 40 |
| 反轉第 `k` 位（k=5） | `x ^ (1 << 5)` | `101100 ^ 100000` | `001100` = 12 |
| 清掉最低的 1 | `x & (x - 1)` | `101100 & 101011` | `101000` = 40 |
| 只留下最低的 1 | `x & -x` | `101100 & …010100` | `000100` = 4 |
| 是不是 2 的次方 | `x && !(x & (x - 1))` | `40 ≠ 0` | false |
| 有幾個 1 | `__builtin_popcount(x)` | 1、1、1 | `3` |

```cpp
int x = 44;
cout << (x & 1) << '\n';                  // 輸出：0
cout << ((x >> 3) & 1) << '\n';           // 輸出：1
cout << (x | (1 << 0)) << '\n';           // 輸出：45
cout << (x & ~(1 << 2)) << '\n';          // 輸出：40
cout << (x ^ (1 << 5)) << '\n';           // 輸出：12
cout << (x & (x - 1)) << '\n';            // 輸出：40
cout << (x & -x) << '\n';                 // 輸出：4
cout << (x && !(x & (x - 1))) << ' ' << (64 && !(64 & 63)) << '\n';   // 輸出：0 1
cout << __builtin_popcount(x) << '\n';    // 輸出：3
```

**為什麼 `x & (x - 1)` 能清掉最低的 1？** `x - 1` 會把最低的那個 1 變成 0，並把它右邊的 0 全部變成 1：

```
x     = 1011 00
x - 1 = 1010 11
AND   = 1010 00   ← 最低的 1 不見了，其他位不變
```

**實用例子：用一個整數表示「集合」**（每一位代表一個東西有沒有被選）：

```cpp
int perms = 0;                      // 權限：第 0 位讀、第 1 位寫、第 2 位執行
const int READ = 1 << 0, WRITE = 1 << 1, EXEC = 1 << 2;
perms |= READ | WRITE;              // 給予讀寫權限
cout << ((perms & WRITE) != 0) << '\n';   // 有寫入權限嗎？輸出：1
perms &= ~WRITE;                    // 拿掉寫入權限
cout << ((perms & WRITE) != 0) << '\n';   // 輸出：0
cout << bitset<3>(perms) << '\n';         // 輸出：001
```

## 6.4 移位的未定義行為

| 寫法 | 問題 | 怎麼避免 |
|---|---|---|
| `1 << 31`（`int` 是 32 位元） | C++20 前是 UB（移進符號位） | 用 `1u << 31` |
| `1 << 32`、`x >> 64` | **移位量 ≥ 型別的位元數**：UB | 先檢查移位量 |
| `x << -1` | 移位量是負數：UB | 先檢查移位量 |
| `1 << 40` | `1` 是 `int`，移 40 位超過 32 位元：UB | 用 `1LL << 40` / `1ULL << 40` |
| `-8 >> 1` | C++20 前由編譯器決定；C++20 起是算術右移（補符號位） | 位元運算一律用無號數 |
| `-1 << 1` | C++20 前是 UB（左移負數） | 用無號數 |

```cpp
cout << (1u << 31) << '\n';               // ✅ 輸出：2147483648
cout << (1LL << 40) << '\n';              // ✅ 輸出：1099511627776
cout << (1ULL << 63) << '\n';             // ✅ 輸出：9223372036854775808
cout << (-8 >> 1) << '\n';                // GCC：輸出 -4（算術右移，保留符號）
unsigned long long u = 12345;
int k = 0;
unsigned long long rot = (k == 0) ? u : (u << k) | (u >> (64 - k));   // ✅ k = 0 時避開 u >> 64
cout << rot << '\n';                      // 輸出：12345
```

**規則**：做位元運算時 **一律用無號型別**，而且常數寫成 `1ULL << k`。`C02` 題的 `rotl x 0` 就是在測「`x >> 64`」這個陷阱。

# 習題解答

**題 1**：
- a) `2 + ((3 * 4) % 5)` = `2 + 2` = **4**
- b) `(10 - 2) - (3 * 2)` = **2**
- c) `1 << (1 + 1)` = **4**
- d) `7 & (3 == 3)` = `7 & 1` = **1**
- e) `((-7 / 2) * 2) + (-7 % 2)` = `(-3 * 2) + (-1)` = **-7**（剛好驗證 `(a/b)*b + a%b == a`）
- f) `(5 > 3) == 1` = `1 == 1` = **1**（`>` 比 `==` 優先）

**題 2**：
- a) 安全。
- b) **C++17 起有定義**（右邊先完全算完，包括 `i++` 的副作用，再賦值），結果是舊的 `i + 1`；C++17 前是 UB。實務上 **不要這樣寫**。
- c) C++17 起有定義（右邊先算）；C++17 前是 UB。同樣不要寫。
- d) **UB**：`y` 在同一個運算式裡被改兩次。
- e) C++17 起有定義（`<<` 由左到右），印出 `i` 再印 `i`（舊值），之後 `i` 加 1。
- f) **未指定**：參數的計算順序不確定，`f` 拿到的第二個參數可能是加之前或加之後的值。

**題 3**：`7 10 14`。`y = 5 * 2 = 10`（之後 x = 6）；`++x` 讓 x 變成 7，`z = 7 * 2 = 14`。

**題 4**：`==` 的優先順序比 `&` 高，變成 `x & (1 == 0)` = `x & 0` = 0，永遠回傳 `false`。改成 `(x & 1) == 0`。

**題 5**：**B** 安全。`&&` 由左到右短路，B 先確認 `i` 沒越界才讀 `v[i]`；A 先讀 `v[i]`，越界時已經出事了。

**題 6**：`0 1`。`0.1 * 3` 是 `0.30000000000000004`，不等於 `0.3`，但差距小於 `1e-9`。

**題 7**：有號整數溢位是 **未定義行為**，`a + b` 一旦溢位，`r < 0` 的檢查不一定有效（編譯器可能把它最佳化掉）；而且只檢查了兩個正數的情況，沒檢查兩個負數相加。要在相加 **之前** 檢查：

```cpp
if ((b > 0 && a > LLONG_MAX - b) || (b < 0 && a < LLONG_MIN - b)) throw overflow_error("overflow");
```

或用 `__builtin_add_overflow(a, b, &r)`。

**題 8**：`x = 1011 0100₂`（180）
- a) 清掉最低的 1：`1011 0000₂` = **176**
- b) 只留最低的 1：`0000 0100₂` = **4**
- c) 反轉第 2 位（原本是 1）：`1011 0000₂` = **176**
- d) 取高 4 位：`1011₂` = **11**

**題 9**：`1 1`。左邊 `i++ == 0` 是 true（`i` 變成 1），`||` 短路，右邊 **不會執行**，所以 `i` 只加了一次。

**題 10**：`-13 % 5 = -3`、`13 % -5 = 3`、`-13 / 5 = -2`（向 0 取整）。數學餘數：`((-13 % 5) + 5) % 5 = 2`。
