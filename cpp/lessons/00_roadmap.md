# 00. C++ 深入：學習路線圖

> 這條路線專門把 **C++ 語言本身** 學扎實。資料結構路線教「資料怎麼放」，這條路線教「C++ 這個工具到底怎麼運作」。

## 為什麼要「深入」學 C++？

很多人會寫 C++，但說不出：
- 為什麼 `i++ + i++` 的結果無法預測？
- 為什麼 `vector` 裡存的指標，`push_back` 之後就不能用了？
- 為什麼基底類別的解構子要加 `virtual`？
- 為什麼 `unique_ptr` 不能複製？為什麼一百萬個節點的串列會在程式 **結束時** 當掉？

這些問題的答案，就是寫出 **正確、安全、快速** 的 C++ 程式的關鍵。這條路線會一個一個講清楚。

## 建議的順序

- **剛學完基本語法**：01 → 02 → 03 → 04 → 05，打好基礎。
- **要寫自己的類別 / 資料結構**：06 → 07 → 08 → 09，這四課是物件導向的核心，也是資料結構路線的「必備工具」。
- **想寫出通用、好維護的程式**：10 → 11 → 12 → 13。
- **想知道整個程式怎麼被組裝起來**：14 → 15。

## 每一課的結構

1. **課程地圖**：這一課分成哪幾部分、讀完會知道什麼。
2. **名詞說明**：英文名稱 → 白話解釋 → 生活比喻 → C++ 範例。
3. **🔍 深入**：標著這個符號的段落，是「底層到底發生什麼事」的說明，第一次讀可以跳過。
4. **名詞總表**。
5. **習題**：預測輸出、找 bug、簡答，附詳解。
6. **程式練習**：可以評測的題目（左邊題目列表的 `C01` ~ `C14`）。

## 怎麼做程式練習？

跟資料結構路線完全一樣：

```bash
python3 judge.py serve          # 網頁版，上方切換到「🔧 C++ 深入」
python3 judge.py start c7       # 命令列：建立 workspace/c07_fraction.cpp
python3 judge.py test c7        # 評測
python3 judge.py test c7 --debug  # 用 sanitizer 抓記憶體錯誤（第 06 課之後非常有用）
```

這裡的題目特別強調 **C++ 本身的陷阱**：溢位、未定義行為、自我指定、記憶體洩漏、解構的遞迴……
測資裡的 `corner_xxx` 名稱就是提示。
