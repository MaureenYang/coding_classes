# 第一部分：指標的本質

## 1.1 位址 (Address)

**白話**：記憶體裡每個 byte 都有一個編號，就是 **位址**。每個變數都住在某個位址上。

**比喻**：一條街上每一間房子都有門牌號碼。

```cpp
int x = 42;
cout << &x;     // 印出 x 的位址，例如 0x7ffd5c3a1b4c
```

## 1.2 指標 (Pointer)

**白話**：一個 **存放位址** 的變數。指標本身也是變數，也有自己的位址。

**比喻**：一張寫著門牌號碼的紙條。紙條不是房子，但照著它可以找到房子。

| 寫法 | 意思 |
|---|---|
| `int* p;` | 宣告 `p` 是「指向 `int` 的指標」 |
| `p = &x;` | `&x`：**取址**，拿到 `x` 的位址 |
| `*p` | **解參考 (dereference)**：照著位址去拿那個 `int` |
| `p->m` | 等於 `(*p).m`，指向物件的成員 |

```cpp
int x = 42;
int* p = &x;
*p = 100;           // 透過指標修改 x
cout << x;          // 100
cout << sizeof(p);  // 8（64 位元系統上，任何型別的指標都是 8 bytes）
```

> **`*` 的兩種意思**：宣告時 `int* p` 的 `*` 表示「這是指標型別」；運算式裡 `*p` 的 `*` 表示「解參考」。
> **宣告陷阱**：`int* a, b;` 只有 `a` 是指標，`b` 是 `int`！要寫成 `int *a, *b;` 或分兩行。

## 1.3 指標的型別

**白話**：指標記得「它指向什麼型別」，這樣解參考時才知道要讀幾個 byte、怎麼解讀。

```cpp
double d = 3.14;
int* p = &d;          // ❌ 編譯錯誤：不能用 int* 指向 double
void* vp = &d;        // ✅ void* 可以指向任何東西，但不能直接解參考
double* dp = static_cast<double*>(vp);   // 要先轉回正確的型別
```

## 1.4 空指標 (Null Pointer)

**白話**：**不指向任何東西** 的指標。C++11 起用 `nullptr`。

```cpp
int* p = nullptr;
if (p) cout << *p;    // 用之前先檢查
*p = 5;               // ❌ 解參考空指標 → 程式當掉（SIGSEGV）
```

`nullptr` vs `NULL` vs `0`：`NULL` 和 `0` 其實是 **整數** 0，在多載時會出問題。`f(int)` 和 `f(int*)` 都存在時，`f(0)` 呼叫的是 `f(int)`；`f(NULL)` 在某些編譯器會呼叫 `f(int)`，在 GCC 則是「模稜兩可」編譯錯誤 —— 都不是你想要的 `f(int*)`。`nullptr` 的型別是專門的 `std::nullptr_t`，只會轉成指標，`f(nullptr)` 一定呼叫 `f(int*)`。**一律用 `nullptr`**。

## 1.5 野指標 (Wild Pointer)

**白話**：**沒有初始化** 的指標，裡面是垃圾值，指向不知道哪裡。

```cpp
int* p;          // 野指標
*p = 5;          // ❌ 寫到隨機的位置：可能當掉、可能默默破壞別的資料
```

**規則**：宣告指標時 **立刻初始化**，不知道要指向哪裡就設成 `nullptr`。

# 第二部分：指標運算與陣列

## 2.1 指標運算 (Pointer Arithmetic)

**白話**：指標加 1，**不是位址加 1**，而是往後移 **一個元素**（`sizeof(T)` 個 byte）。

```cpp
int a[5] = {10, 20, 30, 40, 50};
int* p = a;            // 指向 a[0]，假設位址是 1000
p + 1                  // 位址 1004（int 是 4 bytes），指向 a[1]
*(p + 2)               // 30
p[3]                   // 40（p[i] 就是 *(p + i)）
int* q = &a[4];
q - p                  // 4：兩個指標相減 = 中間差幾個元素（型別 ptrdiff_t）
```

**比喻**：一排同樣大小的置物櫃，「往後一格」就是跳過一整個櫃子的寬度，不管櫃子是寬是窄。

**合法範圍**：指標只能指向陣列裡的元素，或 **最後一個元素的「下一個位置」**（one-past-the-end，`a + 5`）。
`a + 5` 可以拿來比較（迴圈的結束條件），但 **不能解參考**；`a + 6` 連算出來都是未定義行為。
STL 的 `v.end()` 就是這個概念。

## 2.2 陣列退化 (Array-to-pointer Decay)

**白話**：在大部分的運算式裡，**陣列名稱會自動轉成「指向第一個元素的指標」**，而且 **陣列的大小資訊就消失了**。

```cpp
int a[5];
int* p = a;                  // a 退化成 &a[0]
sizeof(a);                   // 20：這裡沒有退化（sizeof 是例外）
sizeof(p);                   // 8

void f(int arr[]) {          // 參數寫 int arr[]，其實就是 int* arr
    sizeof(arr);             // 8！不是陣列大小
}
```

**比喻**：寄包裹時只寫了「第一個箱子的位置」，收件人不知道總共有幾箱。所以傳陣列給函式時，**一定要另外傳長度**（或改用 `vector`、`std::array`、`std::span`）。

🔍 **`a[i]` 的真面目**：`a[i]` 被定義成 `*(a + i)`。因為加法可以交換，`i[a]` 也是合法的（`*(i + a)`）—— 這只是冷知識，千萬不要這樣寫。

## 2.3 C 風格字串

**白話**：以 `'\0'`（值為 0 的字元）結尾的 `char` 陣列。

```cpp
const char* s = "hello";     // 實際佔 6 bytes：h e l l o \0
strlen(s);                   // 5：一個一個數到 '\0'，O(n)
char buf[3];
strcpy(buf, "hello");        // ❌ buf 太小，寫出界（緩衝區溢位 buffer overflow）
```

**字串字面值是唯讀的**：`char* s = "hi"; s[0] = 'H';` 是未定義行為（現代 C++ 連 `char* s = "hi"` 都不允許，要寫 `const char*`）。

C++ 程式請用 `std::string`（第 12 課），它會自己管理長度和記憶體。

# 第三部分：const 與指標

## 3.1 兩個不同的 const

| 寫法 | 名稱 | 能改指向的值 `*p`？ | 能改指標本身 `p`？ |
|---|---|---|---|
| `int* p` | 一般指標 | ✅ | ✅ |
| `const int* p`（= `int const* p`） | **指向常數的指標** (pointer to const) | ❌ | ✅ |
| `int* const p` | **常數指標** (const pointer) | ✅ | ❌ |
| `const int* const p` | 兩個都是常數 | ❌ | ❌ |

**讀法：從變數名稱開始，由右往左讀**。

```
const int* p        →  p 是一個指標，指向 int，那個 int 是 const
int* const p        →  p 是一個 const 的指標，指向 int
```

**比喻**：
- `const int* p`：**唯讀的導覽地圖**。你可以換一張地圖看別的地方（改 `p`），但不能透過地圖去改建房子（改 `*p`）。
- `int* const p`：**焊死在某間房子的鑰匙**。可以進去改裝（改 `*p`），但這把鑰匙永遠只能開這一間（不能改 `p`）。

```cpp
int x = 1, y = 2;
const int* p = &x;
*p = 5;       // ❌
p = &y;       // ✅
int* const q = &x;
*q = 5;       // ✅
q = &y;       // ❌
```

## 3.2 const 正確性 (Const Correctness)

**函式參數** 是 const 最重要的用途：

```cpp
size_t my_strlen(const char* s);    // 承諾：我不會改你的字串
void fill(int* arr, int n, int v);  // 會改：不加 const
```

規則：
- `int*` 可以自動轉成 `const int*`（加上限制，安全）。
- `const int*` **不能** 自動轉成 `int*`（拿掉限制，不安全），要用 `const_cast`，而且如果原本的物件真的是 const，修改它是未定義行為。

# 第四部分：指標的指標與二維陣列

## 4.1 指標的指標 (Pointer to Pointer)

**白話**：指向「**另一個指標**」的指標。

```cpp
int x = 5;
int* p = &x;
int** pp = &p;
**pp = 10;        // x 變成 10
```

**比喻**：一張紙條上寫著「另一張紙條放在哪裡」，那張紙條才寫著房子的地址。

**用途**：
1. 動態二維陣列（下一節）。
2. 函式要 **修改呼叫者的指標**（C 語言風格；C++ 用 `int*&` 更清楚）：

```cpp
void alloc(int** pp) { *pp = new int(42); }
int* p = nullptr;
alloc(&p);        // p 現在指向新配置的 int
```

## 4.2 動態二維陣列（C05 題）

```cpp
long long** a = new long long*[rows];     // ① 一個陣列，存「每一列的指標」
for (int i = 0; i < rows; i++)
    a[i] = new long long[cols]();         // ② 每一列各自配置；() 代表初始化為 0
a[i][j] = 5;                              // a[i] 是第 i 列的指標，[j] 再取第 j 個

for (int i = 0; i < rows; i++) delete[] a[i];   // 釋放：順序相反
delete[] a;
```

```
a ──▶ [ ● ] ──▶ [ 0 0 0 0 ]    ← 每一列在記憶體中可能不相鄰
      [ ● ] ──▶ [ 0 0 0 0 ]
      [ ● ] ──▶ [ 0 0 0 0 ]
```

🔍 **另一種做法：一整塊連續記憶體**，用 `a[i * cols + j]` 存取。只要 `new` 一次、`delete` 一次，而且記憶體連續，對快取比較友善，通常更快。

## 4.3 內建二維陣列的記憶體排列

```cpp
int b[3][4];      // 3 列 4 行
```

在記憶體中是 **一整塊連續的 12 個 int**，**一列接一列** 排（**列優先 row-major**）：

```
b[0][0] b[0][1] b[0][2] b[0][3] b[1][0] b[1][1] ... b[2][3]
```

所以 **外層迴圈跑列、內層迴圈跑行**，存取的記憶體是連續的，比反過來快很多：

```cpp
for (int i = 0; i < R; i++)
    for (int j = 0; j < C; j++) sum += b[i][j];   // ✅ 連續存取
for (int j = 0; j < C; j++)
    for (int i = 0; i < R; i++) sum += b[i][j];   // 跳著存取，大陣列時明顯變慢
```

# 第五部分：參考 (Reference)

## 5.1 參考是別名

**白話**：參考是一個 **已經存在的物件的另一個名字**。對參考做任何事，就是對原本的物件做。

```cpp
int x = 1;
int& r = x;     // r 就是 x
r = 5;          // x 變成 5
cout << (&r == &x);  // 1：位址相同
```

規則：
1. **一定要初始化**：`int& r;` 編譯錯誤。
2. **不能改綁**：`r = y;` 不是讓 `r` 改參考 `y`，而是把 `y` 的值 **指定給 x**。
3. **沒有「空參考」**：參考一定綁著某個物件。

**比喻**：「小明」和他的綽號「阿明」。綽號一旦取了就是指小明，不會變成別人的綽號。

## 5.2 指標 vs 參考

| | 指標 `T*` | 參考 `T&` |
|---|---|---|
| 可以是空的 | ✅ `nullptr` | ❌ |
| 可以改指向別的物件 | ✅ | ❌ |
| 一定要初始化 | 否（但應該要） | 是 |
| 存取語法 | `*p`、`p->m` | 直接用 `r`、`r.m` |
| 指標運算 | ✅ | ❌ |
| 能放進容器 | ✅ `vector<T*>` | ❌（要用 `reference_wrapper`） |

**怎麼選**：能用參考就用參考（比較安全）；需要「可以沒有」、需要改指向、需要指標運算時才用指標。

🔍 **參考在底層通常就是用指標實作的**，只是編譯器幫你自動加上 `*`，並禁止危險的操作。

## 5.3 const 參考可以綁定暫時物件

```cpp
int& r1 = 5;               // ❌ 非 const 參考不能綁定右值
const int& r2 = 5;         // ✅
const string& s = string("hi") + "!";   // ✅ 暫時物件的生命被延長到 s 的作用域結束
```

這就是為什麼 `void f(const string& s)` 可以接受 `f("hello")`：編譯器建立一個暫時的 `string`，綁定到 `s`。

**生命週期延長 (lifetime extension)** 只適用於「直接綁定」的情況；從函式回傳的參考不會延長（第 04 課的懸空參考）。

## 5.4 🔍 右值參考 (Rvalue Reference) 預告

C++11 加入了 `T&&`，**只能綁定右值**（快要消失的暫時物件）。它是 **移動語意** 的基礎：既然這個物件馬上要消失了，就可以直接 **偷走** 它的資源，不用複製。第 06 課詳細說明。

# 第六部分：指標錯誤大全

| 錯誤 | 英文 | 發生原因 | 後果 |
|---|---|---|---|
| 解參考空指標 | Null Dereference | `*p` 但 `p == nullptr` | 當掉 |
| 野指標 | Wild Pointer | 沒初始化的指標 | 隨機破壞記憶體 |
| 懸空指標 | Dangling Pointer | 指向的物件已經 `delete` 或離開作用域 | 讀到垃圾、隨機當掉 |
| 釋放後使用 | Use-after-free | `delete p;` 之後還用 `*p` | 同上 |
| 重複釋放 | Double Free | 同一塊記憶體 `delete` 兩次 | 當掉、堆積損壞 |
| 記憶體洩漏 | Memory Leak | `new` 了沒 `delete`，而且沒有指標指著它了 | 記憶體越用越多 |
| 越界存取 | Out of Bounds | `p[i]` 的 `i` 超出範圍 | 讀到別人的資料、當掉 |
| `new[]` 配 `delete` | Mismatched delete | `new[]` 要配 `delete[]` | 未定義行為 |

```cpp
int* p = new int[10];
int* q = p;           // q 和 p 指向同一塊
delete[] p;
p = nullptr;          // 好習慣，但 q 還是懸空指標！
q[0] = 1;             // ❌ use-after-free
```

**怎麼抓？** 用 `python3 judge.py test <題目> --debug`，AddressSanitizer 會告訴你錯誤的種類和行號。

**怎麼避免？** 第 06 課的 **RAII** 和 **智慧指標**：讓物件自己負責釋放記憶體，就不會忘記、不會重複、不會懸空。

# 習題解答

**題 1**：`20 40 10 2`。`p` 指向 `a[1]`；`*(p+2)` 是 `a[3]`；`p[-1]` 是 `a[0]`（往前一個，合法因為還在陣列內）；`(p + 2) - p` 兩個指標差 2 個元素。

**題 2**：`12 2`。`r = y` **不是改綁**，是把 `y` 的值（2）指定給 `x`；接著 `*p += 10`，`p` 指向 `x`，所以 `x = 12`。`y` 沒變。

**題 3**：① 和 ④。`a` 是指向常數的指標，不能改 `*a`；`b` 是常數指標，不能改 `b` 本身。

**題 4**：`40 8`。`sizeof(a)` 是整個陣列（10 × 4）；函式參數 `int arr[10]` 其實是 `int*`，大小是 8。

**題 5**：
1. `make` 回傳區域變數的位址 → `q` 是 **懸空指標**。
2. `new int[5]` 要用 `delete[]`，不能用 `delete`。
3. `delete` 之後還寫入 `p[0]` → **use-after-free**。

**題 6**：`a` 是 `int*`，`b` 是 **`int`**。`*` 只屬於緊接著的那個變數名稱。

**題 7**：**A 比較快**。二維陣列是 **列優先** 存放，A 依序存取連續的記憶體，CPU 快取能發揮作用；B 每次跳 5000 個 `int`（20 KB），幾乎每次都要重新從主記憶體讀取。實測可能差好幾倍。

**題 8**：參數要能修改 **呼叫者的指標本身**，所以用 **指標的參考** `int*&`（或 C 風格的 `int**`）：

```cpp
void clear_ptr(int*& p) { p = nullptr; }
```
