# C03. 日期計算 (Date Calculator)

> 主題：敘述與控制流程（if / switch / 迴圈）　難度：★★☆　時間限制：1 秒　相關教學：`cpp/lessons/03_statements.md`

## 題目

使用 **公曆（格里曆）**，並假設這套曆法一路往前適用到西元 1 年（proleptic Gregorian calendar）。
西元 `0001-01-01` 是 **星期一**。

**閏年規則**：
- 能被 4 整除的是閏年，
- 但能被 100 整除的 **不是** 閏年，
- 但能被 400 整除的 **又是** 閏年。

例如 `2024`、`2000` 是閏年；`1900`、`2023` 不是。閏年的 2 月有 29 天。

處理以下查詢：

| 查詢 | 輸出 |
|---|---|
| `valid Y M D` | 日期合法輸出 `yes`，否則 `no` |
| `leap Y` | 閏年輸出 `yes`，否則 `no` |
| `weekday Y M D` | 星期幾：`Monday` ~ `Sunday`；日期不合法輸出 `invalid` |
| `diff Y1 M1 D1 Y2 M2 D2` | 第二個日期減第一個日期是幾天（可能是負數）；任一日期不合法輸出 `invalid` |
| `add Y M D N` | 往後加 `N` 天（`N` 可能是負數）的日期，格式 `YYYY-MM-DD`；原日期不合法或結果超出 `0001-01-01 ~ 9999-12-31` 輸出 `invalid` |

## 輸入

第一行 `Q`，接下來 `Q` 行查詢。

## 輸出

每個查詢一行。`add` 的年份補滿 4 位、月日補滿 2 位，例如 `0005-03-01`。

## 限制

- `1 ≤ Q ≤ 10^5`
- 查詢裡的 `Y`、`M`、`D` 是 `-10^4 ~ 10^4` 的整數（**可能不合法**）
- `|N| ≤ 4×10^6`

## 範例

輸入
```
6
leap 1900
valid 2023 2 29
weekday 2024 1 1
diff 2024 1 1 2024 3 1
add 2024 2 28 2
add 2024 1 1 -1
```
輸出
```
no
no
Monday
60
2024-03-01
2023-12-31
```

## 提示

- 寫一個函式把日期轉成「從 `0001-01-01` 開始的第幾天」，`diff`、`weekday`、`add` 都會變得很簡單。
- 每個月的天數可以用陣列，或用 `switch`（注意 `case` 要記得 `break`，或刻意利用 **fall-through**）。
- 合法的日期：`1 ≤ Y ≤ 9999`、`1 ≤ M ≤ 12`、`1 ≤ D ≤ 那個月的天數`。
- 用 `printf("%04d-%02d-%02d\n", ...)` 或 `setw` + `setfill('0')` 補 0。
