# C01. 運算式求值 (Expression Evaluation)

> 主題：運算子優先順序、結合性、整數除法　難度：★★☆　時間限制：1 秒　相關教學：`cpp/lessons/02_expressions.md`

## 題目

給你一些整數運算式，請用 **C++ 的規則** 算出結果（所有數字都是 `long long`）。

運算式可能包含：

| 符號 | 意思 | 優先順序 |
|---|---|---|
| `( )` | 括號 | 最高 |
| `-x` | 負號（一元運算子，可以連續出現，例如 `--3`） | 高 |
| `*` `/` `%` | 乘、除、取餘數（**由左到右** 結合） | 中 |
| `+` `-` | 加、減（**由左到右** 結合） | 低 |

**除法和取餘數照 C++ 的規則**：

- `/` 是整數除法，**向 0 取整**：`7 / 2 == 3`、`-7 / 2 == -3`（不是 -4）。
- `%` 的正負號 **跟被除數一樣**：`-7 % 3 == -1`、`7 % -3 == 1`。
- 永遠滿足 `(a / b) * b + a % b == a`。

運算式中可能有任意數量的空白。

## 輸入

第一行整數 `T`。接下來 `T` 行，每行一個運算式。

## 輸出

每個運算式輸出一行結果。
如果計算過程中 **任何地方** 出現除以 0 或對 0 取餘數，輸出 `division by zero`。

## 限制

- `1 ≤ T ≤ 1000`，每行長度 `≤ 2000`
- 數字是 `0 ~ 10^9` 的非負整數（負數用一元負號表示）
- 保證計算過程中所有中間結果的絕對值都 `≤ 10^18`

## 範例

輸入
```
6
1 + 2 * 3
(1 + 2) * 3
10 - 4 - 3
-7 / 2
-7 % 3
5 / (3 - 3)
```
輸出
```
7
9
3
-3
-1
division by zero
```

## 提示

- `10 - 4 - 3` 是 `(10 - 4) - 3 = 3`，不是 `10 - (4 - 3) = 9` —— 這就是 **左結合**。
- 經典寫法是 **遞迴下降 (recursive descent)**：每一種優先順序寫一個函式，優先順序低的呼叫優先順序高的。

```
expr   = term   { ('+' | '-') term }
term   = unary  { ('*' | '/' | '%') unary }
unary  = '-' unary | primary
primary = 數字 | '(' expr ')'
```

- 遇到除以 0 可以 `throw`，在 `main` 裡 `catch`（例外處理見第 13 課）。
