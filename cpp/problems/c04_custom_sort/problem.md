# C04. 多條件排序 (Custom Comparator & Lambda)

> 主題：函式、lambda、比較函式　難度：★★☆　時間限制：1 秒　相關教學：`cpp/lessons/04_functions.md`

## 題目

有 `N` 位學生，每位有 **姓名**、**分數**、**年齡**。請依照下面的規則排序後輸出：

1. **分數高的在前面**；
2. 分數相同時，**年齡小的在前面**；
3. 分數和年齡都相同時，**姓名字典序小的在前面**（用 ASCII 比較，大寫字母比小寫小）；
4. 三者都相同時，**保持輸入的順序**。

接著有 `Q` 筆查詢 `rank name`：輸出這個名字 **第一次出現** 的那位學生排在第幾名（從 1 開始）；找不到輸出 `-1`。

## 輸入

第一行 `N`，接下來 `N` 行 `name score age`。
然後一行 `Q`，接下來 `Q` 行查詢。

## 輸出

先輸出排序後的 `N` 行 `name score age`，再輸出 `Q` 行查詢結果。

## 限制

- `1 ≤ N ≤ 2×10^5`，`0 ≤ Q ≤ 2×10^5`
- 姓名由英文字母組成，長度 `1 ~ 10`，**可能重複**
- `-10^9 ≤ score ≤ 10^9`，`0 ≤ age ≤ 150`

## 範例

輸入
```
4
amy 90 20
Bob 95 22
cat 90 19
amy 90 20
2
rank amy
rank dog
```
輸出
```
Bob 95 22
cat 90 19
amy 90 20
amy 90 20
3
-1
```

## 提示

- 用 `sort` 搭配 **lambda** 比較函式：

```cpp
sort(v.begin(), v.end(), [](const Student& a, const Student& b) {
    if (a.score != b.score) return a.score > b.score;
    ...
});
```

- 比較函式必須是 **嚴格弱序 (strict weak ordering)**：「相等」的時候一定要回傳 `false`。
  如果寫成 `>=` 或 `<=`，`std::sort` 可能 **當掉** 或結果錯誤（測資裡有大量相同的資料）。
- 規則 4「保持輸入順序」：用 `stable_sort`，或把輸入編號也當作比較條件。
- 分數可能是負數；兩個分數 **相減** 來比較會溢位，請直接用 `<`、`>` 比。
- 「第一次出現」指的是 **輸入** 裡第一次出現的那一位。
