# C02. 位元運算 (Bit Manipulation)

> 主題：位元運算子、無號整數、移位　難度：★★☆　時間限制：1 秒　相關教學：`cpp/lessons/02_expressions.md`

## 題目

對 **64 位元無號整數** `x`（`0 ≤ x < 2^64`，用 `unsigned long long`）處理以下查詢。
位元編號從 0 開始，第 0 位是最低位。

| 查詢 | 輸出 |
|---|---|
| `popcount x` | `x` 有幾個位元是 1 |
| `lowbit x` | 只保留 `x` 最低的那個 1 的值（例如 `12 → 4`）；`x = 0` 輸出 `0` |
| `highbit x` | 最高的 1 在第幾位；`x = 0` 輸出 `-1` |
| `ctz x` | 最低位開始有幾個連續的 0；`x = 0` 輸出 `64` |
| `set x k` | 把第 `k` 位設成 1 之後的值 |
| `clear x k` | 把第 `k` 位設成 0 之後的值 |
| `toggle x k` | 把第 `k` 位反轉之後的值 |
| `test x k` | 第 `k` 位是 1 輸出 `1`，否則 `0` |
| `ispow2 x` | `x` 是 2 的次方輸出 `yes`，否則 `no`（`0` 不是） |
| `rotl x k` | 把 `x` 循環左移 `k` 位（左邊移出去的位元補到右邊） |

## 輸入

第一行 `Q`，接下來 `Q` 行查詢。`0 ≤ k ≤ 63`。

## 輸出

每個查詢輸出一行，數值用 **無號十進位** 表示。

## 限制

- `1 ≤ Q ≤ 2×10^5`

## 範例

輸入
```
7
popcount 13
lowbit 12
highbit 1
set 0 63
test 5 1
ispow2 64
rotl 9223372036854775808 1
```
輸出
```
3
4
0
9223372036854775808
0
yes
1
```

## 陷阱提示

- `1 << 63`：`1` 是 `int`，移 63 位是 **未定義行為**。要寫 `1ULL << 63`。
- `x >> 64`、`x << 64`：移位的位數 **大於等於型別的位元數** 是未定義行為。`rotl x 0` 時要小心。
- `x & -x` 對無號數也成立（`-x` 等於 `~x + 1`，會自動繞回）。
- `x & (x - 1)` 會把最低的 1 清掉，可以用來判斷 2 的次方。
- 讀入要用 `unsigned long long`，`2^64 - 1` 超過 `long long` 的範圍。
