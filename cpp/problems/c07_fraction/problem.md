# C07. 分數類別 (Operator Overloading)

> 主題：類別、封裝、運算子多載、不變量　難度：★★☆　時間限制：1 秒　相關教學：`cpp/lessons/07_classes_oop.md`

## 題目

設計一個 `Fraction`（分數）類別，支援 `+ - * /` 和比較 `< ==`，並用 **運算子多載** 讓下面的寫法成立：

```cpp
Fraction a(1, 2), b(-3, 4);
Fraction c = a + b;      // -1/4
bool less = a < b;       // false
cout << c;               // 印出 -1/4
```

`Fraction` 必須永遠保持 **標準形式（不變量 invariant）**：

1. 分子分母 **約分到最簡**（`gcd = 1`）。
2. **分母永遠是正的**，負號放在分子（`3/-6` → `-1/2`）。
3. 分子是 0 時，分母是 1（`0/7` → `0`）。

輸出時：分母是 1 只輸出分子（`4/2` → `2`）；否則輸出 `分子/分母`。

## 輸入

第一行 `T`。接下來 `T` 行，每行 `A op B`。
`A`、`B` 的格式是 `p/q` 或整數 `p`（`q` 可能是負數，但不會是 0）。`op` 是 `+ - * / < ==` 其中之一。

## 輸出

- 算術運算：輸出結果。除以 0（`B` 等於 0）時輸出 `undefined`。
- 比較運算：輸出 `true` 或 `false`。

## 限制

- `1 ≤ T ≤ 10^5`
- `|p|, |q| ≤ 10^9`（約分前的計算需要 `long long`；`10^9 × 10^9 = 10^18` 還在範圍內）

## 範例

輸入
```
6
1/2 + 1/3
3/-6 * 2
0/5 - 7
1/2 / 0
-1/2 < 1/-3
2/4 == 1/2
```
輸出
```
5/6
-1
-7
undefined
true
true
```

## 提示

- 在 **建構子** 裡做標準化，之後每個運算都回傳一個新的 `Fraction`（也會經過建構子），不變量就自動成立。
- `std::gcd`（`<numeric>`，C++17）會回傳非負數；`gcd(0, x) = |x|`。
- 比較 `a/b < c/d`：分母都是正的時候，等價於 `a*d < c*b`（交叉相乘，不要用浮點數）。
- 運算子可以寫成 **成員函式** 或 **非成員函式**。`operator<<` 必須是非成員函式（左邊是 `ostream`）。
- 分母 0 的處理：建構子遇到分母 0 時可以 `throw`，在呼叫端 `catch`。
