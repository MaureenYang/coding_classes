# 第一部分：圖的名詞

## 1.1 圖 (Graph)

**白話**：一堆 **點**，以及連接點的 **邊**。樹是一種特殊的圖（沒有環、全部連在一起）。

**比喻**：捷運路線圖。車站是點，兩站之間的軌道是邊。

```
1 ── 2
|    |
4 ── 3 ── 5
```

## 1.2 點與邊 (Vertex / Edge)

- **點 (vertex / node)**：圖裡的物體。通常用編號 `1 ~ n` 表示，`V` 或 `n` 代表點的數量。
- **邊 (edge)**：連接兩個點的線。`E` 或 `m` 代表邊的數量。

## 1.3 無向圖 vs 有向圖 (Undirected / Directed Graph)

- **無向圖**：邊沒有方向，`a ── b` 代表兩邊都能走。例：朋友關係（你是我朋友，我也是你朋友）。
- **有向圖**：邊有方向，`a ──▶ b` 只能從 `a` 走到 `b`。例：單行道、追蹤關係（我追蹤你，你不一定追蹤我）、修課的先修關係。

## 1.4 權重 (Weight)

**白話**：邊上的數字，代表走這條邊的「代價」，例如距離、時間、費用。沒有特別說明時，每條邊的代價都當作 1。

**比喻**：地圖上兩個城市之間標著「30 公里」。

## 1.5 鄰居與度數 (Neighbor / Degree)

- **鄰居**：有邊直接相連的點。
- **度數**：一個點連了幾條邊。
- 有向圖分成 **入度 (in-degree)**：有幾條邊 **指向** 我；**出度 (out-degree)**：我 **指出去** 幾條邊。

**比喻**（社群網站）：入度 = 粉絲數，出度 = 追蹤數。

## 1.6 路徑、環、連通 (Path / Cycle / Connected)

- **路徑**：沿著邊從一個點走到另一個點，經過的點序列。路徑長度 = 經過幾條邊。
- **環**：起點和終點是同一個點的路徑（至少一條邊）。
- **自環 (self-loop)**：一條邊連到自己 `a ── a`。
- **重邊 (multi-edge)**：同兩個點之間有好幾條邊。
- **連通 (connected)**：兩個點之間有路徑可以到達。
- **連通塊 / 連通分量 (connected component)**：互相連通的一群點。

```
1 ── 2     5 ── 6       ← 兩個連通塊：{1, 2, 3}、{5, 6}
 \  /
  3
（1 → 2 → 3 → 1 是一個環）
```

## 1.7 有向無環圖 (DAG, Directed Acyclic Graph)

**白話**：**有方向**、而且 **沒有環** 的圖。

**比喻**：修課的先修關係。「微積分 → 工程數學 → 訊號與系統」。如果出現「A 要先修 B、B 要先修 A」，就是環，永遠修不完。

拓撲排序（第五部分）只能用在 DAG 上。

# 第二部分：圖怎麼存

## 2.1 鄰接串列 (Adjacency List)

**白話**：每個點存一個「**我的鄰居有誰**」的清單。最常用。

```cpp
vector<vector<int>> adj(n + 1);    // 點編號 1 ~ n，所以開 n + 1
for (int i = 0; i < m; i++) {
    int a, b;
    cin >> a >> b;
    adj[a].push_back(b);
    adj[b].push_back(a);           // 無向圖：兩個方向都要加；有向圖只加上面那行
}
// 走訪 u 的所有鄰居
for (int v : adj[u]) ...
```

**比喻**：每個人手機裡的通訊錄，只記自己認識的人。

空間 `O(V + E)`，適合大部分的圖。

## 2.2 鄰接矩陣 (Adjacency Matrix)

**白話**：一個 `V × V` 的表格，`g[a][b] = true` 代表 `a` 到 `b` 有邊。

```cpp
vector<vector<bool>> g(n + 1, vector<bool>(n + 1, false));
g[a][b] = g[b][a] = true;
```

| | 鄰接串列 | 鄰接矩陣 |
|---|---|---|
| 空間 | `O(V + E)` | `O(V²)` |
| 查詢「a、b 有沒有邊」 | `O(a 的度數)` | `O(1)` |
| 走訪某點的所有鄰居 | `O(度數)` | `O(V)` |
| 適合 | 點多、邊少（**稀疏圖**） | 點少（`V ≤ 幾千`）、邊多（**稠密圖**） |

`V = 10⁵` 時鄰接矩陣要 `10¹⁰` 格，存不下。

## 2.3 網格也是圖 (Grid as Graph)

迷宮、地圖這類 **二維網格** 不用另外建圖：每一格是一個點，上下左右相鄰的格子之間有邊。

```cpp
const int dr[4] = {-1, 1, 0, 0};   // 上、下、左、右
const int dc[4] = {0, 0, -1, 1};
for (int d = 0; d < 4; d++) {
    int nr = r + dr[d], nc = c + dc[d];
    if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;   // 先檢查邊界！
    if (g[nr][nc] == '#') continue;                         // 牆
    // (nr, nc) 是 (r, c) 的鄰居
}
```

**方向陣列 (direction array)** `dr`、`dc` 讓四個方向可以用一個迴圈處理，不用寫四遍。

# 第三部分：BFS 廣度優先搜尋 (Breadth-First Search)

## 3.1 BFS 的想法

**白話**：從起點開始，**一層一層往外擴散**：先拜訪所有距離 1 的點，再拜訪所有距離 2 的點……

**比喻**：往水池丟一顆石頭，水波一圈一圈往外擴散。或是傳染病：第一天感染直接接觸的人，第二天再感染他們接觸的人。

```
距離 0：S
距離 1：S 的鄰居
距離 2：距離 1 的點的鄰居（還沒拜訪過的）
...
```

## 3.2 為什麼用 queue？

queue 先進先出：**先放進去的（距離比較近的）先處理**。這保證了處理順序是距離 0 → 1 → 2 → ……，不會跳層。

## 3.3 程式

```cpp
vector<int> dist(n + 1, -1);    // -1 代表還沒拜訪過
queue<int> q;
dist[s] = 0;
q.push(s);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u]) {
        if (dist[v] != -1) continue;   // 拜訪過了，跳過
        dist[v] = dist[u] + 1;         // 放進 queue 時就標記！
        q.push(v);
    }
}
// dist[t] 就是 s 到 t 的最短距離（-1 代表走不到）
```

**關鍵細節**：在 **放進 queue 的時候** 就標記為已拜訪，不要等到拿出來才標記。
否則同一個點可能被好幾個鄰居重複放進 queue，最壞會變成 `O(V²)` 甚至更多。

**比喻**：發傳單時，在名單上 **一交出去就打勾**。如果等對方回覆才打勾，同一個人可能會收到好幾張。

## 3.4 為什麼 BFS 找到的是最短距離？

**前提：每條邊的代價都一樣（例如都是 1）**。

BFS 照距離由近到遠處理。某個點 **第一次** 被發現時，是從距離最小的那一層發現的。
如果有更短的路，它應該在更早的一層就被發現了 —— 矛盾。所以第一次發現時的距離就是最短距離。

> 邊的代價 **不一樣** 時，BFS 就不對了，要用 Dijkstra（5.5 節）。

## 3.5 複雜度

每個點進出 queue 一次，每條邊被檢查一次（無向圖兩次）→ **`O(V + E)`**。
網格是 `O(R × C)`。

# 第四部分：DFS 深度優先搜尋 (Depth-First Search)

## 4.1 DFS 的想法

**白話**：一條路 **走到底**，走不下去了再 **退回來** 換別條路。

**比喻**：走迷宮時「一直靠右手邊走」，遇到死路就往回走到上一個岔路口。

```cpp
vector<bool> vis(n + 1, false);
void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u])
        if (!vis[v]) dfs(v);
}
```

DFS 本質上是用 **stack**（遞迴就是利用呼叫堆疊）；BFS 是用 **queue**。

## 4.2 DFS 適合做什麼？

| 用途 | 怎麼做 |
|---|---|
| 找連通塊 | 對每個還沒拜訪過的點做一次 DFS，每次就是一個連通塊 |
| 判斷能不能到達 | 從起點 DFS，看終點有沒有被拜訪 |
| 判斷有向圖有沒有環 | DFS 時遇到「還在目前路徑上」的點 → 有環 |
| 列舉所有可能 | 回溯法（第 02 課）就是在「選擇樹」上做 DFS |

## 4.3 DFS 不能找最短路徑

DFS 找到的是「**某一條**」路，不一定是最短的。它可能繞了一大圈才走到終點。

## 4.4 堆疊溢位的風險

遞迴 DFS 的深度可能等於 **點的數量**。`1000 × 1000` 的蛇形迷宮，路徑長 50 萬格，遞迴 50 萬層 → **堆疊溢位 (RE)**。
`15_maze_bfs` 的 `corner_serpentine_1000x1000` 就是在測這個。

**解法**：用 BFS（queue 放在 heap 區，空間大），或自己用 `stack` 容器寫 **非遞迴的 DFS**。

## 4.5 BFS vs DFS 總整理

| | BFS | DFS |
|---|---|---|
| 用什麼 | queue | stack / 遞迴 |
| 擴散方式 | 一層一層 | 一條路走到底 |
| 最短路徑（邊權都一樣） | ✅ | ❌ |
| 實作 | 迴圈 | 遞迴最簡潔 |
| 堆疊溢位風險 | 無 | 遞迴版有 |
| 複雜度 | `O(V + E)` | `O(V + E)` |

# 第五部分：拓撲排序與延伸

## 5.1 拓撲排序 (Topological Sort)

**白話**：在 DAG 中，把所有點排成一列，使得 **每條邊 `a → b` 都滿足 `a` 排在 `b` 前面**。

**比喻**：排修課順序；做菜的步驟（先洗菜才能切菜，先切菜才能炒菜）；編譯程式時決定哪個檔案先編譯。

```
1 ──▶ 2 ──▶ 4
│           ▲
└──▶ 3 ─────┘

合法的順序：1 2 3 4、1 3 2 4
不合法：2 1 3 4（2 排在 1 前面，但有邊 1 → 2）
```

拓撲排序 **可能不只一種**。有環的話 **一種都沒有**。

## 5.2 Kahn 演算法

**想法**：入度為 0 的點代表「**沒有任何先修條件**」，現在就能做。做完之後，把它指出去的邊刪掉，可能會有新的點入度變成 0。

1. 算每個點的入度。
2. 入度 0 的點全部放進 queue。
3. 從 queue 拿出一個點 `u`，加到答案裡；`u` 的每個鄰居入度 −1，變成 0 的就放進 queue。
4. 重複直到 queue 空了。

```cpp
for (int v = 1; v <= n; v++) if (indeg[v] == 0) q.push(v);
while (!q.empty()) {
    int u = q.front(); q.pop();
    order.push_back(u);
    for (int v : adj[u])
        if (--indeg[v] == 0) q.push(v);
}
if ((int)order.size() < n) cout << "有環，無法排序";
```

**比喻**：大學選課。每學期修「所有先修課都修完了」的課；修完之後，可能又有新的課解鎖。如果到最後還有課永遠解鎖不了，代表先修關係有環。

## 5.3 怎麼判斷有環？

環上的每個點，入度永遠不會變成 0（環上的前一個點永遠等著它）。
所以如果最後輸出的點 **不到 `n` 個**，圖中一定有環。

## 5.4 字典序最小 (Lexicographically Smallest)

**字典序**：像字典排單字一樣，從第一個開始比，第一個不同的地方小的就排前面。`1 3 2 4` < `1 3 4 2`。

要字典序最小的拓撲排序：每次從「現在可以做的點」中挑 **編號最小** 的 → 把 `queue` 換成 **最小堆積**：

```cpp
priority_queue<int, vector<int>, greater<int>> pq;
```

複雜度從 `O(V + E)` 變成 `O((V + E) log V)`。

## 5.5 延伸：Dijkstra 加權最短路徑

邊有不同的權重（而且都 **不是負數**）時，用 **Dijkstra 演算法**：
每次從還沒確定的點中，挑 **目前距離最小** 的那個確定下來，再用它更新鄰居。「挑最小」用 priority_queue。

```cpp
vector<long long> d(n + 1, INF);
priority_queue<pair<long long,int>, vector<pair<long long,int>>, greater<>> pq;
d[s] = 0; pq.push({0, s});
while (!pq.empty()) {
    auto [du, u] = pq.top(); pq.pop();
    if (du > d[u]) continue;                 // 這筆資料過期了（已經找到更短的）
    for (auto [v, w] : adj[u])
        if (d[u] + w < d[v]) {               // 經過 u 走到 v 比較近 → 更新
            d[v] = d[u] + w;
            pq.push({d[v], v});
        }
}
```

「`d[u] + w < d[v]` 就更新」這個動作叫做 **鬆弛 (relaxation)**。複雜度 `O((V + E) log V)`。

**比喻**：用導航找最快路線。從起點開始，每次確定「目前能最快到達的地方」，再從那裡看看能不能更快到達其他地方。

# 小測驗

1. 無向圖有 4 個點、邊 `1-2`、`2-3`、`1-3`、`3-4`。點 3 的度數是多少？這個圖有環嗎？
2. `V = 2 × 10⁵`、`E = 2 × 10⁵`，該用鄰接串列還是鄰接矩陣？為什麼？
3. 下面的 BFS 有什麼問題？

```cpp
q.push(s);
while (!q.empty()) {
    int u = q.front(); q.pop();
    vis[u] = true;
    for (int v : adj[u]) if (!vis[v]) q.push(v);
}
```

4. 迷宮的邊都是 1 步，為什麼不能用 DFS 找最短步數？
5. 有向圖邊 `1→2`、`2→3`、`3→1`、`3→4`。Kahn 演算法會輸出幾個點？結論是什麼？
6. 有向圖邊 `3→1`、`2→1`，用字典序最小的拓撲排序，答案是什麼？

### 答案

1. 點 3 連著 `2-3`、`1-3`、`3-4`，度數 **3**。有環：`1 → 2 → 3 → 1`。
2. **鄰接串列**。鄰接矩陣要 `(2 × 10⁵)² = 4 × 10¹⁰` 格，記憶體放不下；鄰接串列只要 `O(V + E)`。
3. 拿出來才標記 `vis`，同一個點在被拿出來之前可能被很多鄰居重複 push 進 queue，最壞情況 queue 會變得非常大、非常慢。應該在 **push 的時候** 就標記。
4. DFS 找到的是「某一條」路，不一定最短；而且大迷宮上遞迴 DFS 可能 **堆疊溢位**。BFS 一層一層擴散，第一次到達終點時就是最短距離。
5. 一開始 **沒有任何** 入度 0 的點（1、2、3 在環上，入度都是 1；4 的入度也是 1）。輸出 **0** 個點，不到 4 個 → **有環，無法排序**。
6. 入度 0 的點是 2、3，先挑最小的 **2**（1 的入度從 2 變 1）；然後 **3**（1 的入度變 0）；最後 **1**。答案 `2 3 1`。
