# 第一部分：算術運算

## 1.1 五個算術運算子

| 運算子 | 意思 | 範例 | 結果 |
|---|---|---|---|
| `+` `-` `*` | 加、減、乘 | `7 * 3` | `21` |
| `/` | 除 | `7 / 2` | `3`（整數除法） |
| `%` | 取餘數（只能用在整數） | `7 % 2` | `1` |

## 1.2 整數除法：向 0 取整

**是什麼**：兩個整數相除，結果還是整數，**小數部分直接丟掉**（往 0 的方向取整，不是四捨五入、也不是往下取整）。

```c
printf("%d %d %d %d\n", 7 / 2, -7 / 2, 7 / -2, -7 / -2);   // 輸出：3 -3 -3 3
printf("%d %d\n", 1 / 3, 2 / 3);                           // 輸出：0 0
```

`-7 / 2` 是 -3.5，往 0 的方向取整是 **-3**（不是 -4）。Python 的 `//` 是往下取整（得到 -4），兩個語言不一樣，要特別小心。

## 1.3 取餘數 %：正負號跟著被除數

**規則**：`a % b` 的正負號 **和 `a` 一樣**，而且永遠滿足 `(a / b) * b + a % b == a`。

```c
printf("%d %d %d %d\n", 7 % 3, -7 % 3, 7 % -3, -7 % -3);   // 輸出：1 -1 1 -1
```

**常見錯誤：判斷奇數**

```c
int x = -3;
printf("%d %d\n", x % 2 == 1, x % 2 != 0);   // 輸出：0 1
```

`-3 % 2` 是 **-1**，不是 1。判斷奇數要寫 `x % 2 != 0`。

**取「非負」的餘數**（例如陣列循環索引、模運算）：

```c
int m = 5, k = -7;
int r = ((k % m) + m) % m;    // -7 % 5 = -2 → (-2 + 5) % 5 = 3
printf("%d\n", r);            // 輸出：3
```

## 1.4 除以 0

```c
int a = 5, b = 0;
// printf("%d\n", a / b);     // ❌ 整數除以 0：未定義行為，通常程式直接當掉（Floating point exception）
// printf("%d\n", a % b);     // ❌ 一樣
double c = 5.0 / 0.0;         // 浮點數除以 0：得到 inf（無限大），不會當掉
printf("%f\n", c);            // 輸出：inf
```

**規則：除法和取餘數之前，先檢查除數是不是 0。**

## 1.5 整數和浮點數混用

**規則**：運算的兩邊只要有一邊是浮點數，另一邊就先轉成浮點數，用浮點數計算。

```c
printf("%d\n", 5 / 2);            // 兩邊都是 int → 整數除法 → 輸出：2
printf("%f\n", 5 / 2.0);          // 有一邊是 double → 輸出：2.500000
printf("%f\n", 5.0 / 2);          // 輸出：2.500000
```

**常見錯誤：平均值算錯**

```c
int sum = 7, n = 2;
double avg1 = sum / n;            // ❌ 先做整數除法得到 3，再轉成 3.0
double avg2 = (double)sum / n;    // ✅ 先把 sum 轉成 double
printf("%f %f\n", avg1, avg2);    // 輸出：3.000000 3.500000
```

**右邊怎麼算，跟左邊存進什麼型別無關。** `avg1` 是 `double`，但 `sum / n` 已經用整數算完了。

## 1.6 轉型 (Cast)

**是什麼**：`(型別) 運算式`，明確地把值轉成另一種型別。

```c
double d = 3.99;
int i = (int)d;                   // 浮點數轉整數：小數部分丟掉（向 0 取整）
printf("%d %d\n", i, (int)-3.99); // 輸出：3 -3

int big = 300;
unsigned char uc = (unsigned char)big;   // 超出範圍：無號型別會「取餘數」300 % 256
printf("%d\n", uc);                      // 輸出：44
```

**四捨五入**：用 `<math.h>` 的 `round`，或加 0.5 再轉型（只適用於正數）：

```c
#include <math.h>
printf("%.0f %d\n", round(2.5), (int)(2.5 + 0.5));   // 輸出：3 3
```

# 第二部分：型別轉換的規則

## 2.1 整數提升 (Integer Promotion)

**是什麼**：比 `int` 小的型別（`char`、`short`）在運算前，會先 **自動轉成 `int`**。

```c
char a = 100, b = 100;
int sum = a + b;                  // a、b 先變成 int 再相加，不會在 char 的範圍裡溢位
printf("%d\n", sum);              // 輸出：200
char c = a + b;                   // 結果 200 存回 char（範圍 -128~127）→ 超出範圍
printf("%d\n", c);                // 輸出：-56（實作定義：常見的二補數環境得到 200 - 256）
```

## 2.2 ⚠️ 有號與無號混用

**規則**：`int` 和 `unsigned int` 一起運算時，`int` 會被轉成 **unsigned**。負數變成無號數，會變成一個 **很大的正數**。

```c
int a = -1;
unsigned int b = 1;
printf("%d\n", a < b);            // 輸出：0   😱 -1 < 1 竟然是假！
printf("%u\n", (unsigned)a);      // 輸出：4294967295（-1 轉成 unsigned 的值）
```

`-Wall -Wextra` 會警告：`comparison of integer expressions of different signedness`。

**最常見的情況：和 `sizeof`、`strlen` 比較**（它們回傳無號的 `size_t`）

```c
int i = -1;
if (i < sizeof(int)) printf("小於\n");
else printf("不小於\n");          // 輸出：不小於（-1 被轉成超大的無號數）
```

```c
#include <string.h>
const char *s = "";                       /* 空字串，strlen(s) == 0 */
// for (size_t k = 0; k < strlen(s) - 1; k++)   // ❌ 0 - 1 在無號數會變成 18446744073709551615 → 迴圈跑非常多次
printf("%zu\n", strlen(s) - 1);           // 輸出：18446744073709551615
```

**規則**：
- 不要讓有號數和無號數比較；必要時明確轉型：`i < (int)sizeof(int)`。
- `strlen(s) - 1` 這種寫法，改成 `k + 1 < strlen(s)`。

## 2.3 溢位：有號是未定義行為，無號會繞回

```c
#include <limits.h>
unsigned int u = UINT_MAX;
u = u + 1;                        // 無號數溢位：定義好的行為，「繞回」0
printf("%u\n", u);                // 輸出：0

int s = INT_MAX;
// s = s + 1;                     // ❌ 有號數溢位：未定義行為！
```

**有號數溢位為什麼這麼危險？** 編譯器可以 **假設它不會發生**，然後做出意想不到的最佳化：

```c
int check(int x) { return x + 1 > x; }   /* 數學上永遠成立，除非 x + 1 溢位 */
printf("%d\n", check(INT_MAX));          // 輸出（-O2）：1   編譯器直接把整個比較改成「回傳 1」
```

**避免溢位**：用更大的型別（`long long`），或在運算前先檢查：`if (a > INT_MAX - b) { /* a + b 會溢位 */ }`。

# 第三部分：指定、遞增、比較、邏輯

## 3.1 指定運算子

```c
int x = 10;
x += 5;      // x = x + 5  → 15
x -= 3;      // → 12
x *= 2;      // → 24
x /= 5;      // → 4
x %= 3;      // → 1
printf("%d\n", x);            // 輸出：1
```

**指定運算式本身也有值**（就是被指定的值），所以可以連續指定：

```c
int a, b, c;
a = b = c = 7;                // 從右邊開始：c = 7，b = 7，a = 7
printf("%d %d %d\n", a, b, c);   // 輸出：7 7 7
```

## 3.2 遞增遞減：i++ 和 ++i

| 寫法 | 名稱 | 運算式的值 | 副作用 |
|---|---|---|---|
| `++i` | 前置遞增 | 加 1 **之後** 的值 | `i` 加 1 |
| `i++` | 後置遞增 | 加 1 **之前** 的值 | `i` 加 1 |

```c
int i = 5;
int a = i++;                  // a 拿到舊值 5，i 變成 6
int b = ++i;                  // i 變成 7，b 拿到 7
printf("%d %d %d\n", a, b, i);   // 輸出：5 7 7
```

單獨一行 `i++;` 和 `++i;` 效果完全一樣。

**⚠️ 不要在同一個運算式裡修改同一個變數兩次**：

```c
int k = 1;
// k = k++;                   // ❌ 未定義行為
// int r = k++ + k++;         // ❌ 未定義行為
// printf("%d %d\n", k, k++); // ❌ 未定義行為：參數的計算順序沒有規定
```

`-Wall` 會警告：`operation on 'k' may be undefined`。

## 3.3 比較運算子

`==`、`!=`、`<`、`>`、`<=`、`>=`，結果是 `int` 的 **1（真）或 0（假）**。

```c
printf("%d %d\n", 3 > 2, 3 == 2);   // 輸出：1 0
```

### ⚠️ `=` 和 `==`

```c
int x = 5;
if (x = 0) printf("零\n");          // ❌ 這是「把 0 指定給 x」，運算式的值是 0（假）→ 不會印出
else printf("不是零，x = %d\n", x); // 輸出：不是零，x = 0   😱 x 被改掉了
```

`-Wall` 會警告：`suggest parentheses around assignment used as truth value`。

### ⚠️ 不能連續比較

```c
int y = 10;
if (1 < y < 5) printf("在範圍內\n");  // ❌ 先算 1 < y 得到 1，再算 1 < 5 → 永遠是真！
if (1 < y && y < 5) printf("真的在範圍內\n");   // ✅
// 輸出：在範圍內
```

## 3.4 邏輯運算子與短路求值

| 運算子 | 意思 |
|---|---|
| `&&` | 且（兩邊都真才真） |
| `||` | 或（有一邊真就真） |
| `!` | 非 |

**C 的真假**：**0 是假，任何非 0 的值都是真**（包括負數、指標不是 `NULL`）。

```c
printf("%d %d %d\n", !0, !5, !!-3);  // 輸出：1 0 1
```

**短路求值 (short-circuit evaluation)**：`&&` 的左邊是假，右邊 **根本不會被計算**；`||` 的左邊是真，右邊也不計算。

```c
int arr[3] = {1, 2, 3};
int idx = 5;
if (idx < 3 && arr[idx] > 0) printf("ok\n");   // ✅ idx < 3 是假 → 不會去讀 arr[5]
int *p = NULL;
if (p != NULL && *p > 0) printf("positive\n"); // ✅ p 是 NULL → 不會解參考
printf("安全\n");                               // 輸出：安全
```

**順序很重要**：寫成 `arr[idx] > 0 && idx < 3` 就會先越界讀取。

## 3.5 條件運算子 ?:

```c
int a = 3, b = 7;
int mx = a > b ? a : b;          // 條件為真取 a，否則取 b
printf("%d\n", mx);              // 輸出：7
printf("%s\n", a % 2 ? "奇數" : "偶數");   // 輸出：奇數
```

## 3.6 sizeof 運算子

`sizeof` 是 **運算子**（不是函式），在 **編譯時** 算出型別或變數佔幾個 byte，結果型別是 `size_t`。

```c
int arr[10];
printf("%zu %zu %zu\n", sizeof(int), sizeof arr, sizeof arr / sizeof arr[0]);   // 輸出：4 40 10
int n = 0;
size_t s = sizeof(n++);          // sizeof 裡面的運算式不會被執行！
printf("%d %zu\n", n, s);        // 輸出：0 4
```

`sizeof arr / sizeof arr[0]` 是「陣列有幾個元素」的標準寫法（但陣列傳進函式之後就不能用了，第 04 課）。

# 第四部分：位元運算

## 4.1 六個位元運算子

| 運算子 | 名稱 | 每個位元的規則 | 範例（`a = 12` = `1100`，`b = 10` = `1010`） |
|---|---|---|---|
| `&` | AND | 兩個都是 1 才是 1 | `a & b` = `1000` = 8 |
| `|` | OR | 有一個是 1 就是 1 | `a | b` = `1110` = 14 |
| `^` | XOR | 不一樣才是 1 | `a ^ b` = `0110` = 6 |
| `~` | NOT | 0 變 1、1 變 0 | `~a`（有號 int）= -13 |
| `<<` | 左移 | 全部往左移，右邊補 0（左移 k 位 = 乘以 2ᵏ） | `a << 2` = 48 |
| `>>` | 右移 | 全部往右移（右移 k 位 = 除以 2ᵏ） | `a >> 2` = 3 |

```c
unsigned a = 12, b = 10;
printf("%u %u %u %u %u\n", a & b, a | b, a ^ b, a << 2, a >> 2);   // 輸出：8 14 6 48 3
printf("%d\n", ~12);                                               // 輸出：-13
```

## 4.2 常用技巧

```c
unsigned x = 0;
int k = 3;
x |= 1u << k;                    // 把第 k 個位元設成 1
printf("%u\n", x);               // 輸出：8
printf("%u\n", (x >> k) & 1u);   // 讀第 k 個位元 → 輸出：1
x &= ~(1u << k);                 // 把第 k 個位元清成 0
printf("%u\n", x);               // 輸出：0
x ^= 1u << 2;                    // 把第 2 個位元反轉
printf("%u\n", x);               // 輸出：4

int n = 20;
printf("%d %d\n", n & 1, n % 2); // 判斷奇偶（對非負數）→ 輸出：0 0
printf("%d\n", (n & (n - 1)) == 0);   // n 是 2 的次方嗎？ → 輸出：0
```

**位元旗標 (bit flags)**：用一個整數的不同位元表示多個開關。

```c
enum { READ = 1, WRITE = 2, EXEC = 4 };   /* 每個旗標佔一個位元 */
int perm = READ | WRITE;                  /* 打開兩個開關 */
printf("%d %d %d\n", (perm & READ) != 0, (perm & EXEC) != 0, perm);   // 輸出：1 0 3
```

## 4.3 ⚠️ 位元運算的陷阱

- **對有號數左移，結果超出範圍是未定義行為**：`1 << 31`（`int` 是 32 位元）就是。要移到最高位元，用無號數 `1u << 31`。
- **移位量 ≥ 型別的位元數是未定義行為**：`1u << 32`（32 位元的 `unsigned`）。要移 32 位以上用 `1ULL << k`。
- **負數右移的結果由編譯器決定**（實作定義）。GCC 是「補符號位元」：`-8 >> 1` 是 -4。
- **優先順序很低**：`x & 1 == 0` 是 `x & (1 == 0)`，要寫 `(x & 1) == 0`（第五部分）。

```c
unsigned long long big = 1ULL << 40;
printf("%llu\n", big);           // 輸出：1099511627776
printf("%d\n", -8 >> 1);         // 輸出：-4
```

# 第五部分：優先順序與求值順序

## 5.1 優先順序表（由高到低，常用的部分）

| 優先順序 | 運算子 | 結合性 |
|---|---|---|
| 1 | `()` `[]` `->` `.` 後置 `++` `--` | 左到右 |
| 2 | 前置 `++` `--`、一元 `+` `-`、`!` `~`、`*`（解參考）、`&`（取位址）、`(型別)`、`sizeof` | **右到左** |
| 3 | `*` `/` `%` | 左到右 |
| 4 | `+` `-` | 左到右 |
| 5 | `<<` `>>` | 左到右 |
| 6 | `<` `<=` `>` `>=` | 左到右 |
| 7 | `==` `!=` | 左到右 |
| 8 | `&` | 左到右 |
| 9 | `^` | 左到右 |
| 10 | `|` | 左到右 |
| 11 | `&&` | 左到右 |
| 12 | `||` | 左到右 |
| 13 | `?:` | 右到左 |
| 14 | `=` `+=` `-=` 等 | **右到左** |
| 15 | `,` | 左到右 |

## 5.2 最常寫錯的組合

```c
int x = 6;
printf("%d\n", x & 1 == 0);       // ❌ == 比 & 先算：x & (1 == 0) = x & 0 → 輸出：0
printf("%d\n", (x & 1) == 0);     // ✅ → 輸出：1
printf("%d\n", 1 << 2 + 1);       // ❌ + 比 << 先算：1 << 3 → 輸出：8（想要 5？）
printf("%d\n", (1 << 2) + 1);     // ✅ → 輸出：5
```

**規則：位元運算一律加括號。** 不確定優先順序的時候，加括號永遠不會錯。

## 5.3 🔍 求值順序：沒有規定

`f() + g()` 誰先被呼叫？**C 標準沒有規定**（未指定行為）。

```c
int counter = 0;
int next(void) { return ++counter; }
int r = next() * 10 + next();     /* 可能是 1*10+2 = 12，也可能是 2*10+1 = 21 */
```

如果兩個函式有互相影響的副作用，拆成兩行：`int a = next(); int b = next();`。

**例外**：`&&`、`||`、`?:`、`,` 有規定「先算左邊」。

# 第六部分：控制流程

## 6.1 if / else

```c
int score = 85;
if (score >= 90) printf("A\n");
else if (score >= 80) printf("B\n");     // 輸出：B
else printf("C\n");
```

**⚠️ 懸置的 else (dangling else)**：`else` 會配對 **最近的** `if`，不管縮排。

```c
int a = 1, b = 0;
if (a)
    if (b) printf("a 和 b\n");
else                                     // 縮排看起來是配外面的 if，其實配的是 if (b)
    printf("不是 a\n");                  // 輸出：不是 a   😱 a 明明是真
```

**規則：`if` 的本體一律加大括號 `{ }`**，就不會有這個問題。`-Wall` 會警告 `suggest explicit braces to avoid ambiguous 'else'`。

## 6.2 switch

```c
int day = 3;
switch (day) {
    case 1: printf("一\n"); break;
    case 2: printf("二\n"); break;
    case 3: printf("三\n"); break;       // 輸出：三
    default: printf("其他\n"); break;
}
```

**規則**：
- `switch` 的值必須是 **整數**（包括 `char`、`enum`）。**不能 `switch` 字串**（要用 `if` + `strcmp`）。
- `case` 後面必須是 **編譯期常數**（數字、字元、`enum`、`#define`），不能是變數、也不能是 `const int` 變數。
- 沒有 `break` 會 **穿透 (fall through)** 到下一個 `case`。

```c
int level = 2;
switch (level) {
    case 3: printf("三級權限 ");
    case 2: printf("二級權限 ");          /* 沒有 break：繼續往下執行 */
    case 1: printf("一級權限\n");
}
// 輸出：二級權限 一級權限
```

**故意穿透：多個 case 共用同一段程式碼**

```c
char c = 'e';
switch (c) {
    case 'a': case 'e': case 'i': case 'o': case 'u':
        printf("母音\n");                 // 輸出：母音
        break;
    default:
        printf("子音\n");
}
```

**常見錯誤**：忘了 `break`。`gcc -Wextra` 會警告 `this statement may fall through`。

## 6.3 三種迴圈

```c
/* while：先檢查條件 */
int i = 0;
while (i < 3) { printf("%d ", i); i++; }
printf("\n");                            // 輸出：0 1 2

/* for：初始化; 條件; 每輪結束後 */
for (int j = 0; j < 3; j++) printf("%d ", j);
printf("\n");                            // 輸出：0 1 2

/* do-while：先執行一次，再檢查條件（至少執行一次） */
int k = 10;
do { printf("%d ", k); k++; } while (k < 3);
printf("\n");                            // 輸出：10（條件一開始就不成立，但還是執行了一次）
```

`for` 的三個部分都可以省略：`for (;;) { ... }` 是無窮迴圈。

**常見錯誤：分號放錯位置**

```c
int cnt = 0;
for (int t = 0; t < 5; t++);             // ❌ 迴圈本體是那個分號（空敘述）
    cnt++;                               //    這行不在迴圈裡，只執行一次
printf("%d\n", cnt);                     // 輸出：1
```

## 6.4 break 與 continue

- `break`：立刻跳出 **最內層** 的迴圈（或 `switch`）。
- `continue`：跳過這一輪剩下的部分，直接進入下一輪。

```c
for (int n = 1; n <= 10; n++) {
    if (n % 2 == 0) continue;            // 跳過偶數
    if (n > 7) break;                    // 超過 7 就結束
    printf("%d ", n);
}
printf("\n");                            // 輸出：1 3 5 7
```

## 6.5 goto：跳出多層迴圈、集中清理

**是什麼**：跳到同一個函式裡的某個 **標籤 (label)**。

一般情況不要用（會讓流程很難看懂），但 C 沒有例外處理，有兩種情況 `goto` 反而是最清楚的寫法：

**1. 一次跳出多層迴圈**

```c
int grid[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
int fr = -1, fc = -1;
for (int r = 0; r < 3; r++)
    for (int c = 0; c < 3; c++)
        if (grid[r][c] == 5) { fr = r; fc = c; goto found; }   /* break 只能跳出一層 */
found:
printf("%d %d\n", fr, fc);               // 輸出：1 1
```

**2. 錯誤時集中釋放資源**（Linux 核心大量使用這個寫法，第 10 課會再看到）

```c
int process(void) {
    int ret = -1;
    char *buf = malloc(100);
    if (!buf) goto out;
    FILE *f = fopen("data.txt", "r");
    if (!f) goto free_buf;                 /* 失敗：只要釋放已經配置的 buf */
    /* ... 正常處理 ... */
    ret = 0;
    fclose(f);
free_buf:
    free(buf);
out:
    return ret;
}
```

# 習題解答

**題 1**：`3 -3 2 -2`。整數除法向 0 取整：`-17 / 5 = -3`；`17 % -5` 正負號跟 17 → `2`；`-17 % 5` 正負號跟 -17 → `-2`。

**題 2**：`3.0 3.0 3.5`。`a / b` 是整數除法（3），轉成 `double` 只是 3.0；只有先把 `a` 轉成 `double` 才會用浮點數除法。

**題 3**：印出 `s 不比較小`。`s` 和 `u` 比較時，`s` 被轉成 `unsigned int`，-5 變成 4294967291，比 3 大。`-Wall -Wextra` 會警告。

**題 4**：`6 13 3`。`a = i++ * 2` 用 **舊值** 3 計算 → 6，之後 `i` 變成 4；`--i` 是前置遞減，`i` 先變成 3，再用新值計算 `b = 3 + 10 = 13`。

**題 5**：
- 第一個 `if`：`y != 0` 是假，短路，不會計算 `x / y`（不會除以 0），不印。
- 第二個 `if`：`y == 0` 是真，短路，印出 `B`。
- `3 > 2 > 1` 是 `(3 > 2) > 1` = `1 > 1` = 0。

輸出：`B`，換行，`0`。

**題 6**：`0 1 2`。
- `n & 2 != 0` 是 `n & (2 != 0)` = `10 & 1` = 0。
- `(n & 2) != 0`：10 是 `1010`，第 1 個位元是 1 → 1。
- `n >> 1 + 1` 是 `n >> 2` = 2。

**題 7**：`132`。
- `i = 1`：`1 % 3 = 1` → +10。
- `i = 2`：`2` → default +1。
- `i = 3`：`0` → +100，**沒有 break，穿透** 到 case 1 → 再 +10，然後 break。
- `i = 4`：`1` → +10。
- `i = 5`：`2` → +1。

合計 10 + 1 + 110 + 10 + 1 = 132。

**題 8**：`x ^= 1u << k;`（XOR 1 會反轉該位元，XOR 0 不變）。

**題 9**：條件的順序錯了。`i` 變成 5 時，會先計算 `arr[5] != 9` —— 越界讀取。要先檢查範圍：`while (i < 5 && arr[i] != 9) i++;`（短路求值保證 `i < 5` 為假時不會讀 `arr[i]`）。
