# 第一部分：第一個 C 程式

## 1.1 Hello, world

```c
#include <stdio.h>              /* 引入標準輸入輸出函式庫：printf、scanf 都在這裡 */

int main(void) {                /* 程式從 main 開始執行 */
    printf("Hello, world!\n");  /* \n 是換行 */
    return 0;                   /* 回傳 0 給作業系統：代表「成功結束」 */
}
// 輸出：Hello, world!
```

一行一行看：

| 程式碼 | 意思 |
|---|---|
| `#include <stdio.h>` | 把 `stdio.h` 這個 **標頭檔** 的內容貼進來，裡面有 `printf` 的宣告。沒有這行就不能用 `printf` |
| `int main(void)` | 主函式。`int` 是回傳型別；`(void)` 表示 **沒有參數**（C 裡寫 `()` 的意思是「參數不確定」，所以習慣寫 `(void)`） |
| `{ ... }` | 函式本體 |
| `printf(...)` | 印出文字 |
| `;` | 每個敘述都要用分號結尾 |
| `return 0;` | 結束 `main`。`main` 是唯一一個可以省略 `return` 的函式（省略時等於 `return 0;`） |

## 1.2 編譯與執行

C 是 **編譯式語言**：原始碼要先被 **編譯器** 翻譯成機器碼（執行檔），才能執行。

```bash
gcc -std=c11 -Wall -Wextra hello.c -o hello    # 編譯
./hello                                         # 執行（Windows：hello.exe）
```

| 參數 | 意思 |
|---|---|
| `-std=c11` | 使用 C11 標準 |
| `-Wall -Wextra` | 開啟大部分警告。**C 的警告常常就是 bug，一定要開** |
| `-o hello` | 輸出的執行檔名稱 |
| `-g` | 加入除錯資訊（給除錯器、sanitizer 顯示行號） |
| `-O2` | 最佳化（評測系統用這個） |
| `-lm` | 連結數學函式庫（用到 `<math.h>` 的 `sqrt`、`pow` 時，Linux 上要加） |

本平台的 `judge.py` 會幫你做這些事：`.c` 檔用 `gcc -std=c11 -O2 -Wall -Wextra ... -lm` 編譯。

## 1.3 註解

```c
/* 這是 C 傳統的區塊註解，
   可以跨好幾行 */
// 這是單行註解（C99 起才有）
int x = 5; /* 註解可以放在程式碼後面 */
```

**常見錯誤**：區塊註解 **不能巢狀**：`/* 外 /* 內 */ 外 */` 在第一個 `*/` 就結束了，後面的 ` 外 */` 會變成程式碼 → 編譯錯誤。要暫時移除一大段程式碼，用 `#if 0 ... #endif`（第 11 課）。

# 第二部分：型別與變數

## 2.1 變數

**是什麼**：一塊有名字、有型別的記憶體。**型別** 決定了它佔幾個 byte、能存什麼範圍的值、能做什麼運算。

```c
int age = 20;          /* 宣告並初始化 */
double height;         /* 只宣告，還沒有值 */
height = 172.5;        /* 之後再指定 */
int a = 1, b = 2;      /* 一次宣告好幾個 */
```

**C99 起** 變數可以在任何地方宣告（包括 `for (int i = 0; ...)`）；更早的 C89 規定變數只能宣告在區塊的開頭，舊的程式碼常看到這種風格。

### ⚠️ 未初始化的區域變數是垃圾值

```c
int main(void) {
    int x;                 /* 沒有初始化 */
    printf("%d\n", x);     /* ❌ 未定義行為：可能印出任何數字 */
}
```

`-Wall` 會警告 `'x' is used uninitialized`。**規則：宣告時就給初值。**

**全域變數** 和 **`static` 變數** 例外：沒有初始化時自動是 0（第 03 課）。

## 2.2 整數型別

| 型別 | 常見大小（64 位元 Linux） | 範圍 | 格式符號 |
|---|---|---|---|
| `char` | 1 byte | -128 ~ 127（或 0 ~ 255，由編譯器決定） | `%c`（字元）/ `%d`（數字） |
| `short` | 2 bytes | -32768 ~ 32767 | `%hd` |
| `int` | 4 bytes | 約 ±21 億（±2.1 × 10⁹） | `%d` |
| `long` | 8 bytes（**Windows 是 4 bytes！**） | | `%ld` |
| `long long` | 8 bytes | 約 ±9.2 × 10¹⁸ | `%lld` |

每種整數型別都有 **無號 (unsigned)** 版本：`unsigned int`（0 ~ 約 42.9 億）、`unsigned long long` 等，只能存非負數，範圍上限大一倍。

**標準只規定「最小大小」**，實際大小由編譯器決定。用 `sizeof` 查：

```c
printf("%zu %zu %zu %zu %zu\n",
       sizeof(char), sizeof(short), sizeof(int), sizeof(long), sizeof(long long));
// 輸出：1 2 4 8 8
```

（`sizeof` 的結果型別是 `size_t`，要用 `%zu` 印。）

**`<limits.h>` 有每種型別的上下限**：

```c
#include <limits.h>
printf("%d %d\n", INT_MAX, INT_MIN);           // 輸出：2147483647 -2147483648
printf("%lld\n", LLONG_MAX);                   // 輸出：9223372036854775807
printf("%u\n", UINT_MAX);                      // 輸出：4294967295
```

### 選擇整數型別的原則

- 一般的計數、索引：`int`。
- 可能超過 2 × 10⁹（例如乘法、總和、10⁵ × 10⁵）：`long long`。
- 陣列大小、`sizeof` 的結果、`strlen` 的回傳值：`size_t`（無號，`<stddef.h>`）。
- 需要 **確切** 位元數（檔案格式、網路協定）：`<stdint.h>` 的 `int32_t`、`uint8_t`、`int64_t`。
- 不要用 `long`：Linux 是 64 位元、Windows 是 32 位元，同一份程式在兩邊行為不同。

## 2.3 浮點數型別

| 型別 | 大小 | 有效位數 | `printf` | `scanf` |
|---|---|---|---|---|
| `float` | 4 bytes | 約 7 位 | `%f` | `%f` |
| `double` | 8 bytes | 約 15~16 位 | `%f` | **`%lf`** |

**一律用 `double`**，除非記憶體非常吃緊。`float` 的精度很容易不夠：

```c
float f = 16777217;              /* 2^24 + 1 */
double d = 16777217;
printf("%.0f %.0f\n", f, d);     // 輸出：16777216 16777217（float 存不下這個整數）
```

**浮點數不精確**：0.1 在二進位無法精確表示。

```c
double x = 0.1 + 0.2;
printf("%d\n", x == 0.3);        // 輸出：0
printf("%.17f\n", x);            // 輸出：0.30000000000000004
```

比較浮點數要用「差距夠小」：`fabs(x - 0.3) < 1e-9`（`fabs` 在 `<math.h>`）。

## 2.4 字元：char 就是小整數

**是什麼**：`char` 存的是字元的 **編碼數字**（ASCII）。`'A'` 就是 65，`'0'` 就是 48。

```c
char c = 'A';
printf("%c %d\n", c, c);           // 輸出：A 65（同一個值，兩種印法）
printf("%c\n", c + 2);             // 輸出：C
printf("%d\n", '7' - '0');         // 數字字元轉數字 → 輸出：7
printf("%c\n", 'a' - 'a' + 'A');   // 小寫轉大寫 → 輸出：A
```

**常見的跳脫字元 (escape sequence)**：

| 寫法 | 意思 |
|---|---|
| `'\n'` | 換行 |
| `'\t'` | Tab |
| `'\\'` | 反斜線本身 |
| `'\''`、`'\"'` | 單引號、雙引號 |
| `'\0'` | 值為 0 的字元（字串的結尾，第 06 課） |

**`'A'` 和 `"A"` 不一樣**：單引號是一個字元（整數 65）；雙引號是 **字串**（兩個字元 `'A'`、`'\0'` 組成的陣列）。

## 2.5 字面值 (Literal) 的寫法

| 寫法 | 型別 / 意思 |
|---|---|
| `42` | `int` |
| `42u` / `42U` | `unsigned int` |
| `42L`、`42LL` | `long`、`long long` |
| `0x2A` | 十六進位（= 42） |
| `052` | ⚠️ **八進位**（= 42）：開頭是 0 就是八進位！ |
| `3.14` | `double` |
| `3.14f` | `float` |
| `1e6`、`2.5e-3` | 科學記號（`double`）：1000000.0、0.0025 |
| `'a'` | 字元（型別其實是 `int`） |
| `"abc"` | 字串字面值 |

```c
printf("%d %d %d\n", 42, 0x2A, 052);    // 輸出：42 42 42
int zip = 010;                           // 想寫郵遞區號「010」？
printf("%d\n", zip);                     // 輸出：8   😱 被當成八進位了
```

**常見錯誤：大數字溢位**

```c
long long big = 100000 * 100000;         // ❌ 兩個 int 相乘，用 int 計算 → 溢位（未定義行為）
long long ok  = 100000LL * 100000;       // ✅ 有一邊是 long long，整個乘法就用 long long
printf("%lld\n", ok);                    // 輸出：10000000000
```

`-Wall` 會警告 `integer overflow in expression`。**右邊用什麼型別計算，跟左邊存進什麼型別無關。**

## 2.6 const：不能修改的變數

```c
const int MAX_N = 100;
// MAX_N = 200;                 // ❌ error: assignment of read-only variable 'MAX_N'
const double PI = 3.14159265358979;
```

C 的 `const` 變數 **不是編譯期常數**：不能用在需要常數的地方（例如 `switch` 的 `case`）。需要編譯期常數時用 `#define` 或 `enum`（第 08、11 課）。

## 2.7 bool（C99 起）

C 原本沒有布林型別，用整數代替：**0 是假，非 0 是真**。C99 加了 `<stdbool.h>`：

```c
#include <stdbool.h>
bool done = false;
if (!done) done = true;
printf("%d %zu\n", done, sizeof(bool));   // 輸出：1 1
```

比較運算（`<`、`==`）的結果是 `int` 的 0 或 1。

# 第三部分：printf

## 3.1 基本用法

**是什麼**：`printf` 的第一個參數是 **格式字串**，裡面的 `%` 開頭的東西叫 **格式符號 (conversion specifier)**，會依序被後面的參數取代。

```c
int n = 3;
double avg = 87.5;
printf("共 %d 人，平均 %f 分\n", n, avg);   // 輸出：共 3 人，平均 87.500000 分
```

## 3.2 格式符號總覽

| 符號 | 參數型別 | 範例 | 輸出 |
|---|---|---|---|
| `%d` / `%i` | `int` | `printf("%d", -42)` | `-42` |
| `%u` | `unsigned int` | `printf("%u", 42u)` | `42` |
| `%ld` / `%lld` | `long` / `long long` | `printf("%lld", 10000000000LL)` | `10000000000` |
| `%zu` | `size_t` | `printf("%zu", sizeof(int))` | `4` |
| `%f` | `double`（`float` 會自動轉成 `double`） | `printf("%f", 3.14)` | `3.140000` |
| `%e` | `double`，科學記號 | `printf("%e", 12345.678)` | `1.234568e+04` |
| `%g` | `double`，自動選 `%f` 或 `%e`，去掉多餘的 0 | `printf("%g", 3.140)` | `3.14` |
| `%c` | 字元 | `printf("%c", 65)` | `A` |
| `%s` | 字串（`char *`） | `printf("%s", "hi")` | `hi` |
| `%x` / `%X` | `unsigned int`，十六進位 | `printf("%x %X", 255, 255)` | `ff FF` |
| `%o` | `unsigned int`，八進位 | `printf("%o", 8)` | `10` |
| `%p` | 指標（`void *`） | `printf("%p", (void *)&n)` | `0x7ffd...`（每次不同） |
| `%%` | 印出 `%` 本身 | `printf("100%%")` | `100%` |

## 3.3 寬度、精度、旗標

完整的格式：`%[旗標][寬度][.精度]符號`

### 寬度：至少佔幾個字元（不夠時補空白，預設靠右）

```c
printf("[%5d]\n", 42);      // 輸出：[   42]
printf("[%5d]\n", 123456);  // 輸出：[123456]（太長不會截斷）
printf("[%8s]\n", "abc");   // 輸出：[     abc]
```

### 精度：對不同的符號意思不同

```c
printf("[%.2f]\n", 3.14159);     // 浮點數：小數點後幾位 → 輸出：[3.14]
printf("[%.0f]\n", 2.5);         // 0 位：四捨五入到整數（「銀行家捨入」，2.5 → 2）→ 輸出：[2]
printf("[%.3s]\n", "abcdef");    // 字串：最多印幾個字元 → 輸出：[abc]
printf("[%.5d]\n", 42);          // 整數：最少幾位數，不夠補 0 → 輸出：[00042]
printf("[%8.3f]\n", 3.14159);    // 寬度 8、小數 3 位 → 輸出：[   3.142]
```

### 旗標

| 旗標 | 意思 | 範例 | 輸出 |
|---|---|---|---|
| `-` | 靠左 | `printf("[%-5d]", 42)` | `[42   ]` |
| `0` | 用 0 補滿寬度 | `printf("[%05d]", 42)` | `[00042]` |
| `+` | 正數也印 `+` | `printf("[%+d]", 42)` | `[+42]` |
| 空格 | 正數前面留一格空白 | `printf("[% d]", 42)` | `[ 42]` |
| `#` | 十六 / 八進位加前綴 | `printf("[%#x]", 255)` | `[0xff]` |

```c
printf("%02d:%02d:%02d\n", 9, 5, 7);     // 時間格式 → 輸出：09:05:07
printf("%-10s|%6.2f\n", "apple", 1.5);   // 表格 → 輸出：apple     |  1.50
```

### 用 * 指定寬度

寬度可以用參數決定：

```c
int w = 6;
printf("[%*d]\n", w, 42);                // 輸出：[    42]
```

## 3.4 printf 的回傳值

`printf` 回傳 **印出了幾個字元**（出錯時回傳負數）：

```c
int len = printf("hello\n");
printf("%d\n", len);                     // 輸出：hello 換行，再輸出 6
```

## 3.5 ⚠️ 格式符號和型別不符：未定義行為

`printf` **不會檢查** 參數的型別，它只是照著格式字串去讀記憶體。寫錯了就是讀到錯誤的資料：

```c
long long big = 10000000000LL;
printf("%d\n", big);        // ❌ 用 %d 印 long long：印出錯誤的數字
double d = 3.5;
printf("%d\n", d);          // ❌ 用 %d 印 double：印出垃圾值
int n = 5;
printf("%f\n", n);          // ❌ 用 %f 印 int：印出垃圾值（int 不會自動轉成 double！）
printf("%s\n", n);          // ❌ 用 %s 印 int：把 5 當成位址去讀 → 通常直接當掉
```

**好消息**：`gcc -Wall` 會檢查格式字串：

```
warning: format '%d' expects argument of type 'int', but argument 2 has type 'long long int' [-Wformat=]
```

**一定要開 `-Wall`，而且不要忽略 `-Wformat` 警告。**

另一個陷阱：**格式字串不要直接用使用者輸入的資料**：

```c
printf(user_input);          // ❌ 如果使用者輸入 "%s%s%s"，printf 會去讀不存在的參數
printf("%s", user_input);    // ✅
```

# 第四部分：scanf

## 4.1 基本用法：為什麼要加 &

```c
int age;
double h;
scanf("%d %lf", &age, &h);   // 輸入：20 172.5
printf("%d %.1f\n", age, h); // 輸出：20 172.5
```

**為什麼要寫 `&age`？** C 的函式參數都是 **傳值**（第 03 課）：如果寫 `scanf("%d", age)`，`scanf` 只拿到 `age` 的 **複製品**（而且還是垃圾值），沒辦法改到真正的 `age`。`&age` 是 `age` 的 **位址**（第 05 課），`scanf` 拿到位址，才能把讀到的值寫進那個位置。

**比喻**：你想請朋友幫你把東西放進你家的置物櫃。只告訴他「櫃子裡現在有什麼」（傳值）沒有用；要告訴他「櫃子在哪裡」（位址），他才能把東西放進去。

**常見錯誤：忘了 `&`**

```c
int x;
scanf("%d", x);              // ❌ 把 x 的垃圾值當成位址去寫 → 通常當掉
```

`-Wall` 會警告：`format '%d' expects argument of type 'int *', but argument 2 has type 'int'`。

## 4.2 scanf 的格式符號

| 符號 | 變數型別 | 注意 |
|---|---|---|
| `%d` | `int *` | |
| `%lld` | `long long *` | |
| `%u` | `unsigned *` | |
| `%f` | `float *` | |
| `%lf` | **`double *`** | ⚠️ 和 `printf` 不同：讀 `double` 一定要 `%lf` |
| `%c` | `char *` | ⚠️ **不會** 跳過空白（4.4 節） |
| `%s` | `char *`（陣列） | 不用加 `&`；讀到空白為止；要限制長度（4.3 節） |
| `%[...]` | `char *` | 字元集合（4.6 節） |

**`%d`、`%lf`、`%s` 會自動跳過前面的空白**（空格、Tab、換行）：

```c
int a, b;
scanf("%d%d", &a, &b);       // 輸入：「   3\n\n   4」也能正確讀到 3 和 4
```

## 4.3 讀字串：%s

```c
char name[20];
scanf("%19s", name);         // 不用 &：陣列名稱本身就是位址（第 05 課）
printf("Hi, %s!\n", name);   // 輸入：Amy Lee → 輸出：Hi, Amy!（%s 讀到空白就停）
```

**`%19s` 的 19 是什麼？** 最多讀 19 個字元，留 1 格給結尾的 `'\0'`（第 06 課）。

**常見錯誤：沒有限制長度**

```c
char buf[8];
scanf("%s", buf);            // ❌ 使用者輸入超過 7 個字元 → 寫出陣列外面 → 緩衝區溢位
```

這是 C 最經典的安全漏洞之一。**`%s` 一律寫上最大長度。**

## 4.4 讀字元：%c 不會跳過空白

```c
int n;
char c;
scanf("%d", &n);             // 輸入：「5\nx」
scanf("%c", &c);             // ❌ 讀到的是 5 後面的換行字元 '\n'，不是 'x'！
printf("[%c]\n", c);         // 輸出：[
                             //       ]（印出了一個換行）
```

**解法**：在 `%c` 前面加一個空格。格式字串裡的 **空白** 代表「跳過任意數量的空白字元」：

```c
scanf(" %c", &c);            // ✅ 先跳過所有空白，再讀一個字元 → 'x'
```

## 4.5 scanf 的回傳值：成功讀到幾個

**是什麼**：`scanf` 回傳 **成功讀進變數的個數**；一個都還沒讀就碰到檔案結尾時回傳 `EOF`（通常是 -1）。

```c
int a, b;
int r = scanf("%d %d", &a, &b);
// 輸入「3 4」→ r = 2
// 輸入「3 x」→ r = 1（b 沒有被讀到，保持原本的值）
// 輸入「x」  → r = 0（格式不符，什麼都沒讀）
// 沒有輸入   → r = EOF
```

### 讀到檔案結束（不知道有幾筆資料時）

```c
int x, sum = 0;
while (scanf("%d", &x) == 1)     // 成功讀到 1 個才繼續
    sum += x;
printf("%d\n", sum);             // 輸入：1 2 3 → 輸出：6
```

**常見錯誤**：`while (scanf("%d", &x) != 0)` —— 碰到檔案結尾時回傳 `EOF`（-1），不等於 0，迴圈不會停 → 無窮迴圈。**要寫 `== 1`（等於期望讀到的個數）。**

在鍵盤上手動輸入時，按 `Ctrl+D`（Linux / Mac）或 `Ctrl+Z` 再按 Enter（Windows）表示輸入結束。

## 4.6 格式字串裡的一般字元與字元集合

格式字串裡 **一般的字元** 必須和輸入完全符合：

```c
int y, m, d;
scanf("%d-%d-%d", &y, &m, &d);   // 輸入：2024-03-09
printf("%d/%d/%d\n", m, d, y);   // 輸出：3/9/2024
```

**字元集合 `%[...]`**：只讀「在集合裡」的字元；`%[^...]` 讀「不在集合裡」的字元。

```c
char line[100];
scanf("%99[^\n]", line);         // 讀到換行為止（可以讀到空白）
printf("[%s]\n", line);          // 輸入：hello world → 輸出：[hello world]
```

讀一整行比較推薦用 `fgets`（第 10 課），比較不容易出錯。

## 4.7 🔍 為什麼 scanf 很容易出問題？

- 格式錯誤時，**錯誤的輸入會留在輸入緩衝區裡**，下一次 `scanf` 又讀到同一個地方，又失敗 → 程式卡在無窮迴圈。
- `%d` 讀到超出 `int` 範圍的數字是未定義行為。
- `%c`、`%[` 不跳過空白，和 `%d` 混用時要很小心。

正式的程式常改用「`fgets` 讀一整行 → 再用 `sscanf` 或 `strtol` 解析」（第 10 課）。競賽和練習題的輸入格式固定，直接用 `scanf` 沒問題。

# 習題

### 題 1：預測輸出

```c
printf("[%6.2f][%-6d][%06d][%x]\n", 3.14159, 42, -42, 255);
```

### 題 2：找出所有錯誤

```c
#include <stdio.h>
int main(void) {
    int n;
    double avg;
    char name[10];
    scanf("%d %f %s", n, &avg, &name);
    printf("%s: %d, %d\n", name, n, avg);
}
```

### 題 3：預測輸出

```c
int a = 017, b = 0x11, c = 11;
printf("%d %d %d\n", a, b, c);
```

### 題 4：輸入是「`3`」換行「`A`」，下面的程式印出什麼？怎麼修？

```c
int n; char c;
scanf("%d", &n);
scanf("%c", &c);
printf("n=%d c=%d\n", n, c);
```

### 題 5：為什麼下面的迴圈在輸入結束時不會停？

```c
int x;
while (scanf("%d", &x)) {
    printf("%d\n", x * 2);
}
```

### 題 6：預測輸出

```c
long long a = 1000000 * 1000000;
long long b = 1000000LL * 1000000;
printf("%d\n", a == b);
```

### 題 7：寫出 printf 的格式字串，輸出 `|  3.50|7    |0042|`（數字分別是 `3.5`、`7`、`42`）。

### 題 8：`sizeof(long)` 在 64 位元 Linux 和 64 位元 Windows 上分別是多少？為什麼這很重要？

---

# 習題解答

**題 1**：`[  3.14][42    ][-00042][ff]`。
- `%6.2f`：寬度 6、小數 2 位 → `  3.14`。
- `%-6d`：寬度 6、靠左 → `42    `。
- `%06d`：寬度 6、補 0，負號佔一格 → `-00042`。
- `%x`：255 的十六進位 → `ff`。

**題 2**：
- `scanf` 的 `n` 少了 `&`：應該是 `&n`。
- 讀 `double` 要用 `%lf`，不是 `%f`。
- `name` 是陣列，不用加 `&`；而且 `%s` 沒有限制長度，應該寫 `%9s`。
- `printf` 用 `%d` 印 `double avg`：應該是 `%f`。

修正：`scanf("%d %lf %9s", &n, &avg, name); printf("%s: %d, %f\n", name, n, avg);`

**題 3**：`15 17 11`。`017` 開頭是 0 → 八進位 = 1×8 + 7 = 15；`0x11` 是十六進位 = 17。

**題 4**：印出 `n=3 c=10`。`%c` 不會跳過空白，讀到的是 `3` 後面的換行字元（ASCII 10）。修正：`scanf(" %c", &c);`，就會印出 `n=3 c=65`。

**題 5**：碰到輸入結束時，`scanf` 回傳 `EOF`（-1），而 -1 是「真」，迴圈不會停；而且 `x` 沒有被更新，會一直印出同一個數。另外，輸入不是數字時回傳 0 才會停。修正：`while (scanf("%d", &x) == 1)`。

**題 6**：`0`。`1000000 * 1000000` 兩個都是 `int`，用 `int` 計算會溢位（未定義行為，實際上得到錯誤的值），結果才轉成 `long long` 已經來不及了；`b` 有一邊是 `long long`，計算正確。

**題 7**：`printf("|%6.2f|%-5d|%04d|\n", 3.5, 7, 42);`

**題 8**：Linux 是 8，Windows 是 4。同一份程式，用 `long` 存超過 2 × 10⁹ 的數字，在 Linux 正確、在 Windows 溢位。要確定大小的話用 `long long`（至少 64 位元）或 `<stdint.h>` 的 `int64_t`。
