# 00. C 語言：學習路線圖

> 這條路線學的是 **C 語言**（C11 標準），不是 C++。C 是 C++ 的「祖先」，也是作業系統、嵌入式系統、資料庫、程式語言直譯器最常用的語言。

## 為什麼要學 C？

- **離電腦最近的高階語言**：C 沒有 `vector`、`string`、`class`、例外、自動釋放記憶體 —— 每一個位元組都要自己管理。學會 C，你就真正懂了「記憶體」和「指標」在做什麼。
- **到處都是 C**：Linux 核心、Python 直譯器（CPython）、SQLite、Redis、Git、各種微控制器的韌體，都是用 C 寫的。
- **學 C++ 的基礎**：C++ 幾乎完全相容 C。C++ 的 `string`、`vector`、`unique_ptr` 其實就是把 C 裡要「自己小心」的事情包裝起來。先學 C，就知道 C++ 幫你做了什麼。

## C 和 C++ 有什麼不同？

| 功能 | C++ | C |
|---|---|---|
| 輸出入 | `cout << x`、`cin >> x` | `printf("%d", x)`、`scanf("%d", &x)` |
| 字串 | `std::string`（自動管理） | `char` 陣列 + 結尾的 `'\0'`（自己管理） |
| 動態陣列 | `std::vector` | `malloc` / `realloc` / `free` 自己管理 |
| 配置記憶體 | `new` / `delete`（或智慧指標） | `malloc` / `free` |
| 傳參考 | `void f(int& x)` | 沒有參考，只能傳指標 `void f(int *x)` |
| 類別 | `class`、成員函式、建構子、解構子 | 只有 `struct`（只有資料），函式寫在外面 |
| 泛型 | 模板 `template <class T>` | `void *` + 函式指標（例如 `qsort`） |
| 函式多載 | 可以（同名不同參數） | **不行**：每個函式名字都要不同 |
| 錯誤處理 | 例外 `throw` / `catch` | 回傳值（錯誤碼）、`errno` |
| 布林 | `bool`、`true` / `false` | C99 起 `#include <stdbool.h>`（C23 才變成關鍵字） |
| 標準函式庫 | STL：容器、演算法 | 很小：`<stdio.h>`、`<stdlib.h>`、`<string.h>`、`<math.h>`…… |

## 建議的順序

- **從沒寫過 C**：01 → 02 → 03 → 04，先能寫出能動的程式。
- **核心中的核心**：05 → 06 → 07。指標、字串、動態記憶體是 C 最難也最重要的部分，一定要搞懂。
- **組織資料與程式**：08 → 09 → 10 → 11。
- **綜合應用**：12，用前面學到的所有東西，親手寫出 `vector`、串列、雜湊表。

如果你已經學過 C++ 深入路線，可以直接從 05 開始，重點看「C 沒有 C++ 的哪些東西，要怎麼自己做」。

## 每一課的結構

1. **課程地圖**：這一課分成哪幾部分、讀完會知道什麼。
2. **觀念說明**：依序說明 **是什麼 → 為什麼需要 → 怎麼用（範例）→ 常見錯誤**。範例裡的 `// 輸出：` 都是實際用 `gcc -std=c11` 編譯執行過的結果。
3. **🔍 深入**：標著這個符號的段落，是「底層到底發生什麼事」，第一次讀可以跳過。
4. **名詞總表**。
5. **習題**：預測輸出、找 bug、簡答，附詳解。

## 怎麼做程式練習？

題目用 **C** 作答（檔名是 `.c`，用 `gcc -std=c11` 編譯）：

```bash
python3 judge.py serve            # 網頁版，上方切換到「🅲 C 語言」
python3 judge.py start cl3        # 命令列：建立 workspace/cl03_pointer_ops.c
python3 judge.py test cl3         # 評測
python3 judge.py test cl3 --debug # 用 AddressSanitizer 抓越界、記憶體錯誤（C 非常需要！）
```

需要的工具：**gcc**（Linux：`sudo apt install gcc`；Mac：`xcode-select --install`；Windows：和 g++ 一起裝的 MinGW 就有 gcc）。

好幾題（`CL04`、`CL05`、`CL08`、`CL10`）會在程式結束時檢查 **記憶體洩漏**：樣板提供 `xmalloc` / `xfree`，記錄配置和釋放的次數，對不起來就會輸出 `leak check: ... not freed`。在 C 裡，`malloc` 了就一定要 `free`，沒有人會幫你。
