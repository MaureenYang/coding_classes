# CL01. 格式化輸入輸出 (printf / scanf)

> 主題：`printf` 格式字串、`scanf` 讀不同型別　難度：★☆☆　時間限制：1 秒　相關教學：`c/lessons/01_basics_io.md`

## 題目

每一行給你一個「型別」和一個「值」，請用 `printf` 依照下表的格式輸出。
每個欄位都用中括號 `[ ]` 包起來，欄位之間用一個空白隔開，這樣看得出寬度和對齊。

| 輸入 | 輸出格式（printf 格式字串） |
|---|---|
| `int x` | `[%d] [%5d] [%-5d] [%05d] [%+d] [%x] [%o]` |
| `float f` | `[%.2f] [%8.3f] [%-8.1f] [%e] [%g]` |
| `str s` | `[%s] [%10s] [%-10s] [%.3s]` |
| `char c` | `[%c] [%d] [%c]`（第二個是字元的 ASCII 編碼，第三個是 **轉成大寫** 後的字元，不是字母就不變） |
| `time h m s` | `[%02d:%02d:%02d]`（`s` 是總秒數換算前的值，見下方說明） |

`time h m s`：把 `h` 小時 `m` 分 `s` 秒 **正規化**（秒數 ≥ 60 要進位到分、分 ≥ 60 要進位到小時，小時不用取餘數），再用 `HH:MM:SS` 輸出。例如 `time 1 59 75` → `[02:00:15]`。

## 輸入

第一行整數 `T`。接下來 `T` 行，每行是上表其中一種。

- `int`：`-10^9 ≤ x ≤ 10^9`
- `float`：`|f| ≤ 10^6`，最多 6 位小數（用 `double` 讀取）
- `str`：1 ~ 20 個非空白字元
- `char`：一個非空白的可見字元
- `time`：`0 ≤ h, m, s ≤ 10^6`

## 輸出

每一行輸入輸出一行。

## 範例

輸入
```
5
int 42
int -255
float 3.14159
str hello
time 1 59 75
```
輸出
```
[42] [   42] [42   ] [00042] [+42] [2a] [52]
[-255] [ -255] [-255 ] [-0255] [-255] [ffffff01] [37777777401]
[3.14] [   3.142] [3.1     ] [3.141590e+00] [3.14159]
[hello] [     hello] [hello     ] [hel]
[02:00:15]
```

## 提示

- `%x`、`%o` 要的是 **無號整數**（`unsigned int`）。負數要先轉型：`(unsigned)x`，所以 `-255` 會印出 `ffffff01`（二補數，第 01 課）。
- 讀字串用 `scanf("%s", buf)`（`buf` 是陣列，**不用加 `&`**）；讀字元用 `scanf(" %c", &c)`，`%c` 前面的空白會跳過換行和空格。
- 讀 `double` 要用 `%lf`，印 `double` 用 `%f` 就可以。
- 轉大寫用 `<ctype.h>` 的 `toupper`。
- 正規化時間：先全部換成秒，`total = h * 3600LL + m * 60 + s`，再拆回時分秒。注意 `long long`：`10^6 × 3600` 會超過 `int`。
