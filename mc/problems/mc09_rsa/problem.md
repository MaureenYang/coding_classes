# MC09. RSA 加解密 (RSA)

> 主題：RSA 公鑰密碼、RSA 數位簽章　難度：★★　時間限制：1 秒　相關教學：`mc/lessons/10-euler-rsa.md`、`mc/lessons/25-digital-signatures.md`

## 題目

處理 q 個指令：

| 指令 | 意思 | 輸出 |
|---|---|---|
| `KEY p q e` | Alice 用質數 p、q 和加密指數 e 建金鑰 | `N d`：`N = pq`，`d ≡ e⁻¹ (mod (p−1)(q−1))`，`0 < d < (p−1)(q−1)`；e 和 (p−1)(q−1) 不互質時輸出 `invalid` |
| `ENC N e m` | Bob 用公鑰 (N, e) 加密 m | `c = mᵉ mod N` |
| `DEC p q e c` | Alice 解密 | `m = c^d mod N` |
| `VERIFY N e D S` | 驗證 S 是不是文件 D 的 RSA 簽章 | `Sᵉ ≡ D (mod N)` 就輸出 `valid`，否則 `invalid` |

## 輸入

第一行是 q，接下來 q 行，每行一個指令。

## 限制

- `1 ≤ q ≤ 3 × 10⁴`
- p、q 是相異質數，`3 ≤ p, q < 2³¹`（所以 `N < 2⁶²`）；`3 ≤ e < 2⁶²`
- `0 ≤ m, c, D, S < N`；`DEC` 的金鑰保證有效

## 範例

輸入
```
5
KEY 1223 1987 948047
ENC 2430101 948047 1070777
DEC 1223 1987 948047 1473513
KEY 11 13 3
VERIFY 2430101 948047 1070777 153337
```
輸出
```
2430101 1051235
1473513
1070777
invalid
valid
```

前三行是課本例 3.8：`N = 1223 · 1987 = 2430101`，`d = 1051235`，Bob 的明文 1070777 加密成 1473513。`KEY 11 13 3`：`(p−1)(q−1) = 120` 是 3 的倍數，e = 3 不能用。最後一行是課本例 7.4 的簽章（第 25 課）。

## 提示

- `(p−1)(q−1) < 2⁶²`，擴展歐幾里得用 `long long` 就夠；但 `powmod` 裡的乘法要用 `unsigned __int128`。
- 驗證簽章只需要公鑰：`Sᵉ mod N` 和 D 比較。
