# MC11. 整數分解 (Integer Factorization)

> 主題：Pollard ρ 分解法、Miller–Rabin　難度：★★★★　時間限制：2 秒　相關教學：`mc/lessons/12-pollard-difference-of-squares.md`、`mc/lessons/16-probability-collisions-rho.md`

## 題目

把 T 個整數 n 分解成質因數。n 可以接近 2⁶³，可能是 **兩個 31 位元質數的乘積**——試除法要試到 3 × 10⁹，來不及。

**Pollard ρ**：取 `f(x) = x² + c (mod n)`，從 `x = y = 2` 出發，x 每次走一步、y 每次走兩步（`x ← f(x)`，`y ← f(f(y))`），並計算 `d = gcd(|x − y|, n)`：

- `d = 1`：繼續走。
- `1 < d < n`：找到一個因數。
- `d = n`：這個 c 失敗，換下一個 c 重來。

**為什麼有效**：設 p 是 n 的質因數。數列 `x mod p` 只有 p 種值，根據生日悖論，大約 `√p` 步就會 **重複**（走進一個圈，形狀像 ρ）；Floyd 判圈法讓 x、y 在圈上相遇，這時 `p | x − y`。n 最小的質因數 ≤ √n，所以大約 `n^(1/4)` ≈ 5 × 10⁴ 步就夠了。

完整的分解：先用 **Miller–Rabin** 判斷 n 是不是質數（MC10）；不是的話用 ρ 拆成 `d · (n/d)`，兩半各自遞迴。

## 輸入

第一行是 T，接下來 T 行，每行一個整數 n。

## 輸出

每個 n 輸出一行：質因數由小到大，空白隔開；指數大於 1 時寫成 `p^e`。

## 限制

- `1 ≤ T ≤ 100`
- `2 ≤ n < 2⁶³`

## 範例

輸入
```
5
12
97
13927189
1000000016000000063
1024
```
輸出
```
2^2 3
97
3643 3823
1000000007 1000000009
2^10
```

13927189 是課本例 3.29（Pollard p − 1 法）的數字。

## 提示

- 樣板已經有 Miller–Rabin（`is_prime`），也先試除掉 100 以下的小質數。
- 每走一步都算 gcd 很慢：可以把 128 個 `|x − y|` 乘起來（mod n）再做一次 gcd；如果得到 n，就退回這一批的開頭，一步一步重做。
- 乘法一律用 `unsigned __int128`。
