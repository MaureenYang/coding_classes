# MC14. 二維格基約化 (Gaussian Lattice Reduction)

> 主題：格、Gauss 格基約化、最短向量問題　難度：★★★　時間限制：1 秒　相關教學：`mc/lessons/22-lattices-svp-cvp-babai.md`、`mc/lessons/24-lattice-reduction-lll.md`

## 題目

給二維格的一組基底 v₁、v₂（整數向量，線性獨立），用 **Gauss 格基約化** 求出一組好基底。請 **照下面的步驟** 做：

```
loop:
    if ‖v₂‖² < ‖v₁‖²:  交換 v₁、v₂          （只有「嚴格小於」才交換）
    m = round(v₁ · v₂ / ‖v₁‖²)              （0.5 往上進位：m = ⌊v₁·v₂/‖v₁‖² + 1/2⌋）
    if m == 0:  輸出 v₁、v₂，結束
    v₂ ← v₂ − m·v₁
```

結束時 v₁ 就是格中 **最短的非零向量**。

## 輸入

第一行是 T，接下來 T 行，每行四個整數 `a b c d`，表示 `v₁ = (a, b)`、`v₂ = (c, d)`。

## 輸出

每筆輸出一行四個整數：約化後的 v₁、v₂。

## 限制

- `1 ≤ T ≤ 10⁵`
- 座標的絕對值 `≤ 10⁹`，`ad − bc ≠ 0`

## 範例

輸入
```
3
66586820 65354729 6513996 6393464
1 0 0 1
3 1 5 2
```
輸出
```
2280 -1001 -1324 -2376
1 0 0 1
-1 0 0 1
```

第一筆是課本例 6.64：長度約 9 × 10⁷ 和 9 × 10⁶ 的基底，約化成長度約 2490 和 2720 的基底（行列式都是 6742604）。

## 提示

- **不要用浮點數算 round**：數字很大時會出錯。用整數：`m = ⌊(2·dot + n₁) / (2·n₁)⌋`，其中 `dot = v₁·v₂`、`n₁ = ‖v₁‖²`。
- C 的整數除法是 **向 0 截斷**，不是向下取整：分子是負數時要自己修正（樣板裡有 `floor_div`）。
- `‖v‖²` 可以到 2 × 10¹⁸，`2·dot + n₁` 會超過 `long long`：用 `__int128`。
