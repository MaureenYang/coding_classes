# MC07. 中國剩餘定理 (Chinese Remainder Theorem)

> 主題：中國剩餘定理、模反元素、128 位元乘法　難度：★★　時間限制：1 秒　相關教學：`mc/lessons/08-crt-pohlig-hellman.md`

## 題目

每筆測資給 k 個同餘式

```
x ≡ a₁ (mod m₁)
x ≡ a₂ (mod m₂)
  ⋮
x ≡ a_k (mod m_k)
```

模數 **兩兩互質**。輸出唯一的解 x，`0 ≤ x < M = m₁m₂⋯m_k`。

**逐一合併**：設目前已經知道 `x ≡ x₀ (mod M)`，要再加上 `x ≡ a (mod m)`。所有滿足第一式的數都是 `x₀ + M·y`，代入第二式：

```
x₀ + M·y ≡ a (mod m)   ⇒   y ≡ (a − x₀) · M⁻¹ (mod m)
```

（M 和 m 互質，所以 M⁻¹ 存在。）新的解是 `x₀ + M·y`，模數變成 `M·m`。

## 輸入

第一行是 T。每筆測資第一行是 k，接下來 k 行，每行 `aᵢ mᵢ`。

## 限制

- `1 ≤ T ≤ 10⁴`，`1 ≤ k ≤ 15`
- `1 ≤ mᵢ`，模數兩兩互質，`M = Π mᵢ ≤ 10¹⁸`；`0 ≤ aᵢ < mᵢ`

## 範例

輸入
```
3
2
2 3
3 7
3
2 3
3 7
4 16
1
5 8
```
輸出
```
17
164
5
```

第二筆是課本例 2.26：`x ≡ 2 (mod 3)`、`x ≡ 3 (mod 7)`、`x ≡ 4 (mod 16)`，解是 `x ≡ 164 (mod 336)`。

## 提示

- `M·y` 和 `(a − x₀)·M⁻¹` 都可能超過 64 位元：先轉 `__int128` 再乘、再取模。
- `a − x₀` 可能是負的，取模後要調整到 `[0, m)`。
- 不需要先算出最後的 M 再回頭處理；逐一合併最簡單。
