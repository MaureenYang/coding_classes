# MC06. 嬰兒步巨人步 (Baby-step Giant-step)

> 主題：離散對數問題、Shanks 嬰兒步巨人步、雜湊表　難度：★★★　時間限制：2 秒　相關教學：`mc/lessons/07-groups-bsgs.md`

## 題目

給質數 p 和 g、h，求 **最小的** 非負整數 x 使

```
gˣ ≡ h (mod p)
```

沒有解時輸出 `-1`（g 不一定是原根，h 可能不在 g 生成的子群裡）。

p 可以大到 10¹²，暴力試要 10¹² 步；**嬰兒步巨人步** 只要大約 2√p ≈ 2 × 10⁶ 步：

1. 令 `n = ⌊√(p − 1)⌋ + 1`（所以 n² > p − 1 ≥ g 的階）。
2. **嬰兒步**：把 `g⁰, g¹, …, g^(n−1)` 放進雜湊表（值 → 指數 j；同一個值只保留最小的 j）。
3. **巨人步**：令 `u = g^(−n)`，依序算 `h, h·u, h·u², …, h·uⁿ`。第一次在表中找到 `h·uⁱ = gʲ` 時，`gⁱⁿ⁺ʲ = h`，答案是 `x = i·n + j`。
4. 全部找完都沒有：無解。

**為什麼找到的是最小解**：任何解 x 都可以寫成 `i·n + j`（0 ≤ j < n）。i 由小到大找，而且表裡存的是最小的 j，所以第一個找到的就是最小的 x。

## 輸入

第一行是 T，接下來 T 行，每行 `p g h`。

## 限制

- `1 ≤ T ≤ 10`
- `5 ≤ p ≤ 10¹²`，p 是質數；`1 ≤ g, h ≤ p − 1`

## 範例

輸入
```
4
17389 9704 13896
11 2 1
11 3 2
11 3 9
```
輸出
```
1159
0
-1
2
```

第一筆是課本例 2.23：`9704¹¹⁵⁹ ≡ 13896 (mod 17389)`。模 11 時 3 的階是 5，生成 {1, 3, 9, 5, 4}，2 不在裡面。

## 提示

- 雜湊表用 **開放定址 + 線性探測**（樣板裡已經配置好 2²² 格的陣列）。每筆測資開始前要清空。
- `u = g^(−n) = (gⁿ)^(p−2)`（費馬小定理）。
- `√(p − 1)` 用 `sqrtl` 算，避免 `double` 的誤差。
