# MC03. 快速冪 (Fast Powering)

> 主題：平方乘法演算法、128 位元乘法　難度：★★　時間限制：1 秒　相關教學：`mc/lessons/03-modular-arithmetic.md`

## 題目

q 筆詢問，每筆給 a、e、m，輸出 `aᵉ mod m`。

e 可以大到 2⁶³，一次一次乘絕對來不及：要用 **平方乘法**（快速冪），只需要大約 2·log₂ e 次乘法。

## 輸入

第一行是 q，接下來 q 行，每行三個整數 `a e m`。

## 限制

- `1 ≤ q ≤ 10⁵`
- `0 ≤ a, e < 2⁶³`，`1 ≤ m < 2⁶³`
- 約定 `0⁰ = 1`；`m = 1` 時答案一律是 0

## 範例

輸入
```
4
3 218 1000
2 10 1000
5 0 7
123 456 1
```
輸出
```
489
24
1
0
```

（`3²¹⁸ mod 1000 = 489` 是課本例 1.19。）

## 提示

```
r = 1 % m;  a %= m;
while (e > 0) {
    if (e & 1) r = r·a mod m;
    a = a·a mod m;
    e >>= 1;
}
```

- m 接近 2⁶³ 時 `a·a` 會超過 64 位元：`(unsigned __int128)a * b % m`。
- 用 `unsigned long long` 和 `%llu` 讀寫。
