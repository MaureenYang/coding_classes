# MC13. 橢圓曲線運算 (Elliptic Curve Arithmetic)

> 主題：橢圓曲線加法、倍加法　難度：★★★　時間限制：2 秒　相關教學：`mc/lessons/18-elliptic-curves-ecdlp.md`、`mc/lessons/19-ecc-lenstra-binary-curves.md`

## 題目

有限體 F_p 上的橢圓曲線 `E : Y² = X³ + AX + B`。處理 q 個指令：

| 指令 | 輸出 |
|---|---|
| `ADD P Q` | P + Q |
| `MUL k P` | kP = P + P + ⋯ + P（k 個），`0P = O` |

點寫成 `x y`，**無窮遠點** 寫成 `O`（大寫英文字母）。

**加法公式**（P = (x₁, y₁)、Q = (x₂, y₂)）：

- `O + Q = Q`，`P + O = P`。
- `x₁ = x₂` 且 `y₁ + y₂ ≡ 0`：`P + Q = O`（包括 y₁ = 0 時的 P + P）。
- 否則令
  ```
  λ = (y₂ − y₁) / (x₂ − x₁)        P ≠ Q（割線）
  λ = (3x₁² + A) / (2y₁)            P = Q（切線）
  ```
  則 `x₃ = λ² − x₁ − x₂`，`y₃ = λ(x₁ − x₃) − y₁`。

所有運算都在 F_p 中（mod p；除法 = 乘以反元素）。kP 用 **倍加法**（和快速冪一樣，只是「乘」換成「加」）。

## 輸入

第一行 `p A B`，第二行 q，接下來 q 行，每行一個指令。

## 限制

- `7 ≤ p < 2⁶²`，p 是質數；`0 ≤ A, B < p`，`4A³ + 27B² ≢ 0`
- `1 ≤ q ≤ 2000`
- 輸入的點都在曲線上；`0 ≤ k < 2⁶³`

## 範例

輸入
```
13 3 8
5
ADD 9 7 1 8
ADD 9 7 9 7
ADD 9 7 9 6
MUL 0 9 7
ADD O 1 8
```
輸出
```
2 10
9 6
O
O
1 8
```

課本例 5.8、5.10：在 `Y² = X³ + 3X + 8`（mod 13）上，`(9, 7) + (1, 8) = (2, 10)`，`2(9, 7) = (9, 6)`，`(9, 6)` 是 `(9, 7)` 的反元素。

## 提示

- 用一個 struct 表示點：`{ int inf; u64 x, y; }`。
- 減法要先加 p：`(a + p − b) % p`。乘法用 `unsigned __int128`。
- 反元素用費馬：`a^(p−2)`。
