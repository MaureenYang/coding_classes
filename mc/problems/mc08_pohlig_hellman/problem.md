# MC08. Pohlig–Hellman (Pohlig–Hellman Algorithm)

> 主題：Pohlig–Hellman 演算法、離散對數、中國剩餘定理　難度：★★★★　時間限制：2 秒　相關教學：`mc/lessons/08-crt-pohlig-hellman.md`

## 題目

給質數 p、**原根** g 和 h，求 `0 ≤ x < p − 1` 使 `gˣ ≡ h (mod p)`。

p 可以大到 10¹⁸，連嬰兒步巨人步（約 10⁹ 步）都來不及。但測資保證 **p − 1 的每個質因數都 ≤ 10⁵**——這種 p 的 DLP 可以用 **Pohlig–Hellman** 快速解出：

1. 分解 `N = p − 1 = q₁^e₁ ⋯ q_t^e_t`。
2. 對每個 `qᵢ^eᵢ`：令 `gᵢ = g^(N/qᵢ^eᵢ)`、`hᵢ = h^(N/qᵢ^eᵢ)`。gᵢ 的階是 `qᵢ^eᵢ`，而 `x mod qᵢ^eᵢ` 就是 `gᵢʸ = hᵢ` 的解。
3. **一次解一位數**：階是 `q^e` 的 DLP，把 y 寫成 q 進位 `y₀ + y₁q + ⋯ + y_{e−1}q^(e−1)`。令 `γ = gᵢ^(q^(e−1))`（階為 q），依序對 k = 0, 1, …, e − 1：
   ```
   (hᵢ · gᵢ^(−已求出的部分))^(q^(e−1−k)) = γ^(y_k)
   ```
   每一位只要在 0..q − 1 裡找。
4. 用 **中國剩餘定理** 把所有 `x ≡ yᵢ (mod qᵢ^eᵢ)` 合併成 `x mod N`。

## 輸入

第一行是 T，接下來 T 行，每行 `p g h`。

## 限制

- `1 ≤ T ≤ 10`
- `3 ≤ p ≤ 10¹⁸`，p 是質數，**p − 1 的質因數都 ≤ 10⁵**
- g 是模 p 的原根，`1 ≤ h ≤ p − 1`

## 範例

輸入
```
2
11251 23 9689
11251 23 1
```
輸出
```
4261
0
```

課本例 2.37：`N = 11250 = 2 · 3² · 5⁴`，三個小問題的解是 `x ≡ 1 (mod 2)`、`x ≡ 4 (mod 9)`、`x ≡ 511 (mod 625)`，合併得到 4261。

## 提示

- 分解 p − 1：從 q = 2 往上試除，n 除到 1 就停（質因數都 ≤ 10⁵，最多試 10⁵ 個 q）。
- 每一位的小 DLP 直接暴力（最多 10⁵ 次），也可以用嬰兒步巨人步。
- `gᵢ` 的反元素用費馬：`gᵢ^(p−2)`。CRT 的模數 qᵉ 不是質數，反元素要用擴展歐幾里得。
