# MC17. Shamir 秘密分享 (Shamir Secret Sharing)

> 主題：門檻秘密分享、多項式、Lagrange 內插　難度：★★★　時間限制：1 秒　相關教學：`mc/lessons/26-additional-topics.md`

## 題目

**(t, n) 門檻秘密分享**：把秘密 S 分給 n 個人，任 t 個人合作可以還原 S，少於 t 個人得不到任何資訊。

Shamir 的方法（在 F_p 中）：隨機選 `a₁, …, a_{t−1}`，令

```
f(x) = S + a₁x + a₂x² + ⋯ + a_{t−1}x^(t−1)   (mod p)
```

第 i 個人拿到 `(i, f(i))`。t 個點決定一個 t − 1 次多項式，所以 t 個人可以用 **Lagrange 內插** 求出 `f(0) = S`：

```
f(0) = Σᵢ yᵢ · Π_{j≠i} xⱼ / (xⱼ − xᵢ)   (mod p)
```

處理 q 個指令：

| 指令 | 輸出 |
|---|---|
| `SHARE S t n a₁ … a_{t−1}` | `f(1) f(2) … f(n)`，空白隔開 |
| `RECOVER k x₁ y₁ … x_k y_k` | 通過這 k 個點、次數 < k 的多項式在 0 的值（mod p） |

## 輸入

第一行質數 p，第二行 q，接下來 q 行，每行一個指令。

## 限制

- `50 ≤ p < 2⁶²`，p 是質數；`1 ≤ q ≤ 200`
- `1 ≤ t ≤ n ≤ 100`，`n < p`；`1 ≤ k ≤ 100`
- 所有數都在 `[0, p)`；`RECOVER` 的 xᵢ 互不相同，而且都不是 0

## 範例

輸入
```
101
3
SHARE 11 2 3 34
RECOVER 2 1 45 3 12
RECOVER 3 1 45 2 79 3 12
```
輸出
```
45 79 12
11
11
```

`f(x) = 11 + 34x`（mod 101）：`f(1) = 45`、`f(2) = 79`、`f(3) = 113 ≡ 12`。任兩份都能還原秘密 11；三份當然也可以（第 26 課的習題 2）。

## 提示

- 求 f(x) 用 **Horner 法**：`y = 0; for i = t−1..0: y = y·x + aᵢ`。
- 除法 = 乘以反元素（p 是質數，用費馬：`d^(p−2)`）。分母 `xⱼ − xᵢ` 要先加 p 再取模。
- 乘法用 `unsigned __int128`。
