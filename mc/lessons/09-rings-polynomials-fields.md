# 第一部分：環與體

## 1.1 定義

**環**（ring）：一個集合 R，有兩個運算 + 和 ⋆，滿足

| 關於 + | 關於 ⋆ | 連接兩者 |
|---|---|---|
| 有 0、每個元素有 −a、結合律、交換律 | 有 1、結合律、交換律 | 分配律 `a ⋆ (b + c) = a⋆b + a⋆c` |

換句話說：(R, +) 是交換群；乘法有單位元素但 **不要求有反元素**。（課本只考慮乘法可交換、有 1 的環。）

**體**（field）：**每個非零元素都有乘法反元素** 的環。

| 例子 | 是環嗎 | 是體嗎 | 單位（有乘法反元素的元素） |
|---|---|---|---|
| Z | 是 | 否 | 只有 ±1 |
| Q、R、C | 是 | 是 | 所有非零元素 |
| Z/mZ | 是 | m 是質數時才是 | 和 m 互質的元素 |
| F[x]（係數在體 F 的多項式） | 是 | 否 | 非零常數 |

## 1.2 整除、單位、不可約

和整數一樣，在任何環裡都能定義：
- **整除**：`b | a` 如果存在 c 使 `a = b ⋆ c`。
- **單位**（unit）：有乘法反元素的元素。
- **不可約**（irreducible）：a 不是單位，而且每次寫成 `a = b ⋆ c` 時，b 或 c 一定是單位。在 Z 裡，正的不可約元素就是質數。

**零因子**：有些環裡兩個非零元素相乘會得 0，例如 Z/6Z 裡 `2 · 3 = 0`。零因子一定不是單位（如果 2 有反元素，`3 = 2⁻¹ · 2 · 3 = 0`，矛盾），所以 **體裡沒有零因子**。

# 第二部分：商環

## 2.1 任意環的同餘

R 是環、m ∈ R 非零。`a ≡ b (mod m)` 定義為 `m | (a − b)`。和整數一樣，同餘可以相加、相減、相乘（命題 2.42）。

## 2.2 商環 R/(m)

把所有模 m 同餘的元素歸成一類，叫做 **同餘類**（congruence class）。所有同餘類形成的集合記作 `R/(m)` 或 `R/mR`，運算規則是「代表元相加、相乘」：

```
[a] + [b] = [a + b]，  [a] ⋆ [b] = [a ⋆ b]
```

命題 2.44 說這樣定義是 **良好定義的**（不管挑哪個代表元，結果一樣），而且 R/(m) 又是一個環，叫 **商環**（quotient ring）。

Z/mZ 就是 R = Z 的例子。下一步：把 R 換成 **多項式環**。

# 第三部分：多項式環 F[x]

## 3.1 多項式的帶餘除法

`F[x]` 是係數在體 F 中的多項式。**次數** deg(a) 是最高次項的指數。

**命題 2.45（F[x] 是歐幾里得環）**：b ≠ 0 時，可以寫成

```
a = b · k + r，  r = 0 或 deg r < deg b
```

（需要 F 是體，因為每一步要除以 b 的最高次係數。）

下面用一個小工具在 F_p[x] 上做運算。多項式用 **係數串列** 表示，從常數項開始：`[c₀, c₁, c₂, …]` 代表 `c₀ + c₁x + c₂x² + ⋯`。

```python
def trim(a):
    while a and a[-1] == 0:
        a = a[:-1]
    return a

def pdivmod(a, b, p):
    a, b = trim([c % p for c in a]), trim([c % p for c in b])
    inv = pow(b[-1], -1, p)
    q = [0] * max(len(a) - len(b) + 1, 1)
    r = a[:]
    while r and len(r) >= len(b):
        shift = len(r) - len(b)
        c = r[-1] * inv % p
        q[shift] = c
        for i, bc in enumerate(b):
            r[i + shift] = (r[i + shift] - c * bc) % p
        r = trim(r)
    return trim(q), r

def show(a):
    terms = [f"{c}" if i == 0 else f"{'' if c == 1 else c}x{'' if i == 1 else '^' + str(i)}"
             for i, c in enumerate(a) if c]
    return " + ".join(reversed(terms)) or "0"

# 課本例 2.48 的第一步：在 F₁₃[x] 中，x⁵ − 1 除以 x³ + 2x − 3
q, r = pdivmod([-1, 0, 0, 0, 0, 1], [-3, 2, 0, 1], 13)
print(show(q), "|", show(r))
```
```output
x^2 + 11 | 3x^2 + 4x + 6
```
商 `x² + 11`、餘式 `3x² + 4x + 6`，和課本一致。

## 3.2 gcd 與擴展歐幾里得

**gcd**：同時整除 a、b，而且被所有公因式整除的多項式。gcd 只決定到差一個非零常數倍，習慣上取 **首一**（monic，最高次係數是 1）的那個。

**命題 2.47**：F[x] 中 gcd 存在，而且有 `a·u + b·v = gcd(a, b)`——和整數完全一樣，因為我們只用到帶餘除法。

```python
def trim(a):
    while a and a[-1] == 0:
        a = a[:-1]
    return a

def pdivmod(a, b, p):
    a, b = trim([c % p for c in a]), trim([c % p for c in b])
    inv = pow(b[-1], -1, p)
    q = [0] * max(len(a) - len(b) + 1, 1)
    r = a[:]
    while r and len(r) >= len(b):
        shift = len(r) - len(b)
        c = r[-1] * inv % p
        q[shift] = c
        for i, bc in enumerate(b):
            r[i + shift] = (r[i + shift] - c * bc) % p
        r = trim(r)
    return trim(q), r

def pgcd(a, b, p):
    a, b = trim([c % p for c in a]), trim([c % p for c in b])
    while b:
        print("  ", a, "=", b, "· q +", pdivmod(a, b, p)[1])
        a, b = b, pdivmod(a, b, p)[1]
    inv = pow(a[-1], -1, p)
    return [c * inv % p for c in a]          # 化成首一

print(pgcd([-1, 0, 0, 0, 0, 1], [-3, 2, 0, 1], 13))       # 課本例 2.48
print(pgcd([-1, 0, 1], [1, 0, 0, 1], 13))                  # gcd(x² − 1, x³ + 1)
```
```output
   [12, 0, 0, 0, 0, 1] = [10, 2, 0, 1] · q + [6, 4, 3]
   [10, 2, 0, 1] = [6, 4, 3] · q + [4, 9]
   [6, 4, 3] = [4, 9] · q + []
[12, 1]
   [12, 0, 1] = [1, 0, 0, 1] · q + [12, 0, 1]
   [1, 0, 0, 1] = [12, 0, 1] · q + [1, 1]
   [12, 0, 1] = [1, 1] · q + []
[1, 1]
```
第一個：最後一個非零餘式是 `9x + 4`，乘以 `9⁻¹ = 3` 化成首一得 `x − 1`（`[12, 1]` 就是 `x + 12 = x − 1`）。第二個：`gcd(x² − 1, x³ + 1) = x + 1`（課本例 2.46）。

## 3.3 不可約多項式與唯一分解

**不可約多項式**：不能寫成兩個 **次數 ≥ 1** 的多項式相乘。它就是多項式世界的「質數」。

**命題 2.50**：F[x] 中每個非零多項式都能 **唯一** 分解成「常數 × 首一不可約多項式的乘積」。證明和整數的算術基本定理一模一樣。

**同一個多項式，在不同的體上可約性不同**（課本例 2.49）：`x⁵ − 4x³ + 3x² − x + 2` 在 Z[x] 不可約，在 F₃[x] 分解成「1 次 × 4 次」，在 F₅[x] 分解成「2 次 × 3 次」，在 F₁₃[x] 不可約。

**判斷小次數的多項式是否不可約**：2 次或 3 次的多項式可約 ⟺ 它有 1 次因式 ⟺ 它在 F 裡有根。所以只要把 F_p 的每個元素代進去試。

```python
def has_root(f, p):                 # f 用係數串列
    return [x for x in range(p) if sum(c * pow(x, i, p) for i, c in enumerate(f)) % p == 0]

print(has_root([1, 1, 0, 1], 2))           # x³ + x + 1 在 F₂：沒有根 → 不可約
print(has_root([1, 0, 1], 7))              # x² + 1 在 F₇：沒有根 → 不可約
print(has_root([1, 0, 1], 13))             # x² + 1 在 F₁₃：有根 → 可約
```
```output
[]
[]
[5, 8]
```
**課本例 2.59**：`x² + 1` 在 F_p[x] 不可約 ⟺ −1 在 F_p 中不是平方數 ⟺ p ≡ 3 (mod 4)（後一個等價要用第 14 課的二次互反律）。

# 第四部分：有限體 F_{p^k}

## 4.1 商環 F_p[x]/(m)

**命題 2.51**：`F[x]/(m)` 的每個元素都有唯一的代表多項式，次數 < deg m。（就是除以 m 的餘式，像 Z/mZ 用 0～m−1 當代表。）

**推論 2.53**：deg m = d 時，`F_p[x]/(m)` 恰好有 `p^d` 個元素（d 個係數，每個有 p 種選擇）。

**命題 2.54**：a 在 `F[x]/(m)` 中有反元素 ⟺ `gcd(a, m) = 1`。（證明照抄整數版：用擴展歐幾里得。）

**推論 2.55、2.57**：**m 不可約時，`F_p[x]/(m)` 是一個有 p^d 個元素的體。**

**類比**：

| 整數 | 多項式 |
|---|---|
| Z | F_p[x] |
| 質數 p | 不可約多項式 m |
| Z/pZ 是 p 個元素的體 | F_p[x]/(m) 是 p^d 個元素的體 |

課本例 2.56 的直覺：`R[x]/(x² + 1)` 就是 **複數** C——在這個商環裡 `x² = −1`，x 扮演 i 的角色。

## 4.2 例：F₈ = F₂[x]/(x³ + x + 1)

8 個元素：`0, 1, x, x², 1+x, 1+x², x+x², 1+x+x²`。用 3 個位元表示（第 i 位是 xⁱ 的係數）：加法就是 **XOR**；乘法是「多項式相乘，再用 `x³ = x + 1` 化簡」。

```python
M = 0b1011                       # x³ + x + 1

def gf8_mul(a, b):
    r = 0
    while b:
        if b & 1:
            r ^= a               # 係數模 2：加法就是 XOR
        b >>= 1
        a <<= 1
        if a & 0b1000:           # 出現 x³ 就減掉（= XOR）x³ + x + 1
            a ^= M
    return r

names = ["0", "1", "x", "1+x", "x²", "1+x²", "x+x²", "1+x+x²"]
print("     " + " ".join(f"{n:>6}" for n in names[1:]))
for a in range(1, 8):
    print(f"{names[a]:>6} " + " ".join(f"{names[gf8_mul(a, b)]:>6}" for b in range(1, 8)))
```
```output
          1      x    1+x     x²   1+x²   x+x² 1+x+x²
     1      1      x    1+x     x²   1+x²   x+x² 1+x+x²
     x      x     x²   x+x²    1+x      1 1+x+x²   1+x²
   1+x    1+x   x+x²   1+x² 1+x+x²     x²      1      x
    x²     x²    1+x 1+x+x²   x+x²      x   1+x²      1
  1+x²   1+x²      1     x²      x 1+x+x²    1+x   x+x²
  x+x²   x+x² 1+x+x²      1   1+x²    1+x      x     x²
1+x+x² 1+x+x²   1+x²      x      1   x+x²     x²    1+x
```
每一列都是 7 個非零元素的排列，所以每個非零元素都有反元素——它真的是體。

## 4.3 例：F₄₉ = F₇[x]/(x² + 1)

7 ≡ 3 (mod 4)，所以 `x² + 1` 在 F₇ 不可約，商環是 49 個元素的體。元素寫成 `a + bi`（i² = −1），乘法和複數一樣。

**F_{p^k}* 也有生成元**（和第 04 課的原根定理一樣，有限體的乘法群一定是循環群）：

```python
p = 7

def mul(u, v):                         # (a + bi)(c + di)，i² = −1
    a, b = u
    c, d = v
    return ((a * c - b * d) % p, (a * d + b * c) % p)

def order(u):
    k, cur = 1, u
    while cur != (1, 0):
        cur = mul(cur, u)
        k += 1
    return k

elems = [(a, b) for a in range(p) for b in range(p) if (a, b) != (0, 0)]
orders = [order(u) for u in elems]
print(len(elems), max(orders), orders.count(48))
print([u for u in elems if order(u) == 48][:4])
```
```output
48 48 16
[(1, 2), (1, 3), (1, 4), (1, 5)]
```
48 個非零元素中，階為 48 的生成元有 16 個（= φ(48)）。

## 4.4 存在性與唯一性

**定理（有限體的分類）**：
1. 有限體的元素個數一定是質數次方 `p^k`。
2. 對每個質數次方 `p^k`，都 **存在** 這樣的體（因為 F_p[x] 中每個次數都有不可約多項式）。
3. 元素個數相同的有限體都 **同構**（本質上是同一個），記作 `F_{p^k}`。
4. `F_{p^k}*` 是 **循環群**：有生成元，元素個數 `p^k − 1`。

所以「F₈」不管用 `x³ + x + 1` 還是 `x³ + x² + 1` 建構，都是同一個體，只是元素的名字不同。

> 🔍 **AES 的 F₂₅₆**：AES 把每個位元組看成 `F₂[x]/(x⁸ + x⁴ + x³ + x + 1)` 的元素，S-box 的核心就是「在這個體裡取反元素」。例如 `0x53` 的反元素是 `0xCA`：

```python
M = 0x11B                          # x⁸ + x⁴ + x³ + x + 1

def gf256_mul(a, b):
    r = 0
    while b:
        if b & 1:
            r ^= a
        b >>= 1
        a <<= 1
        if a & 0x100:
            a ^= M
    return r

def gf256_inv(a):                  # 乘法群有 255 個元素，a^254 = a⁻¹
    r = 1
    for _ in range(254):
        r = gf256_mul(r, a)
    return r

print(hex(gf256_inv(0x53)), hex(gf256_mul(0x53, 0xCA)))
```
```output
0xca 0x1
```
`a⁻¹ = a^254` 就是 Lagrange 定理（`a^255 = 1`），和 F_p 裡的 `a⁻¹ = a^(p−2)` 同一招。

# 習題解答

**題 1**：

```python
from math import gcd
units = [a for a in range(1, 12) if gcd(a, 12) == 1]
zero_div = [a for a in range(1, 12) if any(a * b % 12 == 0 for b in range(1, 12))]
print(units, zero_div, len(units) + len(zero_div))
```
```output
[1, 5, 7, 11] [2, 3, 4, 6, 8, 9, 10] 11
```
單位和零因子加起來剛好是全部 11 個非零元素——在有限的 Z/mZ 中，每個非零元素不是單位就是零因子。

**題 2**：(a) 代入 0、1 都得 1，沒有根，2 次 → 不可約。(b) 同理沒有根，3 次 → 不可約。(c) 沒有根，但 `x⁴ + x² + 1 = (x² + x + 1)²`（在 F₂ 中 `2x³ = 2x = 0`），所以 **可約**。

```python
def mul(a, b, p):
    r = [0] * (len(a) + len(b) - 1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            r[i + j] = (r[i + j] + x * y) % p
    return r

print(mul([1, 1, 1], [1, 1, 1], 2))
```
```output
[1, 0, 1, 0, 1]
```
**題 3**：`x · (1 + x²) = x + x³ = x + (x + 1) = 1`，所以 `x⁻¹ = 1 + x²`。

```python
M = 0b1011

def gf8_mul(a, b):
    r = 0
    while b:
        if b & 1:
            r ^= a
        b >>= 1
        a <<= 1
        if a & 0b1000:
            a ^= M
    return r

print([b for b in range(1, 8) if gf8_mul(0b010, b) == 1], bin(0b101))
```
```output
[5] 0b101
```
**題 4**：在 F₂ 中 `x² + 1 = (x + 1)²`，可約。所以 `(x + 1) · (x + 1) = x² + 1 ≡ 0`，`x + 1` 是零因子。

**題 5**：9 個元素。3 ≡ 3 (mod 4)，−1 不是模 3 的平方數（0² = 0、1² = 2² = 1），所以 `x² + 1` 不可約，是 9 個元素的體 F₉。
