# 第一部分：向量空間複習

## 1.1 基本定義

| 用語 | 意思 |
|---|---|
| **線性組合** | `a₁v₁ + ⋯ + aₙvₙ`，aᵢ 是實數 |
| **線性獨立** | 只有全部係數為 0 時組合才是 0 |
| **基底** | 線性獨立、而且能組出空間中所有向量的一組向量 |
| **維度** | 基底的向量個數（每組基底都一樣多） |
| **內積** | `v · w = Σ xᵢyᵢ` |
| **長度**（歐幾里得範數） | `‖v‖ = √(v · v)` |
| **正交** | `v · w = 0` |

**Cauchy–Schwarz 不等式**：`|v · w| ≤ ‖v‖ ‖w‖`，等號只在兩向量平行時成立。（因為 `v · w = ‖v‖ ‖w‖ cos θ`。）

## 1.2 Gram–Schmidt 正交化

**定理 6.13**：任何基底 v₁, …, vₙ 都能變成 **正交基底** v₁*, …, vₙ*：

```
v₁* = v₁
vᵢ* = vᵢ − Σ_{j<i} μᵢⱼ vⱼ*，  μᵢⱼ = (vᵢ · vⱼ*) / ‖vⱼ*‖²
```

意思是：從 vᵢ 扣掉它在前面每個 vⱼ* 方向上的「投影」，剩下的部分就和前面都垂直。第 24 課的 LLL 演算法大量使用它。

```python
from fractions import Fraction as F

def gram_schmidt(B):
    Bs, mu = [], []
    for i, v in enumerate(B):
        row = []
        w = [F(x) for x in v]
        for j in range(i):
            m = sum(F(a) * b for a, b in zip(v, Bs[j])) / sum(b * b for b in Bs[j])
            row.append(m)
            w = [a - m * b for a, b in zip(w, Bs[j])]
        Bs.append(w)
        mu.append(row)
    return Bs, mu

B = [(2, 1, 3), (1, 2, 0), (2, -3, -5)]
Bs, mu = gram_schmidt(B)
for v in Bs:
    print([str(x) for x in v])
print(sum(a * b for a, b in zip(Bs[0], Bs[1])), sum(a * b for a, b in zip(Bs[1], Bs[2])))
```
```output
['2', '1', '3']
['3/7', '12/7', '-6/7']
['4', '-2', '-2']
0 0
```

# 第二部分：格

## 2.1 定義

**定義**：v₁, …, vₙ ∈ Rᵐ 線性獨立，它們的 **整數** 線性組合全體

```
L = {a₁v₁ + a₂v₂ + ⋯ + aₙvₙ : aᵢ ∈ Z}
```

叫做由它們生成的 **格**（lattice）。v₁, …, vₙ 是格的一組 **基底**，n 是格的 **維度**。

**和向量空間的差別**：係數只能是整數。所以格是一堆 **離散的點**，像無限延伸的晶格。（等價的定義：Rᵐ 的 **離散加法子群**——每個格點周圍都有一個小球，裡面沒有其他格點。）

所有向量座標都是整數的格叫 **整數格**，例如 Zⁿ 本身。密碼學用的都是整數格。

## 2.2 換基底

同一個格有 **無限多組基底**。

**命題 6.14**：兩組基底之間的轉換矩陣 U 是 **整數矩陣，且行列式 ±1**。（U 的反矩陣也必須是整數矩陣，所以 `det U · det U⁻¹ = 1` 兩個都是整數，只能是 ±1。）這樣的矩陣組成群 `GLₙ(Z)`。

把基底寫成矩陣的列（row），新基底 = U × 舊基底。

```python
def det3(M):
    (a, b, c), (d, e, f), (g, h, i) = M
    return a * (e * i - f * h) - b * (d * i - f * g) + c * (d * h - e * g)

def matmul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]

V = [[2, 1, 3], [1, 2, 0], [2, -3, -5]]            # 課本例 6.15
U = [[4, 1, 3], [-2, 2, 4], [0, -1, 1]]
print(det3(V), det3(U))
W = matmul(U, V)
print(W, det3(W))
```
```output
-36 32
[[15, -3, -3], [6, -10, -26], [1, -5, -5]] -1152
```
`det U = 32`，不是 ±1，所以 W 生成的是 L 的一個 **子格**（行列式變成 32 倍：`|−1152| = 36 × 32`），不是同一個格。

## 2.3 基本區域與行列式

**基本區域**（fundamental domain）：基底向量張成的平行多面體

```
F(v₁, …, vₙ) = {t₁v₁ + ⋯ + tₙvₙ : 0 ≤ tᵢ < 1}
```

把它用格向量平移，剛好不重疊地鋪滿整個空間。它的體積叫做格的 **行列式** `det L`。

**命題 6.20**：n 維格在 Rⁿ 中時，`det L = |det(基底矩陣)|`。**推論 6.22**：不同基底的基本區域體積都一樣（因為差一個行列式 ±1 的矩陣），所以 det L 是格本身的性質。

課本例 6.21：例 6.15 的格 `det L = |−36| = 36`。

## 2.4 Hadamard 不等式：基底有多「正交」

**命題 6.19（Hadamard 不等式）**：`det L ≤ ‖v₁‖ ‖v₂‖ ⋯ ‖vₙ‖`，基底越接近正交，越接近等號。

**Hadamard 比值**：

```
H(v₁, …, vₙ) = ( det L / (‖v₁‖ ⋯ ‖vₙ‖) )^(1/n)，  0 < H ≤ 1
```

H 接近 1 = **好基底**（近乎正交、向量短）；H 接近 0 = **壞基底**（又長又擠在一起）。

# 第三部分：SVP 與 CVP

## 3.1 兩個基本問題

| 問題 | 內容 |
|---|---|
| **最短向量問題（SVP）** | 找格中最短的 **非零** 向量 |
| **最近向量問題（CVP）** | 給一個（不一定在格上的）向量 w，找格中離 w 最近的向量 |

（最短向量不一定唯一：Z² 中 (±1, 0)、(0, ±1) 都是。）

**有多難**：CVP 是 NP-hard；SVP 在某種「隨機歸約」的意義下也是 NP-hard。維度 n 很大（幾百）時，目前最好的演算法時間也隨 n **指數** 成長。實際上常用的是 **近似版本**：apprSVP（找長度不超過最短的 ψ(n) 倍的向量）、apprCVP。

**重要**：對這兩個問題，**目前沒有已知的量子演算法能有效解決**——這是格密碼被視為「後量子密碼」的原因（第 26 課）。

# 第四部分：最短向量有多短

## 4.1 Hermite 定理

**定理 6.25**：每個 n 維格都有非零向量 v 滿足

```
‖v‖ ≤ √n · (det L)^(1/n)
```

（最佳的常數叫 Hermite 常數 γₙ，只在 n ≤ 8 和 n = 24 時知道精確值。）

## 4.2 Minkowski 定理

**定理 6.28**：S 是 **對稱、凸** 的集合，`Vol(S) > 2ⁿ det L`，則 S 一定含有一個非零格點。

**證明的想法**（像鴿籠原理）：把 ½S 用格向量平移，總體積大於基本區域，所以一定有兩個平移後的副本重疊；兩個重疊點相減再利用對稱、凸性，就得到 S 中的非零格點。

把 S 取成邊長 2(det L)^(1/n) 的超立方體，就證出 Hermite 定理。

## 4.3 高斯啟發式

用 **球** 代替立方體可以得到更好的估計。n 維球的體積是 `π^(n/2) Rⁿ / Γ(1 + n/2)`（定理 6.30）。**高斯啟發式**：一個「隨機」的 n 維格，最短向量的長度大約是

```
σ(L) = √(n / (2πe)) · (det L)^(1/n)        （n 大時）
```

**用途**：如果某個密碼系統的秘密向量 **比 σ(L) 短很多**，它很可能就是格中最短的向量，可以期待格約化演算法把它找出來；如果秘密向量和 σ(L) 差不多長，就不容易被區分出來。

```python
import math

def sigma(n, det):
    return math.sqrt(n / (2 * math.pi * math.e)) * det ** (1 / n)

def sigma_exact(n, det):                  # 小 n 時用 Γ 函數的精確公式（課本 (6.22)）
    return (math.gamma(1 + n / 2) * det) ** (1 / n) / math.sqrt(math.pi)

print(round(sigma(6, 1), 4), round(sigma_exact(6, 1), 4))      # 課本 Remark 6.32
print(round(sigma(100, 1), 4), round(sigma_exact(100, 1), 4))

# 背包格（課本例 6.33）：n = 100，det = 2ⁿ·S，S ≈ 2^(2n)
n = 100
log2_det = n + 2 * n
s = math.sqrt((n + 1) / (2 * math.pi * math.e)) * 2 ** (log2_det / (n + 1))
print(round(s, 2), round(math.sqrt(n), 2))
```
```output
0.5927 0.7605
2.4197 2.4903
19.06 10.0
```
最後一行：n = 100 的背包格，高斯預期的最短長度約 19，而目標向量 t 的長度只有 √100 = 10——**明顯比「隨機格的最短向量」還短**，所以 t 幾乎一定就是格中最短的向量，格約化演算法有機會把它找出來（第 24 課）。

# 第五部分：Babai 演算法

## 5.1 正交基底時 CVP 很簡單

如果基底完全正交，把 w 寫成 `t₁v₁ + ⋯ + tₙvₙ`（tᵢ 是實數），再把每個 tᵢ **四捨五入** 成最近的整數，就得到最近的格點。

## 5.2 Babai 最近頂點演算法（定理 6.34）

對一般的基底照做同樣的事：

```
寫成 w = t₁v₁ + ⋯ + tₙvₙ（解線性方程組）
aᵢ = round(tᵢ)
回傳 v = a₁v₁ + ⋯ + aₙvₙ
```

**基底夠正交時**（Hadamard 比值接近 1），v 就是（或很接近）最近的格點；**基底很歪時**，四捨五入的誤差被長向量放大，結果離得很遠。

課本例 6.35：格 L 由 `v₁ = (137, 312)`、`v₂ = (215, −187)` 生成，目標 `w = (53172, 81743)`。

```python
import math

def babai(basis, w):
    (a, b), (c, d) = basis                    # 解 w = t1·v1 + t2·v2
    det = a * d - b * c
    t1 = (w[0] * d - w[1] * c) / det
    t2 = (a * w[1] - b * w[0]) / det
    k1, k2 = round(t1), round(t2)
    v = (k1 * a + k2 * c, k1 * b + k2 * d)
    return (round(t1, 2), round(t2, 2)), v, round(math.dist(v, w), 2)

def hadamard(basis):
    (a, b), (c, d) = basis
    return round(math.sqrt(abs(a * d - b * c) / (math.hypot(a, b) * math.hypot(c, d))), 3)

w = (53172, 81743)
good = [(137, 312), (215, -187)]
bad = [(1975, 438), (7548, 1627)]              # = 5v1 + 6v2、19v1 + 23v2，同一個格
print(hadamard(good), babai(good, w))
print(hadamard(bad), babai(bad, w))
```
```output
0.977 ((296.85, 58.15), (53159, 81818), 76.12)
0.077 ((5722.66, -1490.34), (56405, 82444), 3308.12)
```
同一個格、同一個目標：好基底（H ≈ 0.977）找到距離約 76 的格點；壞基底（H ≈ 0.077）只找到距離約 3308 的格點。

## 5.3 這就是格密碼的陷門

**好基底 = 私鑰，壞基底 = 公鑰。**

- 有好基底的人能解 CVP——把「格點 + 小擾動」還原成格點。
- 只有壞基底的人，Babai 演算法失效，而一般的 CVP 很難。

把好基底變成壞基底很容易（乘一個行列式 ±1 的隨機整數矩陣）；反過來 **從壞基底找回好基底**（格基約化）在高維時很難。第 23 課的 GGH 密碼系統直接用這個想法；NTRU 是它更有效率的版本。

# 習題

### 題 1：基底變換

`v₁ = (3, 1)`、`v₂ = (1, 2)`。`w₁ = 4v₁ + 3v₂`、`w₂ = 5v₁ + 4v₂` 生成的是同一個格嗎？

### 題 2：行列式

算由 `(1, 2, 3)`、`(0, 4, 5)`、`(0, 0, 6)` 生成的格的行列式。

### 題 3：Hadamard 比值

算 `(1, 0)`、`(0, 1)` 和 `(1, 0)`、`(100, 1)` 這兩組基底的 Hadamard 比值。它們生成同一個格嗎？

### 題 4：Babai

用好基底 `(5, 1)`、`(−1, 4)` 對 w = (27, 8) 跑 Babai 演算法。

### 題 5：觀念

為什麼「把好基底乘上一個行列式 ±1 的隨機整數矩陣」得到的公鑰不會洩漏私鑰？

# 習題解答

**題 1**：轉換矩陣 `[[4, 3], [5, 4]]` 的行列式是 16 − 15 = 1，所以是同一個格。

**題 2**：上三角矩陣，行列式是對角線乘積 1 · 4 · 6 = 24。

**題 3**：

```python
import math

def hadamard(B):
    (a, b), (c, d) = B
    return math.sqrt(abs(a * d - b * c) / (math.hypot(a, b) * math.hypot(c, d)))

print(round(hadamard([(1, 0), (0, 1)]), 4), round(hadamard([(1, 0), (100, 1)]), 4))
```
```output
1.0 0.1
```
都是 Z²（`(100, 1) = 100·(1, 0) + (0, 1)`，轉換矩陣行列式 1），但第二組非常歪。

**題 4**：

```python
import math
(a, b), (c, d) = (5, 1), (-1, 4)
w = (27, 8)
det = a * d - b * c
t1 = (w[0] * d - w[1] * c) / det
t2 = (a * w[1] - b * w[0]) / det
k1, k2 = round(t1), round(t2)
v = (k1 * a + k2 * c, k1 * b + k2 * d)
print(round(t1, 3), round(t2, 3), v, round(math.dist(v, w), 3))
```
```output
5.524 0.619 (29, 10) 2.828
```
**題 5**：好基底到公鑰之間的關係只有「乘了一個行列式 ±1 的整數矩陣 U」，而同一個格有無限多組基底；從公鑰 W 要找回好基底 V，就要找到 U⁻¹——這等於要解高維的格基約化問題（找一組短而近乎正交的基底），在高維時沒有已知的有效演算法。
