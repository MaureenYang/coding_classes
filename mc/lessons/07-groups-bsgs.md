# 第一部分：群

## 1.1 定義

**群**（group）：一個集合 G 加上一個運算 ⋆，把兩個元素合成一個元素，而且滿足：

| 公理 | 內容 |
|---|---|
| **單位元素** | 存在 e，使得 `e ⋆ a = a ⋆ e = a` |
| **反元素** | 每個 a 都有 `a⁻¹`，使得 `a ⋆ a⁻¹ = a⁻¹ ⋆ a = e` |
| **結合律** | `a ⋆ (b ⋆ c) = (a ⋆ b) ⋆ c` |

如果還滿足 `a ⋆ b = b ⋆ a`，叫 **交換群**（commutative / abelian group）。

| 例子 | 運算 | 單位元素 | 反元素 | 交換？ | 元素個數 |
|---|---|---|---|---|---|
| F_p* | 乘法 mod p | 1 | `a⁻¹ mod p` | 是 | p − 1 |
| Z/NZ | 加法 mod N | 0 | `−a` | 是 | N |
| Z | 加法 | 0 | `−a` | 是 | 無限 |
| 2×2 可逆矩陣（實數） | 矩陣乘法 | I | 反矩陣 | **否** | 無限 |
| 橢圓曲線上的點（第 18 課） | 點的加法 | 無窮遠點 O | 對 x 軸鏡射 | 是 | 有限 |

**群的階**：G 的元素個數，記作 |G| 或 #G。

**記號**：群運算寫成乘法時，`g^x` 表示 g 自己運算 x 次；寫成加法時寫 `x·g`。兩種寫法本質一樣，DLP 在加法寫法裡長得像「x·g = h」。

## 1.2 元素的階

**定義**：最小的正整數 d 使 `a^d = e`，叫做 a 的 **階**。沒有這樣的 d 就說階無限。

**命題 2.13**：有限群裡每個元素的階都有限；而且 `a^k = e` ⇒ 階 d 整除 k。

**證明**：序列 `a, a², a³, …` 只有有限個可能的值，總會重複：`a^i = a^j`（i < j），兩邊乘 `a^(−i)` 得 `a^(j−i) = e`。整除的部分和第 04 課命題 1.30 一模一樣（用帶餘除法）。

## 1.3 Lagrange 定理

**命題 2.14（Lagrange）**：有限群 G 的元素 a 的階整除 |G|。特別地，`a^|G| = e`。

**交換群的證明**（和費馬小定理同一招）：設 `G = {g₁, …, gₙ}`。`a ⋆ g₁, …, a ⋆ gₙ` 兩兩不同，所以只是 G 的重新排列；全部乘起來 `aⁿ · (g₁⋯gₙ) = g₁⋯gₙ`，消去得 `aⁿ = e`，再由命題 2.13 得到階整除 n。

**費馬小定理就是 Lagrange 定理在 G = F_p* 的特例**（|G| = p − 1）。

```python
from math import gcd

def order(a, n):                 # 在 (Z/nZ)* 中的階
    k, x = 1, a % n
    while x != 1:
        x = x * a % n
        k += 1
    return k

n = 21
G = [a for a in range(1, n) if gcd(a, n) == 1]
print(len(G), sorted({order(a, n) for a in G}))
print(all(pow(a, len(G), n) == 1 for a in G))
```
```output
12 [1, 2, 3, 6]
True
```
(Z/21Z)* 有 12 個元素，所有元素的階（1, 2, 3, 6）都整除 12——但 **沒有** 階為 12 的元素，所以 (Z/21Z)* 沒有生成元。Lagrange 只保證「階整除 |G|」，不保證每個因數都出現。

# 第二部分：怎麼衡量「難」

## 2.1 大 O 記號

**定義**：f、g 是正值函數。如果存在常數 c、C 使得 `f(x) ≤ c·g(x)` 對所有 `x ≥ C` 成立，就寫 `f(x) = O(g(x))`。

**實用判斷（命題 2.15）**：如果 `lim f(x)/g(x)` 存在（有限），則 `f = O(g)`。

例：`2x³ − 3x² + 7 = O(x³)`（極限是 2）；`x² = O(2^x)`（極限是 0）；`k³⁰⁰ = O(2^k)`；`(ln k)³⁷⁵ = O(k^0.001)`。**任何多項式最後都輸給指數，任何 log 的次方最後都輸給多項式。**

## 2.2 用「輸入的位元數」衡量

輸入是一個數 N 時，輸入的大小是它的 **位元數** `k ≈ log₂ N`，不是 N 本身。

| 類別 | 步數（k 是位元數） | 例子 |
|---|---|---|
| **多項式時間** | `O(k^A)` | 快速冪 O(k) 次乘法、歐幾里得演算法 |
| **次指數時間** | 對每個 ε > 0 都是 `O(e^(εk))` | 指標演算法解 DLP、二次篩法分解（第 13 課） |
| **指數時間** | `O(e^(ck))` | 暴力解 DLP：O(p) = O(2^k) |

密碼學的經驗法則：**多項式時間 = 容易，指數時間 = 困難**，次指數介於中間。但這是漸近的說法——常數很大時，指數演算法在實際尺寸下可能反而比較快。

```python
import math
for k in (64, 128, 256, 1024, 2048):
    ln_n = k * math.log(2)                                   # N ≈ 2^k，ln N
    poly = 3 * math.log2(k)                                   # k³ 的 log₂
    sub = math.sqrt(ln_n * math.log(ln_n)) / math.log(2)      # e^(√(ln N · ln ln N)) 的 log₂
    expo = k / 2                                              # 2^(k/2) 的 log₂
    print(f"{k:5}  k³≈2^{poly:.0f}   次指數≈2^{sub:.0f}   √N=2^{expo:.0f}")
```
```output
   64  k³≈2^18   次指數≈2^19   √N=2^32
  128  k³≈2^21   次指數≈2^29   √N=2^64
  256  k³≈2^24   次指數≈2^44   √N=2^128
 1024  k³≈2^30   次指數≈2^98   √N=2^512
 2048  k³≈2^33   次指數≈2^146   √N=2^1024
```
（「次指數」一欄用的是 `e^(√(ln N · ln ln N))` 這種形式、沒算常數，只是示意量級。）這張表說明為什麼 **金鑰長度** 和演算法的種類息息相關：F_p* 有次指數的 DLP 演算法，所以要 2048 位元的 p 才夠安全；而橢圓曲線目前只有 O(√N) 的通用演算法，256 位元就有 128 位元的安全度（第 19 課）。

## 2.3 不同群裡的 DLP，難度天差地遠

| 群 | DLP 的最佳已知演算法 |
|---|---|
| (Z/pZ, +) | 一個模反元素，**多項式時間**（第 06 課 2.4 節） |
| F_p*，p − 1 只有小質因數 | Pohlig–Hellman，很快（第 08 課） |
| F_p*，一般的 p | 指標演算法，**次指數**（第 13 課） |
| 一般群 | 嬰兒步巨人步、Pollard ρ，O(√N)，**指數**（本課、第 16 課） |

# 第三部分：暴力法與碰撞演算法的想法

## 3.1 暴力法

**命題 2.20**：g 的階是 N 時，`g^x = h` 可以在 O(N) 步解出：依序算 `g⁰, g¹, g², …, g^(N−1)`，每一步乘一個 g，遇到 h 就停。

## 3.2 碰撞演算法

**想法**：做 **兩張表**，各約 √N 個元素，保證兩張表有一個 **共同元素**（碰撞），從碰撞推出答案。

類比生日問題：班上只要 23 人，就有超過一半的機率兩人同一天生日——因為要比的是「兩兩之間」，配對數隨人數平方成長（第 16 課會詳細算）。碰撞演算法利用的正是這種「平方根效應」。

# 第四部分：Shanks 嬰兒步巨人步

## 4.1 演算法（命題 2.22）

g 的階是 N ≥ 2，要解 `g^x = h`：

1. 令 `n = 1 + ⌊√N⌋`，所以 `n > √N`、`n² > N`。
2. **嬰兒步**：列出 `e, g, g², …, g^n`。
3. **巨人步**：令 `u = g^(−n)`，列出 `h, h·u, h·u², …, h·u^n`。
4. 找到碰撞 `g^i = h · g^(−jn)`，答案就是 `x = i + jn`。

**為什麼一定有碰撞**：把未知的 x（0 ≤ x < N < n²）寫成 `x = nq + r`，`0 ≤ r < n`。因為 `x < n²`，所以 `q < n`。那麼

```
g^x = h  ⟺  g^r = h · g^(−qn)
```

左邊在嬰兒步表裡（i = r），右邊在巨人步表裡（j = q）。

**花費**：建兩張表各約 √N 次群運算；用雜湊表（Python 的 dict）找碰撞是 O(1)。總共 **O(√N)** 步（課本用排序找碰撞，所以多一個 log N 因子），但要 **O(√N) 的記憶體**。

## 4.2 課本例 2.23

在 F₁₇₃₈₉* 中解 `9704^x = 13896`。9704 的階是 1242，`n = ⌊√1242⌋ + 1 = 36`，`u = 9704^(−36) = 2494`。

```python
def bsgs(g, h, p, N):
    n = 1 + int(N ** 0.5)
    baby = {}
    cur = 1
    for i in range(n + 1):
        baby.setdefault(cur, i)          # g^i -> i
        cur = cur * g % p
    u = pow(g, -n, p)                    # g^(-n)
    cur = h % p
    for j in range(n + 1):
        if cur in baby:
            return baby[cur] + j * n, baby[cur], j
        cur = cur * u % p
    return None

p, g, h, N = 17389, 9704, 13896, 1242
print(pow(g, -36, p))
x, i, j = bsgs(g, h, p, N)
print(x, i, j, pow(g, x, p))
```
```output
2494
1159 7 32 13896
```
碰撞在 `i = 7`、`j = 32`：`9704⁷ = 13896 · 2494³²`，所以 `x = 7 + 32 · 36 = 1159`，和課本一致。

## 4.3 和暴力法比一比

```python
def brute(g, h, p):
    cur, x = 1, 0
    while cur != h:
        cur = cur * g % p
        x += 1
    return x

def bsgs(g, h, p, N):
    n = 1 + int(N ** 0.5)
    baby, cur = {}, 1
    for i in range(n + 1):
        baby.setdefault(cur, i)
        cur = cur * g % p
    u, cur = pow(g, -n, p), h
    for j in range(n + 1):
        if cur in baby:
            return baby[cur] + j * n
        cur = cur * u % p

p, g = 1000000007, 5                # 5 是原根，N = p − 1
x_true = 876543210
h = pow(g, x_true, p)
x1 = bsgs(g, h, p, p - 1)
print(x1 == x_true, f"bsgs 只做了約 {2 * int((p - 1) ** 0.5):,} 次乘法")
print(f"暴力法要做 {x_true:,} 次乘法")
```
```output
True bsgs 只做了約 63,244 次乘法
暴力法要做 876,543,210 次乘法
```
N ≈ 10⁹ 時，嬰兒步巨人步約 6 萬次乘法，暴力法要 8 億多次。但 N ≈ 2²⁵⁶ 時，√N = 2¹²⁸ 還是遙不可及——這就是為什麼群的階要夠大。

> 🔍 **時間換空間**：嬰兒步巨人步要存 √N 個元素。第 16 課的 **Pollard ρ** 演算法同樣是 O(√N) 時間，卻只要 O(1) 的記憶體，實務上更常用。

# 習題

### 題 1：群的判斷

下列哪些是群？說明理由。(a) 整數在乘法下；(b) `{1, −1}` 在乘法下；(c) Z/6Z 去掉 0，在乘法 mod 6 下；(d) F₇*。

### 題 2：大 O

判斷真假：(a) `n² + n = O(n²)`；(b) `2^(2n) = O(2^n)`；(c) `n log n = O(n^1.01)`。

### 題 3：嬰兒步巨人步手算

在 F₁₀₁* 中，2 是原根（階 100）。用嬰兒步巨人步解 `2^x = 22`：n 是多少？列出兩張表，找出碰撞。

### 題 4：觀念

為什麼 n 要取 `1 + ⌊√N⌋` 而不是 `⌊√N⌋`？如果取太小會發生什麼事？

### 題 5：Lagrange

證明：在任何有限群中，`a^|G| = e`。（交換群的情況即可。）

# 習題解答

**題 1**：(a) 不是：2 沒有乘法反元素（1/2 不是整數）。(b) 是：單位元素 1，每個元素是自己的反元素。(c) 不是：`2 · 3 = 0` 不在集合裡（運算不封閉），而且 2 沒有反元素。(d) 是：模質數的非零元素，每個都有反元素。

**題 2**：(a) 真（極限 1）。(b) 假：`2^(2n) / 2^n = 2^n → ∞`。(c) 真：`log n / n^0.01 → 0`。

**題 3**：N = 100，n = 11。

```python
p, g, h, N = 101, 2, 22, 100
n = 1 + int(N ** 0.5)
baby = {pow(g, i, p): i for i in range(n + 1)}
u = pow(g, -n, p)
print("n =", n, " u =", u)
print("嬰兒步", [pow(g, i, p) for i in range(n + 1)])
giant = [h * pow(u, j, p) % p for j in range(n + 1)]
print("巨人步", giant)
j = next(j for j, v in enumerate(giant) if v in baby)
i = baby[giant[j]]
print("碰撞 i =", i, " j =", j, " x =", i + j * n, pow(g, i + j * n, p))
```
```output
n = 11  u = 83
嬰兒步 [1, 2, 4, 8, 16, 32, 64, 27, 54, 7, 14, 28]
巨人步 [22, 8, 58, 67, 6, 94, 25, 55, 20, 44, 16, 15]
碰撞 i = 3  j = 1  x = 14 22
```
**題 4**：證明需要把任何 `0 ≤ x ≤ N − 1` 寫成 `x = nq + r`，其中 `0 ≤ r < n`、`0 ≤ q ≤ n`（兩張表都只列到第 n 項）。取 `n = 1 + ⌊√N⌋` 保證 `n² > N`，所以 `q = ⌊x/n⌋ < n`。如果只取 `n = ⌊√N⌋`，可能漏掉答案：例如 N = 15、n = 3，x = 14 需要 `q = 4 > 3`，巨人步表到 `j = 3` 就結束，找不到碰撞。

**題 5**：設 `G = {g₁, …, gₙ}`，映射 `x ↦ a ⋆ x` 是一對一的（兩邊左乘 a⁻¹ 就還原），所以 `{a⋆g₁, …, a⋆gₙ} = G`。交換群中把兩組全部乘起來：`aⁿ ⋆ (g₁⋆⋯⋆gₙ) = g₁⋆⋯⋆gₙ`，右乘 `(g₁⋆⋯⋆gₙ)⁻¹` 得 `aⁿ = e`。
