# 第一部分：整除與帶餘除法

## 1.1 整除

**定義**：整數 `a`、`b`，`b ≠ 0`。如果存在整數 `c` 使得 `a = b·c`，就說 **`b` 整除 `a`**，記作 `b | a`；否則記作 `b ∤ a`。

例：`847 | 485331`，因為 `485331 = 847 × 573`；`355 ∤ 259943`，因為除下去餘 83。

```python
print(485331 % 847, 485331 // 847)
print(259943 % 355, 259943 // 355)
```
```output
0 573
83 732
```
**整除的性質**（課本命題 1.4），全部都能直接用定義證明：

| 性質 | 為什麼 |
|---|---|
| `a | b` 且 `b | c` ⇒ `a | c` | `b = ax`、`c = by` ⇒ `c = a(xy)` |
| `a | b` 且 `b | a` ⇒ `a = ±b` | `b = ax`、`a = by` ⇒ `a = axy` ⇒ `xy = 1` |
| `a | b` 且 `a | c` ⇒ `a | (b + c)`、`a | (b − c)` | `b ± c = a(x ± y)` |

最後一條最常用，可以推廣成：**`a` 整除 `b` 和 `c`，就整除任何 `bu + cv`**。

## 1.2 帶餘除法

**定理（帶餘除法）**：`a`、`b` 是正整數，一定存在唯一的 **商** `q` 和 **餘數** `r`，使得

```
a = b·q + r，且 0 ≤ r < b
```

Python 的 `a // b` 和 `a % b` 就是 `q` 和 `r`（`divmod(a, b)` 一次給兩個）。

> ⚠️ **負數的餘數**：數學上要求 `0 ≤ r < b`。Python 的 `%` 符合這個定義（`-7 % 3 == 2`），但 **C 語言的 `%` 不符合**（`-7 % 3 == -1`）。寫 C 時要自己修正：`((a % m) + m) % m`。程式練習會用到。

```python
print(divmod(2387187, 27573))
print(-7 % 3, -7 // 3)
```
```output
(86, 15909)
2 -3
```
## 1.3 最大公因數

**定義**：`a`、`b` 的 **公因數** 是同時整除兩者的正整數；最大的那個叫 **最大公因數**，記作 `gcd(a, b)`。

例：`gcd(12, 18) = 6`、`gcd(748, 2024) = 44`。

把兩個數因數分解再取共同部分（`748 = 2² · 11 · 17`、`2024 = 2³ · 11 · 23` ⇒ gcd = `2² · 11 = 44`）在數字小時可以，但 **因數分解非常困難**（RSA 的安全性就靠這件事，第 10 課）。我們需要一個 **不用分解** 就能算 gcd 的方法。

# 第二部分：歐幾里得演算法

## 2.1 核心觀察

如果 `a = b·q + r`，那麼

```
gcd(a, b) = gcd(b, r)
```

**為什麼**：任何同時整除 `a`、`b` 的數，也整除 `r = a − bq`；反過來，任何同時整除 `b`、`r` 的數，也整除 `a = bq + r`。兩組公因數 **完全相同**，最大的當然也一樣。

所以不斷把 `(a, b)` 換成 `(b, a mod b)`，數字越來越小，餘數變成 0 時，**最後一個非零餘數就是 gcd**。

## 2.2 課本例 1.6：gcd(2024, 748)

```
2024 = 748 · 2 + 528
 748 = 528 · 1 + 220
 528 = 220 · 2 +  88
 220 =  88 · 2 +  44   ← gcd = 44
  88 =  44 · 2 +   0
```

```python
def gcd_steps(a, b):
    while b:
        q, r = divmod(a, b)
        print(f"{a:>5} = {b:>4} · {q} + {r}")
        a, b = b, r
    return a

print("gcd =", gcd_steps(2024, 748))
```
```output
 2024 =  748 · 2 + 528
  748 =  528 · 1 + 220
  528 =  220 · 2 + 88
  220 =   88 · 2 + 44
   88 =   44 · 2 + 0
gcd = 44
```
## 2.3 為什麼很快

**課本定理 1.7**：除法步驟最多執行 **2 log₂ b + 1** 次。

**證明的關鍵**：每做 **兩步**，餘數至少減半，也就是 `r_{i+2} < r_i / 2`。分兩種情況：

| 情況 | 推理 |
|---|---|
| `r_{i+1} ≤ r_i / 2` | 餘數遞減，所以 `r_{i+2} < r_{i+1} ≤ r_i / 2` |
| `r_{i+1} > r_i / 2` | 這時 `r_i ÷ r_{i+1}` 的商只能是 1，餘數 `r_{i+2} = r_i − r_{i+1} < r_i / 2` |

每兩步減半，`b` 最多減半 log₂ b 次就到 0，所以總步數約 2 log₂ b。實際上更好：最壞約 1.45 log₂ b，**平均約 0.85 log₂ b**。

**這有多重要？** 密碼學用的數有幾百位數。如果演算法的步數和 `b` 本身成正比，算到宇宙毀滅也算不完；和 **位數**（log b）成正比，就是一瞬間的事。

```python
import math, random

def steps(a, b):
    n = 0
    while b:
        a, b = b, a % b
        n += 1
    return n

random.seed(1)
a, b = random.getrandbits(1024), random.getrandbits(1024)
print(steps(a, b), round(2 * math.log2(b) + 1))

# 最壞的情況：相鄰的費氏數，每一步的商都是 1
F = [1, 1]
while len(F) < 60:
    F.append(F[-1] + F[-2])
print(steps(F[59], F[58]), round(1.45 * math.log2(F[58]) + 1.68))
```
```output
634 2048
58 59
```
兩個 1024 位元的隨機數，只要大約 600 步；理論上限約 2049 步。**相鄰的費氏數** 是最壞情況（每一步的商都是 1，餘數下降得最慢），步數也只有大約 1.44 log₂ b。

# 第三部分：擴展歐幾里得演算法

## 3.1 把 gcd 寫成 a 和 b 的組合

**課本例 1.10**：把 gcd(2024, 748) = 44 的計算 **倒推回去**（令 `a = 2024`、`b = 748`）：

```
528 = a − 2b
220 = b − 528        = b − (a − 2b)        = −a + 3b
 88 = 528 − 2·220     = (a − 2b) − 2(−a + 3b) = 3a − 8b
 44 = 220 − 2·88      = (−a + 3b) − 2(3a − 8b) = −7a + 19b
```

所以 `−7 · 2024 + 19 · 748 = 44`。

**定理 1.11（擴展歐幾里得）**：對任何正整數 `a`、`b`，方程式

```
a·u + b·v = gcd(a, b)
```

**一定有整數解**。如果 `(u₀, v₀)` 是一組解，所有解都是

```
u = u₀ + k · b / g，  v = v₀ − k · a / g，  k 是任意整數，g = gcd(a, b)
```

**為什麼所有解長這樣？** 代進去：`a(u₀ + kb/g) + b(v₀ − ka/g) = au₀ + bv₀ + k(ab/g − ab/g) = g`，所以這些都是解；反過來，任兩組解的差 `(Δu, Δv)` 滿足 `aΔu = −bΔv`，同除以 g 後 `a/g` 和 `b/g` 互質，所以 `b/g` 必須整除 `Δu`（課本習題 1.11）。

```python
a, b = 2024, 748
print(a * -7 + b * 19)
for k in range(-2, 3):                  # 列出幾組其他的解
    u, v = -7 + k * (b // 44), 19 - k * (a // 44)
    print(k, u, v, a * u + b * v)
```
```output
44
-2 -41 111 44
-1 -24 65 44
0 -7 19 44
1 10 -27 44
2 27 -73 44
```
## 3.2 互質

**定義**：`gcd(a, b) = 1` 時，稱 `a`、`b` **互質**（relatively prime）。

把 `−7 · 2024 + 19 · 748 = 44` 兩邊同除以 44，得到 `−7 · 46 + 19 · 17 = 1`，所以 46 和 17 互質。一般來說，`a/g` 和 `b/g` 一定互質。

**互質時，擴展歐幾里得給出 `au + bv = 1`**，這個式子是下一課「模反元素」的核心：兩邊 mod b，得到 `a·u ≡ 1 (mod b)`，也就是 `u` 是 `a` 在模 `b` 下的反元素。

## 3.3 一個重要推論：質數整除乘積

**命題 1.20**：`p` 是質數，`p | ab`，則 `p | a` 或 `p | b`。

**證明**（只用擴展歐幾里得）：如果 `p ∤ a`，因為 `p` 是質數，`gcd(a, p) = 1`，所以有 `au + pv = 1`。兩邊乘 `b`：`abu + pbv = b`。左邊兩項都被 `p` 整除，所以 `p | b`。

這個命題是 **算術基本定理**（質因數分解唯一）的關鍵，第 04 課會用到。注意它對合數不成立：`6 | 3 · 10`，但 6 不整除 3 也不整除 10。

# 第四部分：有效率的寫法

## 4.1 迭代版擴展歐幾里得（課本習題 1.12 的方法）

倒推法需要把每一步記下來。電腦上常用的做法是 **一邊做除法一邊維護兩組係數**：始終保持

```
r_old = a·s_old + b·t_old
r     = a·s     + b·t
```

每次 `q = r_old // r`，三組數一起做 `(old, new) ← (new, old − q·new)`。餘數變成 0 時，`r_old` 就是 gcd，`(s_old, t_old)` 就是係數。

```python
def ext_gcd(a, b):
    r_old, r = a, b
    s_old, s = 1, 0
    t_old, t = 0, 1
    while r:
        q = r_old // r
        r_old, r = r, r_old - q * r
        s_old, s = s, s_old - q * s
        t_old, t = t, t_old - q * t
    return r_old, s_old, t_old          # g, u, v 滿足 a·u + b·v = g

for a, b in [(2024, 748), (73, 25), (527, 1258), (17449, 7814)]:
    g, u, v = ext_gcd(a, b)
    print(a, b, "->", g, u, v, a * u + b * v == g)
```
```output
2024 748 -> 44 -7 19 True
73 25 -> 1 12 -35 True
527 1258 -> 17 -31 13 True
17449 7814 -> 1 -575 1284 True
```
注意 `(2024, 748)` 得到的正好是課本的 `u = −7, v = 19`；最後一行 `7814 · 1284 − 17449 · 575 = 1` 是課本例 1.28，下一課會用它求模反元素。

**遞迴寫法** 更短，也常見：`gcd(a, b) = gcd(b, a mod b)`，如果 `b·u' + (a mod b)·v' = g`，因為 `a mod b = a − (a//b)·b`，整理後 `u = v'`、`v = u' − (a//b)·v'`。

```python
def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, u1, v1 = ext_gcd(b, a % b)
    return g, v1, u1 - (a // b) * v1

print(ext_gcd(73, 25))
```
```output
(1, 12, -35)
```
## 4.2 課本的方格法（Figure 1.3）

`a`、`b` 互質時，課本給了一個手算很方便的方法。以 `a = 73, b = 25` 為例，先做歐幾里得演算法得到商 `2, 1, 11, 2`，然後填表：

```
        2    1   11    2      ← 商
 0  1   2    3   35   73      新格 = 上方的商 × 左邊一格 + 左邊兩格
 1  0   1    1   12   25
```

最後一欄是 `a, b` 本身；**倒數第二欄** 給出 `73 · 12 − 25 · 35 = 1`。一般來說最後四格滿足 `a·Q_{t−1} − b·P_{t−1} = (−1)ᵗ`（t 是商的個數）。

```python
def box(a, b):
    qs = []
    x, y = a, b
    while y:
        qs.append(x // y)
        x, y = y, x % y
    P, Q = [0, 1], [1, 0]
    for q in qs:
        P.append(q * P[-1] + P[-2])
        Q.append(q * Q[-1] + Q[-2])
    return qs, P, Q

qs, P, Q = box(73, 25)
print(qs)
print(P)
print(Q)
t = len(qs)
print(73 * Q[-2] - 25 * P[-2], (-1) ** t)
```
```output
[2, 1, 11, 2]
[0, 1, 2, 3, 35, 73]
[1, 0, 1, 1, 12, 25]
1 1
```
> 🔍 方格法裡的 `P_i / Q_i` 其實是 `a/b` 的 **連分數** 漸近分數：`73/25 = 2 + 1/(1 + 1/(11 + 1/2))`。連分數在密碼分析裡也有用處，例如 RSA 的 Wiener 攻擊（解密指數太小時，用 `e/N` 的連分數就能找到它）。

# 習題解答

**題 1**：

```python
a, b = 291, 252
while b:
    q, r = divmod(a, b)
    print(f"{a} = {b} · {q} + {r}")
    a, b = b, r
print("gcd =", a)
```
```output
291 = 252 · 1 + 39
252 = 39 · 6 + 18
39 = 18 · 2 + 3
18 = 3 · 6 + 0

```
**題 2**：

```python
def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, u1, v1 = ext_gcd(b, a % b)
    return g, v1, u1 - (a // b) * v1

g, u, v = ext_gcd(291, 252)
print(g, u, v, 291 * u + 252 * v)
step = 252 // g                       # u 每次可以加減 b/g
u2 = u % step
v2 = (g - 291 * u2) // 252
print(u2, v2, 291 * u2 + 252 * v2)
```
```output
3 13 -15 3
13 -15 3
```

`gcd = 3`，`291 · 13 + 252 · (−15) = 3`。u 每次可以加減 `252 / 3 = 84`，所以 13 本身就是最小的正數解。
**題 3**：`b = ak`、`c = al`，所以 `bx + cy = a(kx + ly)`，`kx + ly` 是整數，因此 `a | (bx + cy)`。

**題 4**：

```python
def f(a, b):
    while b:
        a, b = b, a % b
    return a
print(f(0, 7), f(7, 0), f(-12, 18), f(12, -18))
```
```output
7 7 6 -6
```
`gcd(0, 7) = 7`、`gcd(7, 0) = 7` 都正確；但遇到負數時，Python 的 `%` 會讓結果可能是負的（`f(12, -18)` 給出負數）。數學上 gcd 定義為正數，所以處理負數時要先取絕對值。Python 內建的 `math.gcd` 已經處理好了。

**題 5**：步數上限是 **2 log₂ b + 1**，和 `b` 的 **位數** 成正比，不是和 `b` 本身成正比。300 位數的 b 大約 1000 位元，最多約 2000 步。

**題 6**：

```python
import math

def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, u1, v1 = ext_gcd(b, a % b)
    return g, v1, u1 - (a // b) * v1

def solve(a, b, c):
    g, u, v = ext_gcd(a, b)
    if c % g:
        return None
    k = c // g
    return u * k, v * k

print(solve(2024, 748, 88))
print(solve(2024, 748, 50))
x, y = solve(2024, 748, 132)
print(2024 * x + 748 * y)
```
```output
(-14, 38)
None
132
```
