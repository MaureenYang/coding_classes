# 第一部分：二次剩餘

## 1.1 定義

p 是奇質數，p ∤ a。如果存在 c 使 `c² ≡ a (mod p)`，就說 a 是模 p 的 **二次剩餘**（quadratic residue, QR）；否則是 **二次非剩餘**（nonresidue, NR）。

例：模 1223，`453² ≡ 968`、`375² ≡ 1203`，所以 968、1203 是二次剩餘。Alice 問 Bob「181 是不是模 1223 的平方數？」——Bob 開始列平方表，算到 96² 就放棄；Alice 繼續算到 `437² ≡ 181`。有沒有更快的方法？

## 1.2 剛好一半是平方數

`c` 和 `−c` 的平方相同，所以 `1², 2², …, ((p−1)/2)²` 已經列出所有的二次剩餘，而且它們兩兩不同。**模 p 恰好有 (p − 1)/2 個二次剩餘、(p − 1)/2 個非剩餘。**

用原根 g 看更清楚：**a 是二次剩餘 ⟺ a = g^k 而 k 是偶數**。

```python
p = 11
qr = sorted({c * c % p for c in range(1, p)})
print(qr, [a for a in range(1, p) if a not in qr])
g = 2                                   # 2 是模 11 的原根
print([pow(g, k, p) for k in range(0, p - 1, 2)])
```
```output
[1, 3, 4, 5, 9] [2, 6, 7, 8, 10]
[1, 4, 5, 9, 3]
```
## 1.3 乘法規則（命題 3.60）

| | QR | NR |
|---|---|---|
| **QR** | QR | NR |
| **NR** | NR | **QR** |

**證明**：寫成原根的次方，「偶 + 偶 = 偶、偶 + 奇 = 奇、奇 + 奇 = 偶」。最後一格最反直覺：**兩個非平方數相乘是平方數**。

## 1.4 歐拉判別法

```
a^((p−1)/2) ≡ 1    如果 a 是 QR
a^((p−1)/2) ≡ −1   如果 a 是 NR
```

**證明**：`a = g^k`，`a^((p−1)/2) = g^(k(p−1)/2)`。k 偶數時是 `(g^(p−1))^(k/2) = 1`；k 奇數時等於 `g^((p−1)/2)` 的奇數次方，而 `g^((p−1)/2)` 平方是 1 又不是 1（g 是原根），所以是 −1。

這給了一個 **快速判斷** 的方法：一次快速冪。

```python
p = 1223
for a in (181, 968, 1203, 2, 5):
    r = pow(a, (p - 1) // 2, p)
    print(a, "QR" if r == 1 else "NR", r)
```
```output
181 QR 1
968 QR 1
1203 QR 1
2 QR 1
5 NR 1222
```

# 第二部分：Legendre 符號與二次互反律

## 2.1 Legendre 符號

```
(a/p) = 1    a 是二次剩餘
(a/p) = −1   a 是二次非剩餘
(a/p) = 0    p | a
```

由歐拉判別法，`(a/p) ≡ a^((p−1)/2) (mod p)`。乘法規則寫成 `(ab/p) = (a/p)(b/p)`。

## 2.2 二次互反律（定理 3.61）

p、q 是奇質數：

```
(a) (−1/p) = 1 ⟺ p ≡ 1 (mod 4)
(b) (2/p)  = 1 ⟺ p ≡ 1 或 7 (mod 8)
(c) (p/q) = (q/p)，除非 p ≡ q ≡ 3 (mod 4)，那時 (p/q) = −(q/p)
```

(c) 是高斯稱為「黃金定理」的結果——**模 q 時 p 是不是平方數，和模 p 時 q 是不是平方數** 竟然有關！這讓我們能像歐幾里得演算法一樣，不斷「翻轉 + 取餘數」把數字變小。

```python
def legendre(a, p):
    r = pow(a, (p - 1) // 2, p)
    return -1 if r == p - 1 else r

# 驗證 (−1/p) 和 (2/p) 的規則
for p in (5, 7, 11, 13, 17, 19, 23):
    print(p, p % 4, legendre(-1, p), p % 8, legendre(2, p))

# 驗證 (c)
for p, q in ((5, 11), (7, 11), (3, 7), (13, 17)):
    print(p, q, legendre(p, q), legendre(q, p))
```
```output
5 1 1 5 -1
7 3 -1 7 1
11 3 -1 3 -1
13 1 1 5 -1
17 1 1 1 1
19 3 -1 3 -1
23 3 -1 7 1
5 11 1 1
7 11 -1 1
3 7 -1 1
13 17 1 1
```
## 2.3 手算例：課本例 3.62

`−15750` 是不是模 37907 的二次剩餘？（`15750 = 2 · 3² · 5³ · 7`）

```
(−15750 / 37907) = (−1/37907)(2/37907)(3/37907)²(5/37907)³(7/37907)
```

平方項是 1，剩下各自用互反律翻轉、取餘數。程式驗證：

```python
def legendre(a, p):
    r = pow(a % p, (p - 1) // 2, p)
    return -1 if r == p - 1 else r

p = 37907
parts = {"-1": legendre(-1, p), "2": legendre(2, p), "3": legendre(3, p),
         "5": legendre(5, p), "7": legendre(7, p)}
print(parts)
total = parts["-1"] * parts["2"] * parts["3"] ** 2 * parts["5"] ** 3 * parts["7"]
print(total, legendre(-15750, p))
```
```output
{'-1': -1, '2': -1, '3': 1, '5': -1, '7': -1}
1 1
```
用歐拉判別法一次快速冪就能算，為什麼還需要互反律？兩個原因：(1) 它是 **理論工具**（例如第 09 課 `x² + 1` 何時不可約），(2) 下一部分的 Jacobi 符號在 **模數是合數** 時仍然能用互反律計算，歐拉判別法卻不行。

# 第三部分：Jacobi 符號

## 3.1 定義

b 是正奇數，`b = p₁^(e₁) ⋯ p_t^(e_t)`，定義

```
(a/b) = (a/p₁)^(e₁) ⋯ (a/p_t)^(e_t)
```

b 是質數時就是 Legendre 符號。

## 3.2 不用分解就能算（定理 3.65）

神奇的是：**二次互反律對 Jacobi 符號照樣成立**（把「奇質數」換成「正奇數」）。所以可以用類似歐幾里得演算法的方式算 `(a/b)`，**完全不需要分解 b**：

1. 用 `a mod b` 取代 a。
2. 把 a 的因數 2 提出來，用 `(2/b)` 的規則處理。
3. a 是奇數時，用互反律翻轉成 `(b/a)`（如果 `a ≡ b ≡ 3 (mod 4)` 就變號）。
4. 重複，直到 a = 1（答案）或 a 和 b 有公因數（答案 0）。

```python
def jacobi(a, b):
    assert b > 0 and b % 2 == 1
    a %= b
    result = 1
    while a:
        while a % 2 == 0:
            a //= 2
            if b % 8 in (3, 5):
                result = -result
        a, b = b, a                       # 互反律
        if a % 4 == 3 and b % 4 == 3:
            result = -result
        a %= b
    return result if b == 1 else 0

print(jacobi(123, 323))                       # 課本例 3.63：123 / (17 · 19)
print(jacobi(-15750, 37907))
print(jacobi(228530738017, 9365449244297))     # 課本例 3.66，完全沒有分解
```
```output
1
1
-1
```
花費和歐幾里得演算法一樣是 O(log b) 步。

## 3.3 ⚠️ (a/N) = 1 不代表 a 是平方數

N = pq 時，`(a/N) = (a/p)(a/q)`，等於 1 有兩種情況：

| `(a/p)` | `(a/q)` | `(a/N)` | a 是模 N 的平方數嗎？ |
|---|---|---|---|
| 1 | 1 | 1 | **是** |
| −1 | −1 | 1 | **不是**（模 p 就不是平方了） |

**知道 p、q** 的人可以分別算 `(a/p)` 分辨這兩種情況；**不知道** 的人目前沒有好方法——這叫 **二次剩餘問題**，一般相信它和分解一樣難。

```python
def legendre(a, p):
    r = pow(a % p, (p - 1) // 2, p)
    return -1 if r == p - 1 else r

p, q = 7, 11
N = p * q
squares = {x * x % N for x in range(1, N) if x % 7 and x % 11}
both_minus = [a for a in range(1, N) if a % 7 and a % 11 and legendre(a, p) == legendre(a, q) == -1]
print(sorted(squares))
print(both_minus)
```
```output
[1, 4, 9, 15, 16, 23, 25, 36, 37, 53, 58, 60, 64, 67, 71]
[6, 10, 13, 17, 19, 24, 40, 41, 52, 54, 61, 62, 68, 73, 76]
```
兩組數的 Jacobi 符號都是 1，但第二組沒有一個是平方數。這個「看起來一樣、卻分不出來」的性質，就是下一部分加密系統的基礎。

# 第四部分：Goldwasser–Micali 機率式加密

## 4.1 為什麼要機率式加密

如果明文只有少數幾種可能（例如只傳一個位元 0 或 1、或「是 / 否」），**確定性** 的公鑰加密（例如教科書 RSA）一點也不安全：Eve 把 0 和 1 都用公鑰加密一次，和截到的密文比對就知道答案。

**機率式加密**（probabilistic encryption）：加密時加入 **隨機性**，同一個明文每次加密都得到不同的密文。我們已經看過一個例子——ElGamal 的臨時金鑰 k（第 06 課）。

## 4.2 Goldwasser–Micali 系統

| | 做什麼 |
|---|---|
| **Bob 建金鑰** | 選秘密質數 p、q，N = pq；選 a 使 `(a/p) = (a/q) = −1`（a 不是平方數，但 Jacobi 符號是 1）；公布 `(N, a)` |
| **Alice 加密位元 m** | 選隨機 r，`m = 0` 送 `c ≡ r² (mod N)`，`m = 1` 送 `c ≡ a · r² (mod N)` |
| **Bob 解密** | 算 `(c/p)`：1 代表 m = 0，−1 代表 m = 1 |

**為什麼對**：`(r²/p) = 1`；`(a r²/p) = (a/p) = −1`。

**為什麼 Eve 解不開**：兩種密文的 Jacobi 符號 `(c/N)` 都是 1，要分辨就得解二次剩餘問題。

課本例 3.68：p = 2309、q = 5651、N = 13048159、a = 6283665。

```python
def legendre(a, p):
    r = pow(a % p, (p - 1) // 2, p)
    return -1 if r == p - 1 else r

p, q = 2309, 5651
N, a = p * q, 6283665
print(N, legendre(a, p), legendre(a, q))

def encrypt(m, r):
    return r * r % N if m == 0 else a * r * r % N

def decrypt(c):
    return 0 if legendre(c, p) == 1 else 1

c0 = encrypt(0, 1642087)               # 課本的第一個位元
print(c0, decrypt(c0))
import random
random.seed(4)
bits = [1, 0, 1, 1, 0, 0, 1]
cs = [encrypt(b, random.randrange(1, N)) for b in bits]
print(cs[:3])
print([decrypt(c) for c in cs])
print(encrypt(1, 5), encrypt(1, 6))    # 同一個明文、不同的 r → 不同的密文
```
```output
13048159 -1 -1
8513742 0
[11648861, 9159005, 7851965]
[1, 0, 1, 1, 0, 0, 1]
513717 4393237
```
## 4.3 不實用的地方

每 **一個位元** 的明文要用一個模 N 的數表示。N 至少 1000 位元時，密文是明文的 **1000 倍長**（訊息膨脹率 log₂ N）。所以 Goldwasser–Micali 主要的意義是 **理論**：它是第一個在明確的數學假設下被證明 **語意安全**（semantic security，密文不洩漏關於明文的任何部分資訊）的系統，Goldwasser 和 Micali 因此獲得 2012 年圖靈獎。

實用的機率式加密：ElGamal（膨脹 2 倍）、RSA 配上隨機填充 OAEP（第 26 課）。

# 習題解答

**題 1**：

```python
p = 13
print(sorted({c * c % p for c in range(1, p)}))
print(pow(3, 6, 13), pow(5, 6, 13))
```
```output
[1, 3, 4, 9, 10, 12]
1 12
```
`3⁶ ≡ 1`，3 是二次剩餘（`4² = 16 ≡ 3`）；`5⁶ ≡ 12 ≡ −1`，5 不是。

**題 2**：31 ≡ 3 (mod 4)。`(3/31)`：3 和 31 都 ≡ 3 (mod 4)，翻轉要變號：`(3/31) = −(31/3) = −(1/3) = −1`。`(13/31)`：13 ≡ 1 (mod 4)，不變號：`(13/31) = (31/13) = (5/13) = (13/5) = (3/5) = (5/3) = (2/3) = −1`（3 ≡ 3 mod 8）。

```python
print(pow(3, 15, 31), pow(13, 15, 31))
```
```output
30 30
```
都是 30 ≡ −1。

**題 3**：`(2/15) = (2/3)(2/5) = (−1)(−1) = 1`，Jacobi 符號是 1；但 2 模 3 就不是平方數，所以不可能是模 15 的平方數。

```python
print(sorted({x * x % 15 for x in range(15)}))
```
```output
[0, 1, 4, 6, 9, 10]
```
模 15 的平方數裡沒有 2——**Jacobi 符號是 1 不保證是平方數**。

**題 4**：

```python
def legendre(a, p):
    r = pow(a % p, (p - 1) // 2, p)
    return -1 if r == p - 1 else r

p = 2309
for c in (5004604, 8513742):
    print(c, 0 if legendre(c, p) == 1 else 1)
```
```output
5004604 1
8513742 0
```
**題 5**：Eve 可以自己把兩種明文都加密一次，比對截到的密文。Goldwasser–Micali 加密時加入隨機的 r，同一個位元有約 N/4 種不同的密文，Eve 無法用「自己加密來比對」的方法；要分辨就得解二次剩餘問題。
