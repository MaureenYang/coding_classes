# 第一部分：同餘

## 1.1 時鐘算術

時鐘上 9 點再過 6 小時是 3 點：`9 + 6 = 15`，但時鐘只到 12，所以是 `15 − 12 = 3`。這就是 **模 12 的算術**。

**定義**：`m ≥ 1`。如果 `m | (a − b)`，就說 `a` 和 `b` **模 m 同餘**，記作

```
a ≡ b (mod m)
```

`m` 叫做 **模數**（modulus）。例：`17 ≡ 7 (mod 5)`（差 10，是 5 的倍數）；`19 ≢ 6 (mod 11)`（差 13）。`a ≡ 0 (mod m)` 就是「`a` 是 `m` 的倍數」。

等價的說法：**`a` 和 `b` 除以 `m` 的餘數相同。**

## 1.2 同餘可以像等式一樣運算

**命題 1.13(a)**：如果 `a₁ ≡ a₂` 且 `b₁ ≡ b₂ (mod m)`，則

```
a₁ ± b₁ ≡ a₂ ± b₂ (mod m)，  a₁ · b₁ ≡ a₂ · b₂ (mod m)
```

**為什麼乘法也成立**：`a₁ = a₂ + km`、`b₁ = b₂ + lm`，相乘得 `a₁b₁ = a₂b₂ + m(a₂l + b₂k + klm)`。

**這件事的實用價值**：計算過程中 **隨時可以先取餘數**，數字永遠不會變大。這是後面所有演算法能處理幾百位數的原因。

```python
a, b, m = 123456789, 987654321, 1000
print((a * b) % m, ((a % m) * (b % m)) % m)
print((a - b) % m, ((a % m) - (b % m)) % m)
```
```output
269 269
468 468
```
> ⚠️ **同餘不能隨便「除」**：`6 ≡ 18 (mod 12)`，兩邊除以 2 得到 `3 ≡ 9 (mod 12)`，這是錯的（差 6）。除法只有在除數有 **模反元素** 時才合法，見第二部分。

## 1.3 Z/mZ

每個整數都和 `0, 1, …, m−1` 其中一個同餘（就是它的餘數），所以處理模 m 的問題時，只要用這 m 個數：

```
Z/mZ = {0, 1, 2, …, m − 1}
```

叫做 **模 m 的整數環**。加法、乘法做完都取餘數。下面是課本圖 1.4 的模 5 乘法表：

```python
m = 5
print("·", *range(m))
for a in range(m):
    print(a, *[(a * b) % m for b in range(m)])
```
```output
· 0 1 2 3 4
0 0 0 0 0 0
1 0 1 2 3 4
2 0 2 4 1 3
3 0 3 1 4 2
4 0 4 3 2 1
```
注意每一列（除了 0 那列）都是 1～4 的一個排列——因為 5 是質數，每個非零元素都有反元素。

# 第二部分：模反元素與單位群

## 2.1 什麼時候能除

在模 m 的世界，「除以 a」的意思是「乘以 a 的反元素」，也就是找 `b` 使得 `a·b ≡ 1 (mod m)`。

**命題 1.13(b)**：`a` 在模 `m` 下有反元素 **若且唯若** `gcd(a, m) = 1`。

**證明**：
- (⇐) `gcd(a, m) = 1` 時，擴展歐幾里得給 `au + mv = 1`，兩邊 mod m 得 `au ≡ 1`，所以 `u` 就是反元素。
- (⇒) 如果 `ab ≡ 1`，則 `ab − 1 = cm`，任何同時整除 `a`、`m` 的數都整除 `ab − cm = 1`，所以 gcd 是 1。

反元素寫作 `a⁻¹ mod m`，在模 m 下唯一。有了它就能算分數：例如 `5/7 mod 11`：`7 · 8 = 56 ≡ 1`，所以 `7⁻¹ ≡ 8`，`5/7 ≡ 5 · 8 = 40 ≡ 7 (mod 11)`。

```python
def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, u1, v1 = ext_gcd(b, a % b)
    return g, v1, u1 - (a // b) * v1

def inverse(a, m):
    g, u, _ = ext_gcd(a % m, m)
    if g != 1:
        raise ValueError(f"{a} 在模 {m} 下沒有反元素（gcd = {g}）")
    return u % m

print(inverse(2, 5), inverse(4, 15), inverse(7, 11))
print(5 * inverse(7, 11) % 11)
print(inverse(7814, 17449))
print(pow(7814, -1, 17449))        # Python 3.8 起內建的寫法
try:
    inverse(6, 15)
except ValueError as e:
    print(e)
```
```output
3 4 8
7
1284
1284
6 在模 15 下沒有反元素（gcd = 3）
```
## 2.2 單位群與歐拉 φ 函數

**定義**：有反元素的元素叫 **單位**（unit）。所有單位組成

```
(Z/mZ)* = {a ∈ Z/mZ : gcd(a, m) = 1}
```

叫做 **模 m 的單位群**。兩個單位相乘還是單位（反元素是 `b⁻¹a⁻¹`），但相加不一定。

**歐拉 φ 函數**：`φ(m) = #(Z/mZ)*`，也就是 `0 ≤ a < m` 中和 `m` 互質的個數。

```python
from math import gcd

def units(m):
    return [a for a in range(m) if gcd(a, m) == 1]

print(units(24), len(units(24)))
print(units(7), len(units(7)))
print([len(units(m)) for m in range(1, 21)])
```
```output
[1, 5, 7, 11, 13, 17, 19, 23] 8
[1, 2, 3, 4, 5, 6] 6
[1, 1, 2, 2, 4, 2, 6, 4, 6, 4, 10, 4, 12, 6, 8, 8, 16, 6, 18, 8]
```
`φ(24) = 8`、`φ(7) = 6`，和課本例 1.17、1.18 一致。**`m` 是質數 p 時 φ(p) = p − 1**（1 到 p−1 全部和 p 互質）。φ 會在 RSA（第 10 課）扮演主角。

# 第三部分：用模運算描述密碼

## 3.1 移位密碼

把字母編號 `a=0 … z=25`，第 01 課的凱撒密碼就是

```
加密 c ≡ p + k (mod 26)，  解密 p ≡ c − k (mod 26)
```

## 3.2 仿射密碼

金鑰是一對數 `(k₁, k₂)`：

```
加密 c ≡ k₁ · p + k₂ (mod 26)
解密 p ≡ k₁⁻¹ · (c − k₂) (mod 26)
```

**`k₁` 必須和 26 互質**，否則沒有反元素、無法解密（而且兩個不同的明文會加密成同一個密文）。所以 `k₁` 只有 φ(26) = 12 種，金鑰共 12 × 26 = 312 種。

```python
def affine_enc(text, k1, k2):
    return "".join(chr((k1 * (ord(ch) - 97) + k2) % 26 + 65) for ch in text)

def affine_dec(text, k1, k2):
    inv = pow(k1, -1, 26)
    return "".join(chr(inv * (ord(ch) - 65 - k2) % 26 + 97) for ch in text)

c = affine_enc("affinecipher", 5, 8)
print(c, affine_dec(c, 5, 8))
print(affine_enc("ab", 13, 0), affine_enc("no", 13, 0))   # k1 = 13 不可逆
```
```output
IHHWVCSWFRCP affinecipher
AN NA
```
最後一行：`k₁ = 13` 時 `a` 和 `o` 都加密成 `A`、`b` 和 `n` 都加密成 `N`，資訊已經遺失，沒辦法解密。

**選擇明文攻擊**（課本習題 1.41）：只要知道兩組「明文 → 密文」，就能解出 `k₁, k₂` 的聯立同餘式。仿射密碼和它的矩陣版本 **Hill 密碼** 都擋不住這種攻擊（第 05 課會再談「安全」的定義）。

# 第四部分：快速冪

## 4.1 問題

RSA 和 Diffie–Hellman 都要算 `g^A mod N`，其中 A 可能有幾百位數。一次乘一個 g 要乘 A 次——A ≈ 2¹⁰⁰⁰ 時，比宇宙年齡還久。

## 4.2 平方再乘法（Square-and-Multiply）

**想法**：把指數寫成二進位，`g^A` 就變成一些 `g^(2^i)` 的乘積，而 `g^(2^i)` 可以 **一直平方** 得到。

**課本例 1.19**：算 `3^218 mod 1000`。`218 = 2 + 2³ + 2⁴ + 2⁶ + 2⁷`（二進位 `11011010`）。

| i | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| `3^(2^i) mod 1000` | 3 | 9 | 81 | 561 | 721 | 841 | 281 | 961 |

```
3^218 ≡ 9 · 561 · 721 · 281 · 961 ≡ 489 (mod 1000)
```

只用了 7 次平方 + 4 次乘法 = 11 次乘法。

```python
def table(g, A, N):
    a = g % N
    for i in range(A.bit_length()):
        bit = (A >> i) & 1
        print(i, a, "←" if bit else "")
        a = a * a % N

table(3, 218, 1000)
print(bin(218), pow(3, 218, 1000))
```
```output
0 3 
1 9 ←
2 81 
3 561 ←
4 721 ←
5 841 
6 281 ←
7 961 ←
0b11011010 489
```
## 4.3 演算法

**由低位到高位（right-to-left）**：一邊平方、一邊把需要的乘進答案。只用常數個變數（課本習題 1.24）。

```python
def power_mod(g, A, N):
    result = 1
    a = g % N
    mults = 0
    while A > 0:
        if A & 1:
            result = result * a % N
            mults += 1
        A >>= 1
        if A:
            a = a * a % N
            mults += 1
    return result, mults

print(power_mod(3, 218, 1000))
print(power_mod(2, 15485862, 15485863))     # 費馬小定理（第 04 課）：答案會是 1
r, k = power_mod(7, 2**1000 + 12345, 10**50 + 151)
print(k)
print(r == pow(7, 2**1000 + 12345, 10**50 + 151))
```
```output
(489, 12)
(1, 36)
1007
True
```
程式數到 12 次乘法，比課本的 11 次多一次：第一次「乘入」是 `1 × 9`，課本不把它算進去。

**花費**：最多 2 log₂ A 次模 N 的乘法。指數是 1000 位元時約 2000 次——一瞬間就做完。Python 內建的 `pow(g, A, N)` 就是這樣算的（還用了更多最佳化）。

**由高位到低位（left-to-right）** 也常見：從最高位開始，每讀一個位元先平方，位元是 1 再乘 g。

```python
def power_mod_lr(g, A, N):
    result = 1
    for bit in bin(A)[2:]:
        result = result * result % N
        if bit == "1":
            result = result * g % N
    return result

print(power_mod_lr(3, 218, 1000))
```
```output
489
```
> 🔍 **旁通道攻擊**：上面的程式碼在位元是 1 時多做一次乘法，執行時間或耗電量就會洩漏指數的位元——如果指數是私鑰，這就是真實的攻擊（timing attack、power analysis）。實務上的函式庫會用「每一位都做一樣的運算」的寫法（例如 Montgomery ladder）。課本 §3.3 和《Cryptography Engineering》第 15 章都提到這類實作問題。

# 習題解答

**題 1**：

```python
print(17 % 5, -17 % 5, (2 - 3) % 12, (6 + 9) % 12)
```
```output
2 3 11 3
```
`−17 = 5 × (−4) + 3`，所以餘數是 3。後兩個就是時鐘：2 點往前 3 小時是 11 點，6 點再過 9 小時是 3 點。

**題 2**：`26 = 11 · 2 + 4`，`11 = 4 · 2 + 3`，`4 = 3 · 1 + 1`。倒推：`1 = 4 − 3 = 4 − (11 − 2·4) = 3·4 − 11 = 3(26 − 2·11) − 11 = 3·26 − 7·11`，所以 `11⁻¹ ≡ −7 ≡ 19 (mod 26)`。

```python
print(pow(11, -1, 26), 11 * 19 % 26)
```
```output
19 1
```
**題 3**：

```python
g, A, N = 5, 37, 23
print(bin(A))
result, a = 1, g
while A:
    if A & 1:
        result = result * a % N
        print("乘入", a, "->", result)
    A >>= 1
    a = a * a % N
print(result, pow(5, 37, 23))
```
```output
0b100101
乘入 5 -> 5
乘入 4 -> 20
乘入 9 -> 19
19 19
```
**題 4**：`i = 8`、`f = 5`、`Q = 16`、`J = 9`。解 `8k₁ + k₂ ≡ 16`、`5k₁ + k₂ ≡ 9 (mod 26)`。相減：`3k₁ ≡ 7`，`3⁻¹ ≡ 9`，`k₁ ≡ 63 ≡ 11`；`k₂ ≡ 16 − 88 ≡ 6`。

```python
k1 = 7 * pow(3, -1, 26) % 26
k2 = (16 - 8 * k1) % 26
print(k1, k2)
print("".join(chr((k1 * (ord(ch) - 97) + k2) % 26 + 65) for ch in "if"))
```
```output
11 6
QJ
```
**題 5**：條件是 `gcd(a, m) = 1`。模數是質數 p 時，1～p−1 都和 p 互質，所以 **每個非零元素都能除**，Z/pZ 變成一個 **體**（field，第 04 課）。

**題 6**：A = 2²⁰ − 1 時，19 次平方 + 20 次乘入答案（第一次乘入是 `1 × a`，嚴格來說可以省掉）≈ 39 次，接近上限 2 log₂ A。A = 2²⁰ 時，20 次平方 + 1 次乘入 = 21 次。所以乘法次數介於 log₂ A 和 2 log₂ A 之間，取決於二進位裡有幾個 1。
